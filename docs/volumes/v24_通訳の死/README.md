# 第24巻終了時の台帳

## 人物

- **後藤又兵衛**：官兵衛を失い、長政との間を訳す者がいなくなる。他国書状の登録、嫡男の門破り、能役拒否、配置転換案を経て、慶長十一年に大隈城と知行を返上する。黒田家へ残る者を裏切り者とせず、最終的には本人に選ばせる。ただし長政の統制を「監視」と読む傾向、自分なら皆を食わせられるという過信、自分の飯を人数へ入れない欠点は残る。
- **黒田長政**：父の死後、五十二万石の外交通信と軍事指揮を一本化する。又兵衛の家を残すため、知行・扶持・名誉を大きく損なわない配置転換案を出すが、独立した城・兵・書状・嫡男を同時に管理しようとし、又兵衛には解体と映る。追手は出さず、家族と供へ連座させない通行状を出す。又兵衛の他家仕官を認めるかは答えない。
- **黒田官兵衛／如水**：慶長九年に死去。最後に「聞け」と残すが、誰が誰の何を聞くのか確定しない。二人を和解させる明確な遺命は残さず、地図、書状、肖像、互いを訳す習慣だけが残る。
- **後藤基則**：急病の娘を救うため、父の軍用札で夜門を破り、門番の手首を折る。自分の罪を父に引き取らせず、能役も自分で受けようとする。最終的には父と城を出るが、小姓組で働きたかった気持ちと、門番へ役を終えて返す約束を残す。
- **カヤ**：又兵衛の決定へ従うのでなく、条件書を基則本人へ渡し、家族それぞれの選択を聞かせる。弦太から帳面外の干し飯を預かり、自分の意思で又兵衛と出る。
- **小夜**：家族の荷へ欠けた椀を入れ、出発人数より一つ多い飯を握る。又兵衛自身の一食を、本人より先に数える。
- **速水弦太**：又兵衛へ条件受諾を勧め、家臣と家族三百余人の生活を数字で示す。又兵衛について出ず、黒田家へ残る者の扶持を一日も遅らせないため兵糧方に残る。友情と所属を分ける。
- **狭間清十郎**：公式記録を黒田家へ返し、帰名帳を持って又兵衛に同行する。出る者と残る者の二本の線を引き、又兵衛の意向が無言の命令になることを指摘する。
- **井上九郎右衛門**：書状登録と配置転換条件を制度へ落とし込む。又兵衛の働きを消す意図はないが、記録へ残る文章が理由を削る危険も自覚する。
- **栗山善助**：黒田家を内側から割らない立場を崩さず、長政の案を支える。又兵衛を力で止めず、成立しなかった条件まで記録へ残す。

## 道具と象徴

- **黒槍**：又兵衛が所有したまま持ち出す。黒田家の藤巴金具と黒白の飾り紐を外し、取り付け跡だけが残る。柄の補修輪、右肩へ負担を掛ける重量、父と仲間の痕跡は変わらない。
- **欠けた椀**：又兵衛側の一片を小夜が荷へ入れる。長政側の一片は黒田家に残る。離別しても、片方だけでは揃わない状態を維持する。
- **私印・知行印・城の鍵**：私印は書院へ印影登録された後に又兵衛へ戻る。知行印と城の鍵は出奔時に返却する。
- **五か条の条件書**：成立せず、黒田家記録へ「不成立案」として残る。又兵衛の修正跡は清書で消えたが、井上が下書きを別に保存する。
- **能の扇と番組表**：基則の未完の役を示す扇は、張り替えられた後、門番へ預ける。長政の手元には当夜の番組表が残り、同じ出来事を三者が別の物で記憶する。
- **如水の国絵図**：福岡城と大隈城が折り目の裏表へ分かれたまま、長政が保管する。
- **通行状**：又兵衛と供六十三人、計六十四人へ、筑前国内の通行と三十日分の旅粮を認める。追手を出さない個人的な約束を、門番が実行できる制度へ変えた長政の最後の保護でもある。

## 情報

- 又兵衛は、長政が自分を嫌って追放したのではなく、家と扶持を残す条件を用意したと知っている。それでも、その条件を受ければ自分の軍と判断権が解体されると考える。
- 長政は、又兵衛が謀反を企てていないと判断している。しかし、又兵衛の名、独自書状、軍事判断、家臣人気が別の命令中心になり得る危険を消せない。
- 基則の門破りは、急病の娘を救うためだった事実まで家中記録へ残る。噂では「兵糧と武器の横流し」が消えず、後藤家への疑念は完全には解けない。
- 又兵衛と長政の一対一の会話内容は、井上も家臣団も知らない。成立しなかった五か条だけが公式記録になる。
- 官兵衛の最後の「聞け」は、又兵衛と長政がそれぞれ自分に向けられた言葉として受け取っている。

## 生活・人数・移動

- 大隈城の扶持帳に載る家臣は百二十七人。家族・奉公人を含めると三百余人。
- 又兵衛と城を出る家臣は二十六人。家族・奉公人を含む供は六十三人で、又兵衛を加えた一行は六十四人。
- 荷車七台、駄馬十二頭。旅粮は三十日分。城の武器・米・火薬は持ち出さず、個人所有品だけを携行する。
- 弦太ら黒田家へ残る者の扶持は継続する。又兵衛一行は細川領方面へ向かうが、正式な仕官先はまだない。

## 史実と創作の区分

- `[A/B]`：黒田官兵衛が1604年に死去したこと、又兵衛が大隈城主級の重臣であったこと、1606年頃に黒田家を離れたこと、細川・池田方面を頼ったとされること。
- `[B/D]`：長政との不和に、他国書状、家中統制、嫡男、能・芸能参加をめぐる逸話など複数の原因が語られること。単一原因へ確定しない。
- `[C]`：官兵衛最期の会話、葬列の具体、書状登録制度の場面、基則の門破り、能『敦盛』の役、五か条の文面、供六十三人という人数、弦太・清十郎・カヤ・小夜の選択。

- 行橋市歴史資料館「[後藤又兵衛の槍展](https://www.city.yukuhashi.fukuoka.jp/site/bunkazai/33771.html)」：官兵衛死後の関係悪化と出奔、隣国小倉藩を頼って京都郡今井へ潜伏した地域伝承を確認。娘を守田家へ託した伝承では名を「久」とするが、本作では人物正典の小夜を `[C]` として継続する。第25巻へ向かう東行の根拠にも用いる。
- 嫡男問題、能役、書状統制、五か条の具体は確定史実として扱わず、本作正典に従う複合的な創作とする。史料間で理由が一つに定まらないこと自体を、二人の決裂を単純な善悪へ落とさないために利用する。

## 第25巻への不可逆な条件

- 又兵衛は大隈城、一万石余の知行、黒田家中の席を失った。黒槍は持つが、旗と兵と蔵を持たない。
- 家臣団は残留と同行へ分かれた。又兵衛は「全員を連れていく」ことが必ずしも救いにならないと知るが、生活を保障する仕組みはまだ作れない。
- 長政は追手を出さなかった。しかし、又兵衛が細川家などへ仕えれば国境と家中統制の問題になるため、他家へ抗議する準備を始める。
- 基則、カヤ、小夜、清十郎らは又兵衛と同行する。弦太は黒田家に残り、二人の陣営が初めて生活の場でも分かれる。
- 友としての別れの言葉は交わされていない。二人の関係は終わったのではなく、今後は書状、使者、制度を介さなければ届かない形へ変わった。
