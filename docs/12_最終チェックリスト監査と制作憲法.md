# 『戦帰 SENKI』最終チェックリスト監査と制作憲法

> **目的**：全30巻・240話を作り込む際、巻ごと・話ごとに主題、人物、謎、史実、象徴、戦闘、死、日常がぶれないようにする。  
> **位置づけ**：本書は物語内容を勝手に変更する資料ではなく、`00_正典ルールと30巻整合性ロック.md`以下の正典を、各話へ落とすための制作憲法である。  
> **結論**：現在の物語は、中心矛盾、主人公の夢、二人の関係、象徴、最終決断については強い。しかし、全240話を執筆する運用としては、情報開示、各話の小さな回答、死後影響、日常配置、戦闘条件の管理がまだ不足している。本書でその不足を固定ルールへ変える。

---

# 1．総合判定

## 現在の完成度

- **長編の背骨**：合格。全30巻を貫く問いと最終回答がある。
- **第1〜14巻の感情曲線**：強い。出会い、家族化、黄金期、軍事的敗北、道徳的破局、再起動がつながっている。
- **全30巻の巻構成**：合格。ただし第15〜30巻は、巻単位の骨子から話単位へ落とす作業が必要。
- **全240話の制作準備**：未完成。話ごとの情報、答え、不可逆な変化、日常、象徴、戦闘条件を管理する仕組みが必要。

## 20項目監査の集計

- **◎ 強く成立**：9項目
- **○ 成立しているが、運用固定が必要**：8項目
- **△ 未固定で、今後ぶれやすい**：3項目

△は次の三つである。

1. 誰が何を知り、なぜ真実を隠すのかという情報権力の全30巻設計。
2. 表層・制度・歴史・存在へ進む四段階の謎の固定。
3. 各話で必ず小さな答えを返し、謎を積み上げ過ぎない運用。

# 3．絶対に変えてはいけない中心矛盾

全240話は、次の一問から外れてはならない。

> **人を守るために作った門、国、誓い、組織は、誰を外へ残すのか。**

主人公側の言葉へ変えると、次になる。

> **誰も見捨てないための強さは、仲間の選択と自分の命を奪う支配にならないか。**

この一つの矛盾を、全要素へ別の形で反復する。

| 階層 | 中心矛盾の現れ方 |
|---|---|
| 世界 | 城と門は人を守るが、身分のない者や敵方を外へ置く |
| 政治 | 国を守る制度は、個人を役割と数字へ変える |
| 軍事 | 全滅を避ける撤退は、誰を残すか決める行為でもある |
| 記録 | 名を残す帳面は、人を救う一方、拘束・徴発・処罰にも使える |
| 主人公 | 「全員を帰す」誓いが、自分の自己犠牲と仲間への支配へ変わる |
| 主従 | 又兵衛は目の前の一人、長政は帰る国全体を守ろうとする |
| 敵 | 同じ願いを持ちながら、弱者、自分、敵国、少数の誰かを切り捨てる |
| 最終決断 | 又兵衛が仲間の選択を認め、自分も守られる一人に数えられるか |

## 各話との接続ルール

各話は、最低一つについて中心矛盾を具体化する。

1. 誰を門の内へ入れるか。
2. 誰を名簿へ載せるか。
3. 誰へ判断を任せるか。
4. 誰の意思を無視して守ろうとするか。
5. 誰の損失によって勝利が成立するか。
6. 誰が帰ったと数えられ、誰が数から消えるか。

どれにも接続しない話は、面白くても本編の正典話には入れない。

# 4．『戦帰』における「壁」の正典――門と帰る場所

『戦帰』で最も重要な世界設定は、物理的な巨大壁ではない。

> **門と、その内側にある帰る場所**

である。

門は一つで、次の機能を持つ。

1. 敵から守る防御。
2. 身分のない者を止める階級制度。
3. 人質を外へ出す政治装置。
4. 軍令を実行する境界。
5. 反乱者や住民を締め出す加害装置。
6. 主君が家臣を囲う制度。
7. 又兵衛が出奔する時に失う居場所。
8. 最終回で本人ではなく名が帰る場所。

## 門の意味変化を固定する

| 段階 | 意味 |
|---|---|
| 第1巻 | 身分がないため入れない |
| 第2〜3巻 | 人質と政治が二人を分ける |
| 第6〜7巻 | 自分の城と未来への憧れ |
| 第13巻 | 又兵衛自身が閉じる側になる |
| 第14巻 | 誰を条件付きで通すかという統治 |
| 第23〜24巻 | 帰る城を得たのに食卓へ帰れない |
| 第26巻 | 長政が国を守るため又兵衛を外へ出す |
| 第29巻 | 大坂城が守りと牢獄を兼ねる |
| 第30巻・最終回 | 又兵衛の名と思想が、人の記憶へ帰る |

## 絶対ルール

- 新しい大章では、必ず「守る境界」と「外へ残される者」を一組置く。
- 境界は城門に限らない。関所、船、陣、軍令、家名、契約、役職でもよい。
- 境界が守る機能だけ、または傷つける機能だけになってはならない。
- 又兵衛が門を開く側だけでなく、閉じる側になる話を必ず残す。

# 5．全30巻を貫く四段階の謎

本作は史実漫画であり、世界そのものを覆す架空の超巨大秘密を置く必要はない。代わりに、戦争と統治が人間をどう記録し、どう消すかを謎の背骨にする。

## 中心の問い

> **誰が「帰った者」として記録され、誰が戦と国の記録から消されたのか。**

この抽象的な問いを、清十郎の**帰名帳**、欠けた頁、公式名簿、扶持帳、兵糧帳、住民証言、書状という物理物へ落とす。

## 第1層――表層の謎

> 今、誰が何をしたのか。

- 父はどこへ行ったのか。
- 「若君を西へ」と書いたのは誰か。
- 密書の依頼主は誰か。
- 誰が門を閉じ、誰が脇門を開いたのか。
- 誰が偽命令を流したのか。

**回答時期**：原則として同じ巻、遅くとも次巻まで。

## 第2層――制度の謎

> 誰が記録と命令を管理し、何を守るために改変・秘匿するのか。

- なぜ非公式の補助兵は戦死者へ載らないのか。
- なぜ手柄が又兵衛一人の名へ集約されるのか。
- なぜ敗走、徴発、処罰の人数を小さく見せたいのか。
- なぜ住民証言と公式記録が違うのか。

**回答時期**：一〜三巻以内。答えは、さらに大きな歴史上の責任を開く。

## 第3層――歴史の謎

> 輝かしい勝利と安定した国は、誰の見えない損失によって成立したのか。

- 天下規模の勝利の裏で、誰が落伍・餓死・行方不明になったのか。
- 救援の技術が、侵攻と統治を延命する装置になっていないか。
- 勝者の記録は、敗者、敵兵、民間人、旧友をどう分類したか。
- 又兵衛自身の名声は、何人の無名の働きを一人の名前へ集めたものか。

**回答時期**：大章単位。関ヶ原、福岡城、出奔へつなぐ。

## 第4層――存在の謎

> 身体を生かして連れ帰れなかった者を、「置き去りにしない」とは何か。

- 仲間の死を受け入れることは、見捨てることか。
- 本人が残ると選んだ時、その意思を尊重できるか。
- 名前、選択、責任を記録へ残すことは帰還になり得るか。
- 又兵衛自身が死ぬ時、彼を誰が連れて帰るのか。

**最終回答**：第30巻と最終回。身体の完全生還だけを夢の唯一の意味にしない。ただし、早い段階から「死んでも名が残ればよい」と逃げてはならない。最後まで生還のための具体策を尽くした後にのみ、記憶と責任の意味へ進む。

# 6．情報を隠す者の配置ルール

情報を隠す時は、作者の都合ではなく、世界内の理由を必ず持たせる。

| 人物・組織 | 知る情報 | 隠す理由 | 隠した代価 |
|---|---|---|---|
| 官兵衛 | 策、交渉、二重書状、家存続の危機 | 作戦成功、家族と家臣を守る | 信頼されず、家族へ本心を伝えられない |
| 長政 | 国政上の全体像、処罰、調略、命令 | 国の統一、反乱防止、外圧への対抗 | 友を役割へ変え、私的な関係を失う |
| 清十郎 | 現場記録、公式記録、住民証言の差 | 初期は証拠不足と身分の弱さ | 見るだけで止めなかった責任を負う |
| 弦太 | 実際に届いた米と人、帳面の差 | 混乱防止、命令への恐怖 | 数字が加害へ転用される |
| カヤ | 偽情報、潜入経路、誰が誰を使うか | 妹、任務、情報源を守る | 信頼と関係を失う |
| 又兵衛 | 現場で見た死と救出 | 仲間を動揺させたくない、自分で背負う | 仲間が判断へ参加できず、独断が進む |
| 役所・家 | 損失、扶持、逃亡、処罰の実数 | 財政、威信、士気、責任回避 | 無名の者が記録から消える |
| 敵側 | 自軍の損失、住民被害、命令の失敗 | 生存、報復回避、正統性 | 次の世代が誤った敵像を継ぐ |

## 情報開示の四条件

重大な真相は、必ず次の四つを同時に行う。

1. 以前の疑問へ答える。
2. より大きな問いを生む。
3. 味方または敵への見方を変える。
4. 誰かへ不可逆な決断を迫る。

四つのうち二つ以下しか満たさない開示は、設定説明であり、物語上の重大開示には数えない。

## 謎の負債上限

- 一話で開く**重大な謎は一つまで**。
- 一話で、過去の小さな問いへ**最低一つ答える**。
- 一巻で、前巻以前から継いだ重要な問いを**最低二つ閉じる**。
- 一巻で新しく開く大きな問いは**二つまで**。
- 表層の謎を八話以上放置しない。
- 制度の謎を三巻以上、理由なく放置しない。
- 答えを引き延ばす場合、隠す人物の利益・恐怖・危険が増していることを見せる。

# 7．主人公の夢を危険にする絶対ルール

又兵衛の夢は変えない。

> **どんな負け戦でも、最後の一人まで連れて帰る。**

変えるのは、夢が指す「最後の一人」と「帰る」の意味である。

## 夢の段階

1. **第1〜3巻**：目の前の人間を物理的に連れ戻す。
2. **第4〜7巻**：本人の意思を奪わず、仲間として戻る道を作る。
3. **第8〜12巻**：大軍で誰を最後尾へ置くかという責任に直面する。
4. **第13〜14巻**：正しい命令と制度も人を外へ残すと知る。
5. **第15〜18巻**：敵国の人間も「一人」に含めるかを問う。
6. **第19〜26巻**：守る集団が大きくなるほど、別の忠誠と支配を生む。
7. **第27〜30巻**：仲間の選択を認め、自分も帰すべき一人に数える。

## 又兵衛を正解にし過ぎない

各巻で最低一度、次のどれかを起こす。

- 守ろうとした相手の意思を無視する。
- 全員を救おうとして別の集団を危険にする。
- 自分だけ残り、仲間から選択権を奪う。
- 武名欲を救援の正義へ混ぜる。
- 命令を破り、組織全体を危険にする。
- 命令を問い直さず従い、人を傷つける。
- 救った者を自分の仲間へ囲おうとする。

又兵衛が正しい時も、方法、代価、見落とした相手を残す。

# 8．主要人物を「主題への別の答え」にする

| 長政 | 帰る国と黒田家 | 大切な人ほど制度へ囲う | 制度で所有せず、失った名を国へ帰す |

| 甚六 | 帰れる退路 | 自分を裏方として数えない | 退路こそ大将の仕事だと残す |

| 豊久 | 必要とされる名 | 命を懸けなければ価値がない | 自分の名でなく未来を守る殿を選ぶ |
| 忠勝 | 味方を戦わせない強さ | 強い者は守られなくてよい | 最強の者にも帰る場所が必要だと示す |
| 家康 | 戦国を終わらせる秩序 | 一つを滅ぼせば多数を救える | 完全な正解にはせず、平和の代価を残す |

## 人物制作の絶対条件

名前のある継続人物には、最低限、次を設定する。

1. 欲しいもの。
2. 本当に必要なもの。
3. 長所と同じ根から生まれる欠点。
4. 主題への本人なりの答え。
5. 又兵衛と同じ点。
6. 又兵衛と分かれる一点。
7. 本人にしかできない不可逆な選択。
8. 又兵衛がいなくても成立する最終進路。

次の人物は作らない。

- 又兵衛を褒めるだけの人物。
- 又兵衛に救われたため無条件で従う人物。
- 敗北しただけで思想を捨てる敵。
- 主人公を怒らせるためだけに傷つく家族や子ども。
- 同じ役割と性格を持つ代替可能な仲間。

# 9．死と喪失の絶対ルール

死は驚きではなく、その後の物語を変える原因でなければならない。

## 人物を死なせる前の六条件

1. 本人に未完了の願いがある。
2. 本人が最期まで一つ以上の選択をする。
3. 死によって最低三人の行動または関係が変わる。
4. 組織の役割・指揮・技術に空席ができる。
5. 道具、場所、口癖、仕事のどれかへ不在が残る。
6. 少なくとも十話後にも影響が確認できる。

## 影響を三段階で管理する

| 時期 | 必須影響 |
|---|---|
| 次の1〜2話 | 葬送、空席、実務の混乱、怒り、罪悪感、判断の変化 |
| 8〜10話後 | 技術、組織、関係、口癖、象徴のいずれかへ変換 |
| 別大章 | 生存者の重要な選択、敵への見方、最終決断へ再作用 |

## 死亡禁止条件

次の場合、人物を死なせない。

- 主人公を覚醒させる以外の影響がない。
- 同じ役割の人物が直後に補充される。
- 未完了の願いを読者が知らない。
- 死後、周囲が次話から平常運転へ戻る。
- 残酷さを増すためだけである。
- 史実人物の死を創作主人公の手柄へ変える。

## 死なせない喪失も同じ重さで扱う

- 身体機能。
- 身分。
- 城。
- 主君。
- 家族関係。
- 名誉。
- 信頼。
- 技能の用途。
- 帰る場所。

人物を生かしたまま責任を背負わせる方が強い場合、安易に死を選ばない。

# 10．日常と光の配置ルール

暗さを深さと混同しない。読者が守ってほしいと願う具体的生活を先に作る。

## 各巻8話の最低配置

一巻につき、最低でも次を入れる。

- **食事または飲み物の場面**：1回以上。
- **仕事・家事・訓練・祭り・商いの生活場面**：2回以上。
- **人物同士が作戦説明をせずに過ごす場面**：1回以上。
- **笑い、冗談、失敗、遊びの場面**：1回以上。
- **戦後に誰が修理し、運び、埋葬し、養うかを描く場面**：1回以上。

## 配置上の禁止

- 戦闘、軍議、政治説明だけの話を三話連続させない。
- 破壊する村、城、店、橋は、破壊前にそこで生きる具体的な人物と習慣を見せる。
- 食事場面を休憩だけにせず、身分、関係、欠落、後の空席を保存する。
- 笑いを悲劇の直後の感情無視に使わない。呼吸を戻す位置へ置く。

## 日常場面の役割

日常は最低二つの機能を持たせる。

1. 人物の性格を覚えさせる。
2. 人間関係を進める。
3. 守る価値のある生活を示す。
4. 後の喪失や反転を準備する。
5. 戦争以外の才能と未来を見せる。
6. 物資、仕事、身分、家族という現実を示す。

# 11．戦闘・救出・撤退の絶対ルール

派手な技名より先に、読者が状況を理解できる条件を作る。

## 戦闘前に必ず決める九項目

1. 又兵衛側の勝利条件。
2. 敵側の勝利条件。
3. 敗北条件。
4. 時間制限。
5. 地形と移動可能範囲。
6. 人数、米、水、馬、刃、火薬、船などの資源。
7. 負傷、疲労、天候、身分、命令などの制約。
8. 両陣営が知っている情報と誤認。
9. 勝利しても失う具体的なもの。

## 戦闘中の絶対ルール

- 新技、新兵器、援軍、逃げ道を決戦中に初出させない。
- 勝利に使う要素は、最低一話前までに見せる。
- 又兵衛一人が全ての重要行動をしない。集団戦では最低三人の別能力を接続する。
- 敵を急に無能にしない。敵の失敗も性格、情報不足、時間、地形から生じさせる。
- 戦い方で心理を見せる。怒れば直線的、恐れれば過剰、守る時は位置取り、自己処罰なら防御放棄として現れる。
- 退却、時間稼ぎ、交渉、護送、兵站維持も正式な勝利とする。
- 「多く助かった」で済ませず、出発者、到着者、負傷者、死者、行方不明者を数える。
- 戦闘結果は、身体、関係、価値観のうち最低二つを変える。

## 史実との境界

各話の事件をA・B・Cで表示する。

- **A：史実確定**。年代、勝敗、所属、生死、主要行動を変更しない。
- **B：伝承**。複数説があることを必要に応じて示す。
- **C：創作**。記録の空白に置く救出、撤退、護送、潜入、兵站、対話。

Cの活躍によってAの歴史的勝敗が決まったことにしない。実在人物の著名な功績を又兵衛へ移さない。

# 12．象徴の使用ルール

全編の主象徴は五つに絞る。

| 象徴 | 初期 | 中盤 | 後半・最終 |
|---|---|---|---|
| 門 | 身分がなく入れない | 守る制度、閉じる命令 | 出奔、牢獄、名が帰る場所 |
| 黒槍 | 父から借りた夢 | 仲間と名声、加害への関与 | 責任、無城、手すりと標識 |
| 帰名帳 | 消された父の名を戻す | 敵、民間人、加害側も記す | 勝者の嘘を越え、又兵衛の名を残す |
| 欠けた椀 | 身分を越えた最初の食事 | 呼べない食卓、空席 | 又兵衛の名が福岡へ帰る |
| カヤの鈴 | 音を消した命令 | 自分で選んだ帰路の合図 | 不在、再選択、帰る場所の音 |

## 使用制限

- 一話で前景化する主象徴は一つまで。
- 一巻の主象徴は一つ、補助象徴は二つまで。
- 同じ象徴を同じ意味で繰り返さない。
- 象徴の意味を台詞で全説明しない。使い方、置かれ方、誰が触れないかで示す。
- 新しい象徴を増やす前に、既存の五つで表現できないか確認する。
- 象徴が人物の選択と無関係なら削る。

# 13．初読と再読を両立させるルール

各巻に最低一つ、次の二重場面を置く。

- 初読では成功、再読では失敗の始まり。
- 初読では友情、再読では支配の芽。
- 初読では強化、再読では身体と関係の不可逆な傷。
- 初読では救出、再読では別の集団への加害。
- 初読では正しい台詞、再読では本人が守れなかった約束。

## 公平性

再読反転は、後出しだけで作らない。

- 真相前にも不自然な行動、言葉、欠けた情報を見せる。
- 読者が手掛かりを見ていたが、分類を間違えた形にする。
- 真相前の読み方も感情的には成立させる。
- 人物が嘘をついていた場合、なぜ嘘が必要だったかを先に示す。

# 15．固定するものと変えてよいもの

## 絶対固定

- 中心矛盾。
- 又兵衛と長政の夢、欠点、最終回答。
- 第1巻の入口と二人の約束。
- 門、黒槍、帰名帳、椀、鈴の最終意味。
- 史実Aの年代、勝敗、生死、主要行動。
- 第13巻の道徳的破局。
- 第14巻の第二の第1巻機能。
- 第26巻の出奔。
- 第30巻で又兵衛が自分も一人に数えた後、救援へ戻ること。
- 又兵衛が倒れても人を見捨てない仕組みが動く結末。

## 変更可能

- 各話の順番。
- 小規模な架空敵や住民の人数。
- 誰が手掛かりを発見するか。
- 戦闘の具体的な技順。
- 一部のサブキャラクターの登場時期。
- 台詞の言い回し。
- 大きな決着へ至る複数の作戦経路。

変更可能な部分を動かす場合も、固定事項へどう接続するかを記録する。

# 16．全編で禁止する十五項目

1. 世界説明から始め、人間の危機を後回しにする。
2. 又兵衛だけを正解にし、敵と長政を冷酷な障害へ落とす。
3. 救った相手が無条件で又兵衛の配下になる。
4. 真相を明かしても人物の行動が変わらない。
5. 一話で謎を増やすだけで、何も答えない。
6. 死を主人公の怒りや覚醒の燃料だけにする。
7. 新技、援軍、偶然で決戦を解決する。
8. 戦闘後の負傷、食料、埋葬、仕事、家族を省略する。
9. 「全員救った」と言いながら護衛、敵兵、住民、自分を数えない。
10. 歴史上の大勝敗や実在人物の功績を又兵衛へ奪わせる。
11. 暗い場面を連続させ、守りたい生活を描かない。
12. 象徴を台詞で説明し、同じ意味で反復する。
13. 又兵衛の夢を途中で別の夢へ取り替える。
14. 長政と又兵衛を一度の会話で完全和解させる。
15. 結末を設定資料の説明で閉じ、人物の選択を弱める。

# 17．巻を作る前の合格条件

一巻8話の詳細化へ入る前に、次の12項目を全て書く。

1. 一文で分かる表面目標。
2. 巻の中心となる人間関係。
3. 中心矛盾の今回の形。
4. 又兵衛と同じ願いへの敵の別解。
5. 前巻から受け取る未解決問題。
6. この巻で答える問題を二つ以上。
7. 次巻へ送る大きな問いを二つ以内。
8. 明確な勝利条件、敗北条件、時間、地形、資源。
9. 守りたい日常場面。
10. 主象徴と、その巻で変わる意味。
11. 初読と再読で意味が変わる一場面。
12. 勝利と同時に生じる不可逆な代価。

一つでも空欄なら、全8話の執筆へ進まない。

# 18．各話を作る際の最終原則

各話は、必ず次の流れを持つ。

> **分かりやすい目的**  
> → **人物の誤解または不足情報**  
> → **本人の選択**  
> → **行動の結果**  
> → **小さな答え**  
> → **不可逆な変化**  
> → **より大きい次の問い**

最重要なのは事件ではなく選択である。

- 危機が人物を変えたのではなく、危機の中で何を選んだかを書く。
- 台詞でテーマを説明した時は、その人物が次の行動で台詞を守れるか、裏切るかを必ず見せる。
- 一話終了時に、最低一人の「できること」「知っていること」「信じていること」「関係」のいずれかを変える。
- 何も変わらない話は削るか、別話へ統合する。

> **全240話で守る最後の一文**  
> **又兵衛が人を連れて帰る物語であると同時に、又兵衛自身を仲間が連れて帰ろうとする物語にする。**
