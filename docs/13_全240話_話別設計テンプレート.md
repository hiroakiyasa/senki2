# 『戦帰 SENKI』全240話・話別設計テンプレート

> **目的**：各巻8話、全240話を同じ品質と思想で設計する。

# ハードゲート判定

以下をすべて `合格` にする。

| 項目 | 判定 |
|---|---|
| 正典の年代・人物・史実と一致 |  |
| 前話の結果が開始条件になっている |  |
| 表面目標が具体的 |  |
| 視点人物が自分の価値観で選ぶ |  |
| 選択による不可逆な変化がある |  |
| 次話へ送る代価がある |  |
| 戦闘条件が具体的、または戦闘なしと明記 |  |
| 守る価値のある日常がある |  |
| 伏線だけで話を進めていない |  |
| 初読と再読の二重性がある |  |
| 人数・負傷・道具の連続性がある |  |
| 史実人物の功績を奪っていない |  |
| 又兵衛の自己犠牲を無条件に正解にしていない |  |
| 長政を悪意だけの人物にしていない |  |

# 巻全体カード

8話を作る前に記入する。

- 巻タイトル：
- 表面目標：
- 内面の問い：
- 巻頭で主人公が欲しいもの：
- 巻末で得るもの：
- 巻末で失うもの：
- 次巻の開始条件：
- 8話の役割配分：
  1. 問題と期限
  2. 最初の失敗
  3. 仲間・敵の別回答
  4. 中間勝利と代価
  5. 情報反転
  6. 最大の敗北
  7. 最終選択
  8. 表面決着と次巻への傷

各話の役割は固定公式ではないが、同じ機能の話が続き過ぎないよう監査する。
