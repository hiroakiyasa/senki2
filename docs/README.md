## 今回固定した創作正典

次の三点は、史実上の空白や異説があっても本作の物語正典として維持します。

- 又兵衛が有岡城へ潜入し、官兵衛救出の現場中心人物になる。
- 竹中半兵衛の決断を受け、又兵衛が松寿丸の処刑偽装、移送、追手攪乱を主導する。
- 追放中または仙石家所属の又兵衛が、官兵衛の極秘依頼を受け、黒田方の非公式実働者として備中高松城と中国大返しに参加する。

史実人物の功績は守ります。又兵衛は、潜入、退路、伝令、兵站、負傷者救援、秘密保持という公式記録に残りにくい役割で歴史を接続します。

## 制作時の必須順序

1. `00`で年代、夢、史実、創作正典、黒槍の状態を確認する。
2. `15`で対象話の前話、当話、次話を読む。
3. `02`と`03`で登場人物の夢、欠落、対立軸を確認する。
4. `06`と`07`で技、負傷、道具、伏線の状態を確認する。
5. `12`のハードゲートを確認する。
6. `13`の話別設計カードを全項目埋める。
7. 執筆後に人物、年代、情報、負傷、道具、死、生活、象徴の台帳を更新する。

## 絶対にぶらさない事項

- 又兵衛の夢は「どんな負け戦でも最後の一人まで連れて帰る大将になる」。
- 又兵衛の最終成長は、一人で美しく死ぬことではなく、最後尾と責任を仲間へ渡し、自分も帰る一人に数えること。
- 長政を冷酷な裏切り者にしない。同じ約束を国家と制度で守ろうとする最大の理解者・対立者として描く。
- 官兵衛、半兵衛、秀吉、宗治、三成、家康、信繁らを主人公の引き立て役にしない。
- 各巻は表面目標を完結させ、その勝利自体から次巻の代価を生む。
- 戦闘は精神論だけでなく、地形、人数、武器、時間、疲労、情報差で決まる。
- 戦で壊される前に、町、食事、仕事、家族、祭りを描き、読者に守る価値を感じさせる。
