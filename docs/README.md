## 固定する創作正典

- 又兵衛が有岡城へ潜入し、官兵衛救出の現場を支える。
- 又兵衛が松寿丸の処刑偽装、移送、追手攪乱を主導する。
- 又兵衛が黒田方の非公式実働者として備中高松城と中国大返しへ参加する。
- 又兵衛が山崎で渡河路、鉄砲対策、長政隊の命令系統、明智軍の再集結阻止を担う。

史実人物の功績は消しません。又兵衛は歴史の決断者ではなく、決断を戦場で動く形へ変える実働者として描きます。

## 制作手順

1. `00`で年代、史実、創作正典、象徴を確認する。
2. `17`で前話、当話、次話を読む。
3. 対象巻に完成稿がある場合は、その完成稿を本文正典として読む。
4. 対象巻に制作脚本がある場合は、共通仕様と前話終了台帳を読んでから見開きを生成する。
5. `02`と`03`で人物の夢、欠落、対立を確認する。
6. `06`と`07`で技、負傷、道具、伏線を確認する。
7. `12`と`13`の設計ゲートを通す。
8. Stop Slopスキルを読み、本文を書く。
9. 直接性、リズム、読者への信頼、人間らしさ、密度を各10点で採点する。
10. 合計35点未満、受動態、抽象説明、定型反転が残る文章は書き直す。

## ぶらさない事項

- 又兵衛の夢は「どんな負け戦でも最後の一人まで連れて帰る大将になる」。
- 最終成長は、一人で美しく死ぬことではなく、最後尾と責任を仲間へ渡し、自分も帰る一人に数えること。
- 長政は同じ約束を国家と制度で守ろうとする最大の理解者であり、最大の対立者。
- 戦闘は地形、人数、武器、時間、疲労、情報差で決まる。
- 戦で壊す前に、町、食事、仕事、家族を描く。
