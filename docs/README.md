# 『戦帰 SENKI』制作資料

このディレクトリは、全30巻・全240話を一貫して制作するための正典・物語設計・人物設定・制作工程をまとめたものです。

## 最初に読む3ファイル

1. [`00_canon/00_正典ルール.md`](00_canon/00_正典ルール.md) — すべての矛盾を裁く最上位ルール
2. [`00_canon/01_全体設計サマリー.md`](00_canon/01_全体設計サマリー.md) — 作品全体を短時間で把握する入口
3. [`04_production/01_制作憲法.md`](04_production/01_制作憲法.md) — 各巻・各話を作る際の品質ゲート

## 推奨読書順

### A. 作品全体を理解する

1. 正典ルール
2. 全体設計サマリー
3. 作品理念とテーマ
4. 全30巻・240話構成

### B. 第1巻から第14巻を作り込む

1. 第一大章「名なしの槍」全24話
2. 第1〜14巻「黒田黄金時代」
3. 第14巻「黒槍、再び」

### C. 各話を執筆する

1. 制作憲法
2. 対象巻の正典資料
3. 全240話・話別設計テンプレート
4. 執筆後に人物・年代・情報・負傷・道具・死・生活・象徴の台帳を更新

## フォルダー構成

```text
docs/
├── README.md
├── 00_canon/       # 最上位正典・全体要約
├── 01_story/       # テーマ・全30巻・伏線・世界観
├── 02_characters/  # 主人公級人物・敵将・成長体系
├── 03_arcs/        # 巻・章ごとの詳細設計
└── 04_production/  # 制作憲法・話別テンプレート
```

## 正典の優先順位

1. `00_canon/00_正典ルール.md`
2. `03_arcs/01_第一大章_名なしの槍_全24話.md`
3. `03_arcs/02_第1〜14巻_黒田黄金時代.md`
4. `03_arcs/03_第14巻_黒槍再起.md`
5. `01_story/02_全30巻240話構成.md`
6. その他の設定資料

`04_production`は物語内容を上書きしませんが、制作工程では必須です。ハードゲートに不合格が一つでもある話は、ネーム・脚本・小説本文へ進めません。
