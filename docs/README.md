## 改訂後の歴史軸

- 第1〜3巻：播磨、松寿丸の人質、有岡城、一族追放。
- 第4〜6巻：仙石秀久への仕官、戸次川敗戦。
- 第7〜10巻：百石で黒田家へ帰参、城井谷、長岩城、豊前統治。
- 第11〜13巻：文禄・慶長の役、晋州城、亀甲車。
- 第14〜15巻：関ヶ原、大隈城、一万石級の重臣。
- 第16〜18巻：官兵衛死去、長政との確執、1606年頃の出奔。
- 第19〜20巻：細川・池田、奉公構、京都・大和の浪人生活、帰参交渉不成立。
- 第21〜24巻：大坂入城、冬の陣、鴫野・今福、講和と堀埋立。
- 第25〜27巻：郡山周辺、寝返り工作、道明寺作戦と情報漏洩。
- 第28〜30巻：濃霧、国分先取、小松山約六時間、又兵衛戦死。

## 史実区分

- `[A]` 比較的確度が高い史実。
- `[B]` 有力説だが細部に異説がある。
- `[C]` 記録の空白へ置く創作。
- `[D]` 軍記、講談、地域伝承。

伝承を魅力的な場面として使用してよい。ただし、地の文で確定史実のように断定せず、噂、兵の証言、後世の講談、複数証言の食い違いとして描きます。

## 制作時の必須順序

1. `00`で年代、所属、史実区分、黒槍の状態を確認する。
2. `14`で史実・異説・伝承の境界を確認する。
3. `05`と対象巻の詳細資料を読む。
4. `12`のハードゲートを確認する。
5. `13`の話別設計カードを全項目埋める。
6. 執筆後に人物、年代、所属、情報、負傷、道具、死、生活、象徴の台帳を更新する。

## 絶対にぶらさない事項

- 又兵衛を1578年以降も黒田家へ連続在籍させない。
- 高松城、中国大返しを又兵衛本人の功績にしない。
- 黒田家帰参は仙石家と戸次川を経た後、百石級から再出発させる。
- 城井鎮房を又兵衛が直接殺害する構成にしない。
- 長政を突然の冷酷な裏切り者にしない。
- 官兵衛死去を、又兵衛と長政の間の通訳が消える事件にする。
- 奉公構と浪人生活を独立した大章として描く。
- 大和郡山城爆破、播磨一国、虎退治、傷跡五十三か所は伝承として扱う。
- 道明寺の敗北を又兵衛個人の無謀だけにせず、情報漏洩、濃霧、連絡不全、国分先取、兵力差で描く。
- 又兵衛は史実どおり戦死する。
- 最終成長は「一人で美しく死ぬこと」ではなく、自分も生きて帰りたいと認め、責任を仲間へ渡すこと。
