## 制作時の必須順序

1. `00`で年代、夢、史実、人物、黒槍の状態を確認する。
2. `12`のハードゲートを確認する。
3. 対象巻の正典資料を読む。
4. `13`の話別設計カードを全項目埋める。
5. 執筆後に人物、年代、情報、負傷、道具、死、生活、象徴の台帳を更新する。

## 今回の整合性修正で固定した重要事項

- 第1巻の又兵衛は16〜17歳前後［C］。
- 第1巻の救出対象は松寿丸と四十三人の村人。
- 兵糧は十二台中九台が到着する。
- 第1〜3巻は各8話、全24話。
- 第14巻は全体第105〜112話で、第二の第1巻。
- 第14巻の避難民は二十三人、荷車二台、負傷者四人。
- 高松城は、秀吉が信長の死を知り、秘して講和を急ぎ、宗治自刃と和睦を経て中国大返しへ進む。
- 又兵衛は城井鎮房の直接殺害者にしない。
- 甚六は第13巻で死亡し、第14巻以降も生存させない。
- 右肩の傷は消えず、低い水平構えと仲間との連携へ変わる。
- 第14巻の黒槍贈与は、長政の信頼と監視の両方を含む。
- 最終成長は、一人で美しく死ぬことではなく、自分も守られる一人に数え、責任を仲間へ渡すこと。
