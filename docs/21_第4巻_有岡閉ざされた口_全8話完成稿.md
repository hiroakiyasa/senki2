## 第25話　帰らぬ軍師

| 項目 | 内容 |
|---|---|
| 視点 | 後藤又兵衛 |
| 表面目標 | 日没までに官兵衛の帰還または確かな所在を得る |
| 即時質問 | 官兵衛は自分の意思で有岡へ残ったのか |
| 選択 | 単騎で有岡へ走らず、仲間へ道・馬・書状の検分を任せる |
| 不可逆な変化 | 官兵衛は「帰還待ち」から「離反の疑い」へ移され、黒田家中の門が閉じる |
| 次話への代価 | 忠誠を紙で示す誓紙が回り始める |

姫路の黒田屋敷で、官兵衛の膳だけが三度温め直された。

麦飯、蕪の汁、干した小魚。昼には湯気の立っていた汁へ薄い膜が張り、炊事場の女が鍋へ戻すたび、椀の縁に白い跡が増えた。

官兵衛は朝、有岡城へ向かった。荒木村重を翻意させ、日が落ちる前に帰ると言い残した。供は少ない。大勢を連れれば説得ではなく威嚇になる、と官兵衛自身が決めた。

又兵衛は門の外を見続けていた。

焼け槍は壁へ立ててある。若党の仮札は腰に下げている。橋砦の頃なら、止める者の手を振り払い、もう馬へ乗っていただろう。

二度目の鐘が鳴った。

「まだか」

又兵衛が言うと、速水弦太は炊事場から顔を出した。口の端に飯粒が一つ付いている。

「帰ってきたら食う飯を、お前が先に減らすな」

「味見や。三回温めた汁は塩が濃うなる」

槙島甚六が門の閂へ肩を当てた。夕刻から夜番へ替わる時刻だった。狭間清十郎は門脇で、出入りした者の名と馬の数を書いている。

道の向こうから、一騎が来た。

又兵衛は泥へ飛び出した。馬上に官兵衛はいない。有岡へ随行した小者が、鞍へしがみつくように伏せていた。顔は灰色で、右の袖が裂けている。

「官兵衛殿は」

小者は返事より先に、懐から折った書状を出した。

栗山善助が受け取った。封は官兵衛のものだった。短い文面に、荒木方との話が長引くため当分有岡へ留まる、とある。

家臣の一人が息を吐いた。

「留まる、か」

別の者が口を挟んだ。

「村重へ付いたのではないか」

その言葉を誰も叱らなかった。

又兵衛は小者の胸倉をつかんだ。

「どこで別れた」

「城の内です。御前は、村重殿ともう一度話すと」

「自分で残ったんやな」

「門を出る時、後ろから閉められました」

又兵衛の手が止まった。

弦太は馬の腹へ手を当てた。汗は冷え、腹帯の下へ白い泡が乾いている。左の後脚だけ、黄土色の泥が蹄の上まで付いていた。

「真っすぐ帰ってへん」

「何が分かる」

「有岡から姫路まで同じ道なら、四本とも似た泥になる。この馬、北へ回されとる。それに水を二度飲んだ腹や。半日はどこかで止められた」

清十郎は書状を灯りへ透かした。

「文字は官兵衛殿です。ただ、墨が三か所で切れています。いつもなら一息で書く長さです」

「脅されて書いたと言うのか」

栗山が尋ねた。

「そこまでは書けません。手を止める者が傍にいた可能性はあります」

又兵衛は門脇の焼け槍を取った。

「確かめてくる」

甚六が門の前へ立った。

「夜門を閉める」

「開けろ」

「善助殿の命令や」

「官兵衛殿が閉じ込められたかもしれん」

「だから、残った者まで外へ散らさん」

又兵衛は甚六の肩を押した。甚六は動かなかった。橋砦で盾を背負っていた頃より、胸板が厚くなっている。

「退け」

「一人で行って、門の数も兵の数も分からんまま捕まったら、次に誰が探しに行く」

又兵衛は答えられず、槍の柄を強く握った。

母里太兵衛が槍の穂先を片手で押し下げた。

「走るのは、考えた後でもできる」

「考えとる間に死んだらどうする」

「お前が増えれば、助ける人数が一人増える」

門が閉じた。閂の木が受け金へ落ち、腹へ響く音を立てた。

又兵衛はその場へ残った。弦太には馬が通った道と止められた場所を追わせ、清十郎には書状の語尾と過去の文を比べさせた。甚六には今夜の門番を一人も欠かさず数えさせた。

自分は何もしていないように思えた。槍を持って走るより、待つ方が身体へ悪かった。

夜半、炊事場の女が官兵衛の膳を下げようとした。

栗山が止めた。

「捨てるな。朝までは」

女は冷えた椀へ木蓋をかぶせた。

同じ頃、門番の名簿では、官兵衛の帰着欄が空白のまま閉じられた。隣へ小さく、墨で二文字が加わった。

――所在不明。

## 第26話　誓紙

| 項目 | 内容 |
|---|---|
| 視点 | 後藤又兵衛 |
| 表面目標 | 正午までに後藤一族の誓紙を納め、家の出入りと兵糧を止めさせない |
| 即時質問 | 又兵衛個人の忠誠を、一族から分けて認めさせられるか |
| 選択 | 一族の代表印がないまま、自分の名だけを余白へ書く |
| 不可逆な変化 | 個人の名は残るが誓紙として受理されず、後藤家の仮札・武器・兵糧が預け置きになる |
| 次話への代価 | 又兵衛の家は、味方の内側にいながら監視対象になる |

翌朝、長い誓紙が黒田屋敷の広間を一周した。

紙は新しかったが、硯の水は濁っていた。名を書き終えた者が次の者へ回し、家ごとの印を押す。筆を持つ指に傷のある者は、家族へ代筆させた。

文面は短い。

黒田官兵衛が荒木方へ通じたとの風聞に従わず、黒田家へ忠節を尽くす。敵方と私に文を交わさず、疑わしい縁者があれば届け出る。

栗山善助が、書面の端を押さえていた。

「疑いを消す紙やない」

誰も尋ねていないのに、栗山は言った。

「疑いが出ても家中を割らせんための紙や」

一軒ずつ名が埋まった。井上九郎右衛門の家、母里の家、古参の小者たち。又兵衛は自分の順番を待った。

後藤の欄だけが白かった。

一族の年長者、藤岡九兵衛が広間の外へ座っていた。後藤家と血のつながる男で、又兵衛が幼い頃から伯父と呼んできた。九兵衛の前に筆と硯が置かれている。筆先は一度も濡れていない。

「書け」

又兵衛は九兵衛の横へ膝をついた。

「分からんことを、知っとるようには書けん」

「官兵衛殿が裏切ったと思うとるんか」

「思うてへん」

「なら書けるやろ」

九兵衛は誓紙の文面を指でなぞった。

「有岡の町に、後藤の縁者が二人おる。鍛冶場へ奉公に出した者や。文が来ても届け出ろとある。城の内から助けを求める文でも、敵との私通になる」

「受け取らんかったらええ」

「お前は、助けを求める声を聞かんふりできるんか」

又兵衛は口を閉じた。

九兵衛は続けた。

「官兵衛殿が何を選んだか、わしは見てへん。村重殿が何を言うたかも知らん。知らんことへ血判を押して、あとで違うた時、誰が責めを負う」

「黙っとったら、今ここで全員が疑われる」

「せやから迷うとる」

九兵衛は強い声を出さなかった。それが又兵衛を余計に苛立たせた。

又兵衛は誓紙を引き寄せた。

「俺が書く」

栗山が手を置いた。

「後藤家の欄は、家を預かる者の印が要る」

「俺の忠義は俺のもんや」

「戦でお前が命令を破れば、後藤家の所領と家族が罰を受ける。敵が後藤の名で門をくぐれば、お前一人を斬って済まん。家中は人を家ごと数える」

「それで、俺が何をしても九兵衛が書かんかったら同じか」

「今は同じや」

又兵衛は筆を奪った。後藤の欄の下、折り目ぎりぎりの余白へ、自分の名を書いた。

後藤又兵衛。

墨が紙の裏までにじんだ。

栗山は消さなかった。受け取ったとも言わなかった。名の周りへ細い四角を引き、横へ「個人」と小さく記した。

「これで俺は入れるな」

「後藤家の誓紙は未提出のままや」

正午、後藤家へ三つの命令が届いた。

屋敷内への仮札を預けること。支給兵糧を半分にすること。家の武器を門番へ預け、許可なく持ち出さないこと。

又兵衛は門の武器棚へ焼け槍を置いた。父の槍は、華やかな長槍の間で煤けた棒のように見えた。

門兵が札を差し出した。

「受け取り札や」

又兵衛は木札を取らなかった。

「自分の槍を預けて、預けた証まで持たされるんか」

「証がなければ、返せん」

又兵衛は木札をつかんだ。

門を出る時、背中が軽かった。身軽になったとは思えなかった。

広間では誓紙が巻かれた。九兵衛の欄だけが白く、又兵衛の名だけが折り目の外へ残った。

## 第27話　疑われた家

| 項目 | 内容 |
|---|---|
| 視点 | 後藤又兵衛 |
| 表面目標 | 日暮れまでに家族の兵糧と出入りを戻すため、個人離脱の願書を出す |
| 即時質問 | 一族から自分の名を切り離せば、母と妹を守れるか |
| 選択 | 一族を捨てる願書を出さず、仲間へ調査を分け、自分は監視対象のまま残る |
| 不可逆な変化 | 又兵衛は公的な門と軍議へ入れなくなり、非公式に動くしかなくなる |
| 次話への代価 | 官兵衛側の情報を得るには、有岡城内の視点が必要になる |

後藤家の門へ、黒田の見張りが二人立った。

槍を構えず、道端で焚き火をしている。お常が井戸へ行けば一人が後ろへ付き、お菊が薪を拾いに出れば、もう一人が立ち上がった。

又兵衛は帰宅すると、焚き火へ足を向けた。

「家の前から退け」

お常が袖をつかんだ。

「見張りにも腹はある」

薄い粥を二椀よそい、戸口へ置く。兵は三度断った後、椀を受け取った。

「食わせたら疑いが晴れるんか」

「晴れへん。追い返されたと嘘を書く理由を減らすだけや」

後藤家の粥は、米より水の方が多くなった。

お常が木杓子を鍋の底へ当てる。ざらりと鳴った。昨日までなら三度すくえた量が、今朝は二度でなくなった。

弦太は戸口へ座り、残った粟を指で量った。

「このままやと五日。見張りにも朝夕食わせたら四日」

お菊が言った。

「兄ちゃんが食べへんかったら」

「一日だけ延びる」

弦太は正直に答えた。

又兵衛が睨むと、弦太は腰の袋から干し大根を半本出した。

「虫に食われとった。捨てるのも惜しいから持ってきた」

大根に虫穴は一つもなかった。

甚六は壊れてもいない戸の蝶番へ油を差した。清十郎は土間の隅で、有岡から姫路までの道を紙へ写している。三人とも後藤家へ出入りすれば、自分の名まで疑われると知っていた。

「帰れ」

又兵衛が言った。

弦太は鍋の匂いを嗅いだ。

「薄い飯を一人で食う方が、よっぽど怪しい」

「俺に付き合う必要はない」

甚六が戸を二度開け閉めした。

「付き合うかどうかは、こっちで決める」

清十郎は筆を止めなかった。

「門の記録では、昨日から後藤家へ来た者の名も取っています。もう帰っても消えません」

又兵衛は腹が立った。ありがたいとも思った。その二つを口に出すと負ける気がして、何も言わなかった。

懐には願書が入っていた。

後藤一族の判断と自分の忠節は別である。一族の所行について連帯の責めを負わず、黒田家へ個人として仕えることを願う。

井上九郎右衛門が文面を整えてくれた。これを出せば、又兵衛だけは仮札を返される可能性がある。又兵衛が働けば、その俸から母と妹へ食わせられる。

昼前、九兵衛が来た。

袖から、小さく畳んだ紙を出した。有岡の鍛冶場へ奉公に出た縁者からの文だった。

城下の門は閉じられ、商人の荷まで調べられている。荒木方は米と炭を集め、鍛冶場へ矢尻と門金具を急がせている。出たい者の名を取る一方、家族を城内へ残さなければ通行札を出さない。

文の最後に、短くあった。

――子が熱を出した。薬を頼む。

「これを届け出たら、書いた者は敵方の間者として捕まる」

九兵衛は言った。

「捨てたら、薬を待つ子が一人減る」

「だから誓紙を書かんかったんか」

「それだけやない。官兵衛殿を信じることと、見てへんことを見たと言うことは別や」

又兵衛は願書を出した。

「俺は家を抜ける」

お常の杓子が止まった。

九兵衛は紙を読んだ。怒りもせず、又兵衛へ返した。

「抜けたら、お前の母と妹への疑いが晴れると思うか」

「俺が黒田の中で働けば、飯は持って帰れる」

「後藤を捨てた男が持ってくる飯を、黒田方が後藤家へ入れさせるか」

又兵衛は答えを探した。

門の外では、家族も一人ずつ数えられていなかった。後藤という一つの名で、鍋の底まで浅くされた。

お常が粥を四つの椀へ分けた。自分の椀だけ少なくしたのを、誰も指摘しなかった。

「父ちゃんが帰らんかった日も」

お常は鍋を水ですすぎながら言った。

「残った者が、帰らんかった者の分まで疑われた。戦は、家へ帰ってからも人数を間違える」

又兵衛は願書を折り直した。

黒田屋敷へ向かった。門前の受付へ出すつもりだった。だが門脇の札掛けに、後藤家の名があった。

味方の札でも敵の札でもない。

「預かり」と書かれ、その下へ、お常、お菊、九兵衛、又兵衛の名が並んでいる。

自分の名だけを抜けば、三人が残る。

又兵衛は願書を出さなかった。紙を開き、裏へ有岡までの道を書き始めた。

「弦太、荷車を追え。城へ入る米と薬の道を見つけろ」

「命令されんでも行く」

「清十郎、官兵衛殿の過去の書状を全部見比べろ。水と井戸の言葉だけ抜け」

「入れる文庫が限られています」

「入れる者に頼め」

「甚六、門番の交替と、見張りが薄くなる刻を」

甚六は首を振った。

「お前の門やない。有岡の門を数える」

三人は別々の道へ歩き出した。

又兵衛は門前へ残った。仮札も槍も中にある。公式の軍議へ入れず、命令書も読めない。

その日の夕刻、札掛けの「預かり」の横へ、もう一枚の札が増えた。

――要監視。

門兵が、印のない紙を一枚だけ渡した。

> 有岡へ入る荷と、出ない荷を調べよ。黒田の名を使うな。

誰の命令かは書かれていない。又兵衛はその紙の裏へ、有岡へ入る荷車の車輪幅を書き足した。

## 第28話　荒木村重

| 項目 | 内容 |
|---|---|
| 視点 | 黒田官兵衛 |
| 表面目標 | 荒木村重へ開城または織田方との再交渉を選ばせ、自ら有岡を出る |
| 即時質問 | 村重の離反は、家臣と領民を守るための忠義なのか |
| 選択 | 村重の側へ立つ書状と押印を拒み、城内に囚われる |
| 不可逆な変化 | 官兵衛は客から囚人となり、外へ届く言葉を奪われる |
| 次話への代価 | 官兵衛は水と日課だけを使って生存を伝えなければならない |

有岡城の内側では、魚が売られていた。

朝の市に、鯉、干鰯、里芋が並ぶ。商人は値を下げろと怒鳴り、子どもは焼いた豆を袖へ隠した。土塁と堀に囲まれていても、町は町の顔をしていた。

ただし、門へ向かう荷は止められていた。

城兵が米俵へ木札を付け、炭の俵を数え、外へ出ようとする者の家族名を帳面へ書く。城主家の厩では六頭の馬へ新しい蹄鉄を打っている。町人の草鞋は、一戸につき二足までと決められた。

官兵衛はその様子を見ながら、荒木村重の座敷へ通された。

座敷は豪華ではなかった。壁際に兵糧帳が積まれ、畳へ泥の足跡が残っている。村重は鎧を着ず、袖をまくって米蔵の数を確かめていた。

「蔵は四つ。今の人数なら、麦を混ぜて四十日」

村重は帳面を官兵衛へ向けた。

「織田の軍が来れば、外の田は刈られる。門を開けても、家臣の妻子が人質に取られる」

官兵衛は帳面を閉じた。

「門を閉じれば、四十一日目に同じ妻子が飢える」

「四十日の間に、毛利も本願寺も動く」

「動くと確かめた使者は」

村重は答えなかった。

官兵衛は城へ来る前から、村重の恐れを読んでいた。信長は有能な者を使い、結果を急がせる。失敗した者へ二度目を与えない。その速さへついていけなければ、領地も家臣も削られる。

だが官兵衛は一つ読み違えた。村重は説得されるために会ったのではなかった。黒田官兵衛という知恵を、自分の城へ置けるか確かめていた。

村重が新しい書状を出した。

織田方の軍勢が領民と家臣を使い潰すため、荒木家は家を守って立つ。黒田官兵衛もその道理を認め、有岡へ留まる。

最後に、官兵衛の印を押す空白があった。

「お前が押せば、黒田もすぐ敵には回らん」

「私の子は織田方の人質です」

「だからこそ、黒田がこちらへ立てば軽々しく斬れん」

「黒田が立ったと見せた時点で、斬る理由を渡す」

村重は指先で畳を叩いた。

「では聞く。お前がわしなら、門を開けるか。ここに家臣の女房子がいる。町の商いも、寺も、鍛冶もある。信長へ従い続ければ、次の戦、その次の戦へ出される。残るのは名前だけや」

庭先で、子どもが転んだ。運んでいた薪が散り、城兵が拾うのを手伝った。

村重はその姿を見た。

「わしは、あれを守る」

官兵衛も見た。

「守るなら、出たい者の子を城へ残させるな」

村重の指が止まった。

「外へ出た者が敵へ道を売る」

「売る者を見分ける手間を捨て、全員の出口を閉じた。四十日後、誰がその子へ飯を渡す」

「黒田殿は、正しい者だけで城が守れると思うか」

「思わん。だが、出たい者を一人ずつ調べる手間を惜しめば、四十日分の米を内側の敵へ変える」

官兵衛は書状を押し返した。

村重の顔から、交渉の色が消えた。

「印を押さぬなら、外へは出せん」

「私を留めれば、黒田が疑われる」

「それで織田が黒田を斬れば、信長がどんな主か皆に分かる」

「私の子で証明する気か」

村重は目をそらさなかった。

官兵衛は腹の底で、自分の誤りを認めた。人の恐怖を読めば動かせると思っていた。村重は恐怖を捨てず、その中へ城と家族を丸ごと入れた。

官兵衛は押印を拒んだ。

村重は立ち上がり、近習へ命じた。

「客の間を替えろ。筆も文も持たせるな」

城内の奥へ連れていかれる途中、官兵衛は水汲みの列とすれ違った。桶を担ぐ者は二十七段の石段を下り、東の低い方へ消える。桶の底から落ちた水が、土の溝を流れていた。

官兵衛は歩数を数えた。

曲がり角を三つ。下りが二十七。湿った風は右から来る。

最後の戸が閉じる直前、市の鐘が聞こえた。

牢の上で、魚売りがまだ値を争っていた。

官兵衛は暗がりへ座り、水の音を待った。

## 第29話　牢の水

| 項目 | 内容 |
|---|---|
| 視点 | 黒田官兵衛／後藤又兵衛（場面交替） |
| 表面目標 | 官兵衛は三日以内に生存と牢の位置を外へ伝え、又兵衛はその合図を見つける |
| 即時質問 | 口を塞がれた者は、日課と水だけで真実を送れるか |
| 選択 | 官兵衛は水汲みの少年を命令で使わず、逃げ道を教えた上で伝言を託す。又兵衛は証拠を家中へ公表せず、伝言経路を守る |
| 不可逆な変化 | 又兵衛、弦太、清十郎、甚六だけが官兵衛の生存と東側排水路を知る |
| 次話への代価 | 生存証拠を隠したまま、松寿丸の処刑命令へ対処しなければならない |

牢の中では、朝と夜が水の回数でしか分からなかった。

桶が来るのは一日二度。戸の向こうで鎖が擦れ、木の底が石へ当たる。水汲みの足音は二人分だったが、三日目の朝から一人が軽くなった。

官兵衛は壁へ背を預けた。腰から腿へ鈍い痛みが広がる。横になれば床の水が袖へ染み、座れば脚が痺れた。牢は七歩で端へ届く。上の明かり取りから落ちる光は、昼でも手のひら一枚ほどだった。

戸が開いた。

桶を運んできたのは、十二、三の少年だった。初日にいた大人の水番は外へ残り、少年だけが中へ入る。腕が細く、桶の縁が腰骨へ当たるたび顔をしかめた。

官兵衛は水椀を受け取った。

「名は」

少年は答えなかった。

「答えるなと言われたか」

小さくうなずいた。

官兵衛は椀を半分飲み、残りを桶へ戻した。

少年の目が動いた。

「薄めても増えません」

初めて口を開いた。

「お前の家で使え」

「囚人の水を持ち帰ったら叱られる」

「なら、桶を洗う水に混ぜろ」

少年は迷い、戸の外を見た。

「妹が熱を出しています」

「薬は」

「町の外から入らん」

官兵衛は自分の下着の袖を裂いた。乾いている内側を細く切り、三つ折りにする。少年が後ずさった。

「何も書いてへん」

「書けば見つかる」

官兵衛は布の端へ爪を立て、短い裂け目を四つ、少し離して三つ作った。橋砦で又兵衛たちが帰した四十三人。その数を官兵衛は何度も又兵衛から聞かされていた。

布の反対側へ、もう一つだけ裂け目を入れた。

「町の東に、薬を売る荷車が来る。丸い顔で、食べ物の匂いを先に嗅ぐ若い男を探せ」

「見つからなかったら」

「布を捨てて、妹の額を拭け」

「持って行けとは言わんのですか」

「お前の家が先や」

少年は布を握った。

官兵衛は続けた。

「伝えられるなら、言葉は一つでええ。冷えた椀を、まだ捨てるな」

少年は意味を尋ねなかった。布を水桶の担ぎ縄の下へ押し込み、戸を出た。

その日の夕方、東の排水口から流れる水へ、細い藁屑が増えた。

城外では、弦太が薬商の荷車へ干し生姜を積み替えていた。後藤家の札では有岡へ近づけない。弦太は商人へ荷役代を値切られ、代わりに荷車の下へ潜り込める仕事を得た。

「車軸が鳴る」

商人が言った。

「水をかけたら余計に割れる。油や」

弦太は答えながら、門へ入る水桶の数を見た。朝は十二、夕方は十四。二つ増えた桶だけ、底に黒い泥が付いている。城の東側、低地の水を汲んだ跡だった。

清十郎は少し離れた寺の縁で、官兵衛の過去の書状を並べていた。

「井戸」「水」「東」。有岡から届いた文にだけ、その三つが不自然に固まっている。

甚六は城下外周の門を一巡し、見張りの交替を数えた。市の鐘が二度鳴る前、東の土塁では荷の検めが薄くなる。兵が夕餉へ替わるためだった。

又兵衛は、排水の流れへ手を入れた。

秋の水は冷たかった。指先がすぐに痛くなり、泥の中で感覚が鈍る。流れてくるのは藁、魚の鱗、炭の粉。城の内側に町があるため、生活の屑と牢の屑を分けられない。

「何を探す」

甚六が尋ねた。

「官兵衛殿が捨てるもんや」

「捨てる物の形は」

「知らん」

又兵衛は夕刻まで水をさらった。爪の間へ泥が入り、右手の指が震えた。

弦太が薬荷を下ろして戻ってきた。袖の内から布切れを出す。湿っていた。

「東の市で子どもに渡された。丸い顔で、食いもんの匂いを嗅ぐ男を探せ言われたらしい」

「悪口まで合うとる」

弦太は笑わなかった。

布の端に、裂け目が四つと三つあった。

清十郎が数えた。

「四十三」

その反対へ一つ。

又兵衛は布を鼻へ近づけた。牢の湿気、木桶の匂い、人の汗。官兵衛が使う香も墨もない。それでも、言葉が残っていた。

「冷えた椀を、まだ捨てるな」

弦太が少年から聞いたまま伝えた。

官兵衛の膳を朝まで残したことを知る者は、屋敷の中でも少ない。四十三という数を、官兵衛は又兵衛の自慢話として何度も聞いていた。

「生きとる」

又兵衛は言った。

清十郎が布を取ろうとした。

「善助殿へ見せれば、離反の疑いを止められます」

又兵衛は手を引いた。

「この布がどこから来たか聞かれる」

「水汲みの子を隠して報告する」

「家中が動けば、村重も出口を探す。あの子と東の水路が先に塞がれる」

甚六が又兵衛を見た。

「黙れば、お前の家への疑いは残る」

「残す」

口にすると、胸の奥が熱くなった。正しいからではない。官兵衛の生存を最初に見つけたのに、誰にも言えない悔しさが混じっていた。

又兵衛は布を清十郎へ渡した。

「写すな。名も書くな。四人だけや」

「官兵衛殿を帰名帳から消すんですか」

「生きたまま守るために、今だけ書かん」

清十郎は帳面を閉じた。記録しないことを選ぶ指が、わずかに止まった。

夜、又兵衛は黒田屋敷の裏手へ回った。塀越しに炊事場が見える。官兵衛の膳は片づけられていたが、椀だけが棚の上へ伏せてあった。

又兵衛は泥の付いた小石を一つ、東の水路を描いた紙へ置いた。

生きている者の印だった。

## 第30話　処刑命令

|---|---|
| 視点 | 松寿丸／後藤又兵衛（場面交替） |
| 表面目標 | 又兵衛はその日のうちに処刑の実行時刻を知り、松寿丸へ手が届く連絡路を作る |

長浜の人質屋敷で、松寿丸の朝餉から小刀が消えた。

いつもは焼き栗の皮をむくため、膳の端へ小さな刃が置かれている。今日は箸と椀だけだった。廊下の番は二人増え、黒田から付き添っていた老僕は別室へ移されている。

松寿丸は何も聞かず、麦飯を三口食べた。

庭では、前日に降った雨が石鉢へ残っていた。門番の一人が、戸口の名札を外す。掃除のためではない。縄を通しやすいよう、釘まで抜いた。

松寿丸は箸を置いた。

「父上が、荒木へ付いたのですか」

番士は答えなかった。

「僕を斬れば、父上が戻るのですか」

若い番士の喉が動いた。年長の者が制した。

「若君は、お部屋に」

「若君と呼ぶなら、何が決まったか教えてください」

命令書は、まだ松寿丸へ読み聞かされていなかった。だが人質として暮らした二年で、少年は部屋の空気が変わる順番を覚えていた。刃物が消え、身近な者が離され、名札が外れる。人ではなく、処分する荷へ変える手順だった。

松寿丸は袖の内へ手を入れた。

欠けた椀の半片がある。食器としては使えない。角を布で包み、旅の間も持っていた。

「手紙を書かせてください」

「どなたへ」

「父上と、又兵衛へ」

年長の番士は目を伏せた。

「紙は出せません」

「では、覚えてください」

松寿丸は言った。

「僕は逃げません。逃げないから、老僕を戻してください。あの人まで罰する命令ではないはずです」

少年は自分の命を交渉の材料へ戻した。橋砦で、自分を人質にすれば村人を入れられると考えた時と同じ癖だった。

番士は返事をせず、戸を閉じた。

同じ日の昼、姫路へ処刑命令の写しが届いた。

信長は、官兵衛が村重へ同心したと見た。黒田の忠節を試すため、織田方に預けた子、松寿丸を処刑せよ。

広間で文を読んだ井上九郎右衛門の声が、一度だけ掠れた。

栗山は命令書を畳へ置いた。

「官兵衛殿を捜す兵を出せば、若君の処刑を早める。若君を奪えば、黒田家全体が反逆になる」

家臣たちの意見が割れた。

官兵衛はすでに荒木へ付いた。子を救って家を滅ぼすな、と言う者がいた。官兵衛が囚われているなら、先に主を救うべきだと言う者もいた。若君を失えば黒田の先が絶える、と机を叩く者がいた。

又兵衛は広間の外から聞いていた。仮札を預けたため中へ入れない。

「官兵衛殿は生きとる」

声を張ると、室内が止まった。

栗山が障子を開けた。

「誰が見た」

「見てへん」

「何を得た」

又兵衛は懐の布へ手を当てた。

「言えん」

「場所は」

「今は言えん」

家臣の一人が笑った。

「後藤の家を救うための作り話か」

又兵衛は土間へ上がろうとした。甚六が後ろから帯をつかんだ。

栗山は怒鳴らなかった。

「証を出せ。出せぬ証で家中は動かせん」

「出したら、証を運んだ者が死ぬ」

「なら、わしらは何を信じて若君の命を賭ける」

又兵衛は返せなかった。栗山の問いは正しかった。四人しか知らない証へ、黒田家全体を従わせることはできない。

広間の奥で、誰かが言った。

「二人ともは無理や」

その言葉が、又兵衛の胸へ刺さった。

弦太も同じことを言った。日が傾く頃、四人は後藤家の土間へ集まった。長浜までの道、有岡の東排水、処刑役が移動する日数を並べる。

「長浜と有岡は、同じ足で往復できん」

弦太は二本の指を離した。

「馬を替えても無理や。松寿丸様を先に動かしたら、有岡の水路が閉まるかもしれん。水路を先に探ったら、処刑役が着く」

「二人とも救う」

又兵衛が言うと、甚六が首を振った。

「言葉を増やしても、足は増えん」

清十郎は地図へ二つの時刻を書いた。

「同じ者が二か所へ行くから無理になります。人を分ければ、時刻は重ねられる」

又兵衛は地図を見た。

橋砦でも、五人が一つの場所へ固まった時は動けなかった。荷、道、盾、人数を分けて初めて四十三人を渡した。

それでも、松寿丸の傍へ自分が行きたかった。官兵衛の牢へも自分が入らなければならないと思った。

「半兵衛殿へ送る」

又兵衛は決めた。

官兵衛の布を、清十郎が別の紙へ写さず包み直す。伝言は短くした。

官兵衛生存。東の水。松寿丸の命令時刻を知りたい。

清十郎が尋ねた。

「善助殿には」

「まだ言わん」

「これで後藤の疑いを晴らせます」

「晴らしたら、水路が死ぬ」

自分の名を守る道を閉じるのは、槍で敵を止めるより難しかった。

その夜、長浜では松寿丸の部屋の外から名札が消えた。

松寿丸は欠けた椀を寝具の下へ隠した。取り上げられた時に割れないよう、布をもう一重巻いた。

姫路では、清十郎の使いが半兵衛へ向けて出た。

二人の名が、別々の場所で公の記録から消え始めた。

## 第31話　半兵衛の密使

| 項目 | 内容 |
|---|---|
| 視点 | 後藤又兵衛 |
| 表面目標 | 夜明けまでに半兵衛と役割を合意し、松寿丸を生かしたまま処刑済みとする骨格を作る |
| 即時質問 | 主君の命令へ背くことが、主君への忠義になり得るか |
| 選択 | 自家の疑いを晴らす機会を捨て、半兵衛の決断を守る秘密の実働者になる |

半兵衛は、薬売りの蓑を着て後藤家へ来た。

夜半を過ぎ、雨戸を二度、間を置いて一度叩いた。又兵衛が焼け槍の代わりに樫棒を持って戸を開けると、痩せた男が薬箱を背負って立っていた。

竹中半兵衛は蓑を脱ぐ前に咳き込んだ。袖で口を押さえ、音が収まるまで頭を下げた。

「軍師が一人で来る道やない」

又兵衛が言うと、半兵衛は濡れた草鞋を脱いだ。

「一人ではない。外に二人いる。家へ入れば、お前たちの粥が五人分になるから待たせた」

弦太が鍋の蓋を押さえた。

「もう水を足した後です」

半兵衛は薄い粥を一椀受け取った。湯気へ顔を寄せ、すぐには飲まなかった。冷えた指を椀で温めている。

お常は客の身分を尋ねなかった。薬売りの蓑を火の近くへ吊り、咳に効く干し大根の煮汁を出した。

半兵衛は一口飲んだ。

「長浜へ、処刑役が向かう。早ければ二日後の朝」

土間の空気が変わった。

「止められるんか」

又兵衛が尋ねた。

「止めると書けば、命令へ逆らった者が先に捕まる」

「なら、連れ出す」

「門を破れば、松寿丸が逃げたと全ての番所へ伝わる」

半兵衛は粥の椀を置いた。

「松寿丸は死んだことにする」

弦太の箸が止まった。甚六は戸口を見た。清十郎だけが筆を取ろうとし、半兵衛に手で制された。

「まだ書くな」

「代わりの首を用意するのですか」

清十郎が尋ねた。

「生きた子は使わん。戦場で身元の分からぬ遺体を借りる案はある」

「名のない死者を、若君の名で埋めることになります」

「名がないと決めるな。使うなら先に探せ。表の記録が松寿丸でも、裏の帳面へ本当の名を戻す」

清十郎は筆を置いた。偽りを作る役と、偽りの下から一人の名を掘り戻す役が、同じ手へ来た。

半兵衛は続けた。

「匿うと決めたのは私だ。私の家中で場所を用意する。命令に背いた責めも、まず私が負う」

「俺は何をする」

「死んだと信じさせる手順を作る。処刑役の人数、首実検の順、棺を誰が運ぶか、街道で誰が見たと証言するか。生きた子を隠すだけなら一晩でできる。死んだ記録を生かし続けるには、毎日誰かが嘘を支えなければならん」

又兵衛は長浜の地図を広げた。

「俺が松寿丸様を運ぶ」

「有岡の東水路は誰が入る」

「それも俺が」

半兵衛は又兵衛の顔を見た。叱るでも笑うでもなかった。

「お前は二人おるのか」

「馬を替えれば」

「官兵衛殿の牢へ入った後、同じ夜に長浜へ着く馬はおらん」

「順番を」

「順番を付けた時、後になった方が死ぬ」

又兵衛は黙った。

半兵衛は四人を順に見た。

「手を分けろ。時刻だけ合わせる」

弦太が地図へ荷車の印を置いた。

「松寿丸様を俵の下へ隠すなら、俵の数を減らしたら車の沈み方で分かる。人の重さと同じだけ別の荷を下ろす」

「処刑の報告は、実行者、見届け役、使者の三段です。三人全部を欺くより、報告が合流する前に文面を同じにする方が早い」

甚六は長浜屋敷の裏門を指した。

「人を出す門より、荷を出す門の方が狭い。狭い門は一人ずつしか見られん。交替の時に荷車を二台続ける」

半兵衛はうなずいた。

「松寿丸の道は、この三人と私の者で作る」

又兵衛は反発しかけた。

半兵衛が先に言った。

「お前は有岡へ入る。官兵衛殿を今すぐ連れ出すためではない。生存を自分の目で確かめ、牢までの水路と、後に家臣団が入れる門を探す」

「有岡が落ちる前に大勢で救出すれば、城内の人質も町人も巻き込む。栗山らが動ける刻まで、入口を死なせるな」

又兵衛は拳を握った。

「善助殿へ話す」

「今は話せん。官兵衛殿の生存が広がれば、信長様は松寿丸の処刑を確かめに人を増やす。村重は牢を替える」

半兵衛は言葉を柔らかくしなかった。

「ここで官兵衛殿の証を出せば、お前の名は戻る。その代わり、子と父の出口が閉じる」

お常が空いた椀へ湯を足した。

「帰ってから言えることは、帰ってから言い」

又兵衛は半兵衛へ向き直った。

「証は出さん」

半兵衛は一度だけ目を閉じた。

「では、私もお前の名を記録へ残せん」

「松寿丸様が生きるならええ」

言い切った後で、胸が痛んだ。名など要らないとは思っていない。欲しいまま手放すから、代価になった。

半兵衛は薬箱の底から、二枚の紙を出した。

一枚は長浜の人質屋敷。裏門、井戸、台所、荷蔵が描かれている。もう一枚は白紙だった。

半兵衛の手が、紙を押さえながら細かく震えた。咳をこらえているのか、熱のためか、又兵衛には分からなかった。

「一つは咳、もう一つは熱。どちらも私より先に、必要な者へ」

外で待っていた二人の供と、闇へ消えた。

土間には二枚の地図が残った。

片方には、十歳の子が閉じ込められた部屋がある。

片方には、まだ何も描かれていない。

又兵衛は白紙へ、東から流れる一本の水路を書いた。

## 第32話　二つの入口

次の夜まで、残り一日半だった。

後藤家の土間へ、石が十二個並んだ。

松寿丸、老僕、荷車を引く者二人、半兵衛方の案内三人、弦太、清十郎。残り三つは、道中で替わる御者、見届け役へ近づく者、第一の隠れ家で待つ者の印だった。

「多い」

甚六が言った。

「一人増えるたび、口も足跡も増える」

清十郎は三人分の印を一列から外し、道の三地点へ一つずつ置いた。

「案内は一区間ごとに替えます。全道程を知る者を作らない」

弦太が荷車の板へ米袋を載せた。人質屋敷の薬荷を模した車だった。松寿丸と同じほどの重さを、麦袋と水桶で作っている。

「人を入れた分だけ荷を下ろしたら、車輪の沈みは変わらん。ただし道が乾いたら、泥でごまかせん」

「明日の夜は雨や」

清十郎が空を見た。

「雲だけで決めるな」

弦太は湿った風を嗅ぎ、庭の蟻が土を上げているのを見た。

「夕方から降る。強うはない。轍が残るくらいや」

松寿丸側の入口は、人質屋敷の裏にある荷門と決まった。夕餉の薬荷が入り、空車が出る。門番の交替は暮れの鐘から半刻。二台を続け、最初の車へ検めを集める。二台目の底板の下に人を隠す。

処刑の偽装手順は、まだ完成していない。それは次に実行しながら詰める。ただし、移送に失敗した時の中止条件だけは先に決めた。

門番が二人以上、荷台へ手を入れたら戻る。追手が一刻以内に出たら、第一の隠れ家へ向かわず、川沿いで荷を替える。老僕が離されている場合、松寿丸だけを先に出さず、別の刻へ延ばす。

又兵衛は最後の条件へ指を置いた。

「若君だけ先に出せ」

甚六が手を重ねた。

「橋砦で、それをさせんかった」

「今は処刑役が来る」

「老僕を残して若君だけ出したら、若君は自分から戻る」

松寿丸ならそうする。又兵衛にも分かった。

「二人とも出す」

条件を書き直した。

有岡側は、紙の上だけでは決められなかった。東の排水路が人の通れる幅か、途中に格子があるか、水がどこまで上がるか。又兵衛は町外れの使われなくなった酒蔵で、同じほど狭い排水溝を探した。

入口は肩幅より少し広い。濡れた石に腹をつけ、縄を腰へ結んで進む。焼け槍と同じ長さへ切った竹竿を背へ負うと、先が天井へつかえた。

又兵衛は身体をひねった。竹竿を前へ回そうとする。石へ当たり、鈍い音が返った。

「音で見つかる」

清十郎が入口から言った。

「短く持つ」

「短くしても、曲がり角を通らん」

又兵衛はさらに進んだ。濡れた縄が腰で締まり、胸が石へ押された。片腕を前へ伸ばしたまま、引くことも押すこともできなくなる。

水が顎へ触れた。

「まだ行ける」

「戻れ」

甚六の声がした。

「格子まで見てへん」

「試しで詰まって死ぬな」

又兵衛は返事をせず、足先で壁を押した。身体が半寸も動かない。

腰の縄が二度引かれた。中止の合図だった。

「引くな」

三度目の合図と同時に、甚六と弦太が縄を引いた。濡れた衣が石へ擦れ、又兵衛は入口へ引き戻された。

外へ出ると、息を吸うたび胸が痛んだ。

「俺が戻る言うまで待て」

又兵衛が怒鳴ると、甚六は縄を解いた。

「お前が言えん場所やった」

竹竿の先が石へ当たり、縦に割れていた。

又兵衛は泥を拭った。父から受け取った焼け槍なら、追手が来ても戦えると思っていた。竹竿の割れ目は、その考えが水路の途中で自分と退路を塞ぐと示していた。

「槍は置く」

言葉が喉へ引っかかった。

甚六が割れた竹竿を受け取った。

「焼け槍は、戻るまで俺が持っとく」

「勝手に使うな」

「お前より先に欠かさん」

有岡の水路へ入る者は又兵衛一人。入口で縄を持つのは甚六。九兵衛の文を運んだ奉公人は、魚市側から木格子を上げる。二度引けば前進、三度で撤退。水位が膝を越えたら進まない。牢を見つけても戸を破らず、生存と道筋を確かめて戻る。追手を見たら、官兵衛へ近づかず入口を守る。

又兵衛は「連れ出さない」という条件へ、最後まで印を付けられなかった。

夕方、九兵衛が土間へ来た。

誓紙はまだ白いままだった。代わりに、有岡の縁者から届いた二通目の文を持っている。

東の魚市では、雨の夜だけ排水の木格子を上げる。魚の血と屑が詰まり、水が町へ戻るためだ。格子を上げるのは、暮れの鐘から一刻後。

「これを出せば、文を運んだ者が捕まる」

九兵衛は言った。

「せやから、お前にだけ渡す」

「誓紙は」

「まだ書けん」

又兵衛は九兵衛を責めなかった。紙へ名を書くことと、危険な情報を渡すことのどちらが忠義か、もう一つに決められなかった。

二枚の地図が完成した。

長浜の荷門は、暮れの鐘の直後。

有岡の木格子は、その一刻後。

松寿丸側が動き、報告の使者が街道へ出る頃、有岡では魚市の排水が開く。別々の場所で、見張りが日課へ気を取られる短い時間が重なった。

「同じ夜に始める」

又兵衛は言った。

「長浜は俺と清十郎、半兵衛殿の者で動かす」

弦太が答えた。

甚六は有岡の地図へ縄の端を置いた。

「俺はここで引く。入って、戻るまでが又兵衛の役目や」

弦太は土間の石を数えた。

「松寿丸様、老僕、御者、案内、俺と清十郎。十二」

清十郎が有岡側へ石を三つ置いた。

「官兵衛殿、水汲みの子、甚六」

「水汲みの子は、連れ出さん」

又兵衛が言った。

「なら、今夜出た者のうち、帰る人数は」

「官兵衛殿も今夜は連れ出さん。救出する人数は零や」

「救出の数やない」

弦太は又兵衛を見た。

又兵衛が答え直さないため、何も言わず小石を一つ取った。二枚の地図の間、又兵衛の手が届かない側へ置く。

又兵衛は気づかなかった。

夜になっても、門の武器棚から焼け槍を借り出す正式な許可は下りなかった。甚六は受け取り札だけを持ち、門番へ頭を下げた。

栗山善助が奥から出てきた。

「何に使う」

甚六は答えられない。

又兵衛が前へ出た。

「俺が戻るまで、甚六が持つ」

「どこから戻る」

「言えん」

栗山はしばらく又兵衛を見た。

やがて武器棚の鍵を開けた。ただし仮札は返さなかった。命令書も渡さなかった。

「黒田家は、お前へ任務を命じてへん」

「分かっとる」

「失敗しても、家中の名は出せん」

「分かっとる」

栗山は焼け槍を甚六へ渡した。

「それでも、借りた物は返せ」

又兵衛は返事をせず、槍へ一度だけ触れた。

長浜では、松寿丸の部屋の閂が下りた。

有岡では、牢の水が石溝を流れた。

後藤家の土間では、二本の縄が別々の輪に巻かれていた。一本は荷車を縛るため。一本は水路から人を引き戻すため。

又兵衛は二枚の地図を重ねず、並べた。

「次の夜、二つとも開ける」

弦太が置いた一つ余分な小石だけが、灯りの外へ残った。

# 第4巻終了時の台帳

## 人物

- **後藤又兵衛（十八歳）**：官兵衛の生存と東排水路を突き止める。後藤一族の誓紙が未提出のため仮札と公的信用を失う。松寿丸側を仲間と半兵衛方へ任せる一方、有岡の水路は自分一人で入ると決める。名を欲しながら、二人の出口を守るため功を名乗らない道へ入った。
- **松寿丸**：処刑命令の対象となり、人質屋敷で名札と身近な者を外される。自分の命を交渉材料にする癖が残る。欠けた椀の半片を保持し、偽装計画の詳細は知らない。
- **黒田官兵衛**：荒木村重への説得に失敗し、有岡城内で囚われる。村重の恐怖を読めば動かせるとの自負が外れた。水汲みの少年へ選択権を残して伝言を託し、生存と東側の位置を又兵衛たちへ知らせた。
- **竹中半兵衛**：松寿丸を匿う決断と責任を自ら引き受ける。又兵衛へ、手を分けて時刻を合わせるよう求める。保護の決断者は半兵衛、偽装・移送・追手攪乱の実働は又兵衛たち、という役割が成立した。
- **荒木村重**：信長に従い続ければ家臣と領民が使い潰されると考え、有岡を閉じる。町、家臣、家族を守る合理的な願いを持つが、出たい者の家族を城内へ残させ、出口を閉じることで願いを傷つけ始める。
- **栗山善助**：家中を割らせないため誓紙と監視を進める。又兵衛の無根拠な断言を受け入れず、証拠を求める。巻末では任務を公認しないまま焼け槍だけを貸し、家の規律と個人への信頼を両立させようとする。
- **藤岡九兵衛 `[B/C]`**：後藤一族の代表として誓紙への署名を保留する。知らない事実へ誓えないこと、有岡の縁者から届く助けの文を敵方との私通として差し出せないことが理由。後藤家への疑いを深める一方、東魚市の木格子情報を又兵衛へ渡す。
- **速水弦太**：使者の馬、薬荷、水桶、荷車の沈みを読み、二地点の作戦を重量と時刻へ落とす。又兵衛が自分を帰還人数へ入れていないと気づき、黙って小石を一つ加える。
- **狭間清十郎**：書状の筆勢、命令書の報告経路、地図を担う。官兵衛の生存証拠を記録しない選択を初めて行い、記録が人を守る場合と、記録しないことで守る場合の矛盾を抱える。処刑偽装では、無名遺体の本当の名を裏の帳面へ戻す役も担う。
- **槙島甚六**：門、交替、中止条件、縄の撤退合図を決める。又兵衛の命令を待たず水路の試験から引き戻し、実行時も有岡側の出口で縄と焼け槍を預かる。又兵衛が帰れない時に止める役割を、自分の判断で引き受ける。

## 道具と象徴
