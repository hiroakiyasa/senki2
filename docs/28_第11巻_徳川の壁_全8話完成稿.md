# 第11巻終了時の台帳

## 人物

- **又兵衛**：山崎・賤ヶ岳後も所属と功績が曖昧なまま、仙石家の若者を中心とする五十二人の臨時救援組を預かる。小牧山の正面攻撃を退け、本多忠勝の位置取りに一合も交えず止められる。白山林では武功を焦って反撃を命じ、宗吉・平次を失う。長久手では池田の旗を立てるより負傷兵を運び、追撃命令へ従わず六十三人を楽田へ帰す。撤退判断を得た一方、四国の「先陣」という字へ目を奪われる武名欲は残る。
- **速水弦太**：五十二人分の兵糧、井戸、馬草、荷車を管理する。徳川方の精米、馬糞、替え草鞋から、家康が動かずに軍を保つ仕組みを読む。帰陣者を六十三人と数え、又兵衛を抜くことを許さない。次巻の渡海準備で水桶と船荷を数え始める。
- **狭間清十郎**：三河路の高低差と水場を正確に描くが、村人の走り継ぎを地図へ入れられなかった。白山林以降は命令書の古さ、伝令の到着時刻、死者の所属を記録する。与七の死地と死因を断定せず、「分からない」と記録へ残す。
- **槙島甚六**：又兵衛の最初の反撃を止めきれず二人を失う。以後、盾、畦、荷車、人数を使って退路を作る。最後尾を又兵衛一人へ渡さず、農道から楽田まで戻る。又兵衛の独走を止める役割が、命令ではなく生存手順へ変わる。
- **黒田官兵衛**：三河中入りの決定者にはしない。又兵衛へ二万が詰まる場所を調べさせ、敗戦後は撤退権限と報告経路を対で設計すべきだと秀吉へ進言する。家康を小牧山で倒すより、織田信雄との結び目を政治で削る道を示す。
- **黒田長政**：又兵衛が自分を帰陣人数から外したことを見抜く。仙石家の兵である宗吉ら五人を黒田側の帳面にも記し、幼い頃の「帰ってきた者を追い出さない場所」という夢を記録の行動へ移す。
- **仙石秀久**：又兵衛へ五十二人を預け、攻め口を形のある報告として持ち帰らせる。先駆けと武名を求める若者へ機会を与える一方、その価値観が白山林で又兵衛の焦りを強める。巻末、四国出陣の先陣を告げる。
- **徳川家康**：土塁、堀、連砦、交代、井戸、草鞋、誤報への対応で小牧山を保つ。長久手の戦術的勝利後も秀吉との正面決戦へ戻らず、兵を小牧山へ帰す。又兵衛にとって「動かないことを選び続ける大将」の最初の完成形となる。
- **本多忠勝**：竹藪の補給路と撤収時の渡りを守り、又兵衛の攻め筋を位置だけで消す。又兵衛を追って武功を増やさず、自分へ与えられた場所から出ない。個人武力の頂点を、派手な一騎討ちではなく無駄のない判断で示す。
- **宗吉・平次・庄八・伊作・与七 `[C]`**：五十二人の臨時救援組から出た戦死者。宗吉と平次は又兵衛の性急な反撃、庄八と伊作は池田の旗周辺、与七は兄を探して隊列を離れたことで死ぬ。五人を「又兵衛の夢を強くするための美しい死」にせず、命令、旗、家族、情報の不足へそれぞれ接続する。
- **新田藤六・藤五・新八 `[C]`**：他隊から収容した兵。藤六は生還。藤五と新八は退却中に死亡し、所属と名前だけを楽田へ帰す。

## 負傷

- **又兵衛**：白山林の転倒と打撲、左前腕の浅い裂傷。農道で荷車を梃子上げした際に右肩の筋を一度痛めるが、巻末までに腕は上がり、恒久的な後遺症はない。上位正典で第16〜17巻へ置かれる右肩の本傷を先取りしない。
- **甚六**：白山林で盾越しに右脇を打撲。農道退却では歩ける。脚の重傷はまだ負わない。
- **弦太**：夜間行軍と荷車押しで両足に血豆。戦闘能力ではなく歩調管理へ影響する。
- **清十郎**：桧ケ根の鉄砲音で一時的に右耳が聞こえにくくなる。巻末までに回復。
- **新田藤六**：右腿の矢傷。池田旗の裂け布で止血され、生還する。

## 道具と象徴

- **焼け槍／継ぎ槍**：又兵衛が所持。黒槍ではない。小牧山では攻め口の深さを測り、長久手では人の流れを分け、農道では荷車を持ち上げる。敵将を討つより、地面と荷重へ使われる。
- **黒旗**：中国大返しから複数人が持つ無紋の黒布のうち一本を使用。白山林で高く掲げず、畑へ抜ける低い退路標識とする。落伍兵収容から、敗戦時の出口へ意味が広がる。
- **五十二枚の木札**：仙石秀久から渡される。五人分は帰名帳へ挟まれ、与七の札は破片だけが戻る。次巻の新規五人は、札を配る前に名前を聞く。
- **池田の旗布**：戦利品にしない。すでに裂けた下端を新田藤六の止血へ使う。池田家の旗そのものを又兵衛の所有物にしない。
- **小牧の地図**：表に土塁、連砦、三河路、伝令時刻を記す。巻末、裏面が四国渡海の水・干飯・馬草の積載表となる。
- **草鞋**：家康方では交代と補給、秀吉方では伝令の遅れ、死者の家へ送る五足では生活の継続を表す。
- **帰名帳**：宗吉、平次、庄八、伊作、与七、藤五、新八を追加。史実人物の死と創作兵の死を同じ筆致で混同せず、所属・時刻・確度を併記する。

## 情報

- 又兵衛は、小牧山が低い丘でも、二重土塁・堀・虎口・連砦・交代制によって正面攻撃を受けない陣になっていると知る。
- 又兵衛は、地図上の道が正しくても、村人が誰へ先に知らせるかで行軍の安全が変わると知る。
- 又兵衛は、本多忠勝を一騎討ちで越える以前に、忠勝の守る位置へ入れない。
- 又兵衛は、古い命令が本物の印を持ったまま届き、人を誤った方向へ動かすと知る。
- 秀吉は、又兵衛の救援を功として、無断退却を罪として別欄へ残す。又兵衛は褒賞を得ないが、五人の家への扶持米は出る。
- 家康は長久手で勝ったが、秀吉に野戦で屈服させられていない。秀吉は信雄との和議によって戦う場所を政治へ移す。
- 又兵衛は「退く命令」を出せるようになるが、報告経路を用意せず独断で完結させる欠点が残る。

## 第12巻への不可逆な条件

- 仙石家の臨時救援組は五人を失い、新たな五人を加えて再び五十二人になる。人数は戻るが、同じ隊ではない。
- 又兵衛の公式記録には、六十三人を帰した功と追撃命令違反が同時に残る。
- 又兵衛は撤退を選べたことで成長するが、四国で先陣の名を取り返したい欲を持ち込む。
- 弦太は渡海兵站、清十郎は海路と上陸地図、甚六は船から陸へ移る退路を準備する。
- 池田・森勢の敗北と家康の規律は、後の戸次川で「大将の焦り、長い隊列、遅い情報、失われる退路」を見抜くための前例となる。ただし又兵衛は、その前例を知っていても再び武名欲に負ける可能性を残す。
- 小牧の地図の裏面に四国の積載表が書かれ、第12巻『四国の海』第89話「海の先陣」へ接続する。

# 史実監査

## `[A]` 史料・自治体史等に基づき固定する事項

- 天正12年3月、家康・信雄方が小牧山を本陣として東へ連砦を築き、秀吉方が楽田を本陣として半円状に砦を置いたこと。
- 家康方が3月18日から22日頃までの短期間に小牧山を大改修し、二重の土塁・堀・虎口を整えたとされること。
- 4月6日夜、岡崎を目指す別働隊が出発し、その動きが篠木の住民らを通じて家康方へ伝わったこと。
- 4月9日、白山林で三好信吉隊が急襲され、木下兄弟が信吉を逃がして戦死したこと。
- 堀秀政隊が桧ケ根で家康方先遣隊を破った後、家康本隊の接近を知って退いたこと。
- 長久手で池田恒興・池田元助・森長可が戦死し、秀吉方が敗れたこと。
- 秀吉の救援主力が到着する前に家康が小牧山へ戻り、その後は大規模決戦が起きず、11月に秀吉と信雄の和議が成立したこと。
- 小牧・長久手を、単純な「秀吉の完全敗北」「家康の天下取得」とせず、長久手の戦術的勝利、戦役全体の政治的帰結、両者の別格化を分けて描くこと。

## `[B/C/D]` 本作で補う事項

- 又兵衛が小牧・長久手で五十二人の臨時救援組を率いた史料はないため、本巻の中核任務は創作 `[C]`。
- 仙石秀久がこの五十二人を直接預けた場面、官兵衛が又兵衛へ三河路調査を命じる場面、長政が戦死者を黒田の帳面へ記す場面は創作 `[C]`。
- 本多忠勝と又兵衛が竹藪、撤収路、和議後の道で接触する場面は創作 `[C]`。忠勝の「位置だけで又兵衛を止める」機能を優先し、史実上の一騎討ちとして扱わない。
- 宗吉、平次、庄八、伊作、与七、新田藤六、藤五、新八、味噌を売る老婆は創作人物 `[C]`。
- 池田の旗布を止血へ用いる場面は象徴上の創作 `[C]`。池田家の正式な旗の所在や伝来を改変しない。
- 徳川方の草鞋札、井戸札、村人の受取書、村から村へ情報が渡る具体的手順、和議後に五家へ扶持米を届ける場面は、史実の補給・情報優位を人物の生活へ落とす創作 `[C]`。
- 仙石勢と又兵衛の本戦上の配置は史料で固定せず、史実上の戦功や敗因を奪わない範囲の救援・退路任務として描く `[C]`。
- 戦場の人数、死者数、各隊の細部には史料差があるため、作中の五十二人・六十三人は主人公周辺の創作人数としてのみ固定する。

## 提出前の禁止事項確認

- 技名を叫ばせていない。
- 黒槍、恒久的な右肩後遺症、亀甲車、後世の五原則を先取りしていない。
- 家康を臆病な敵、秀吉を怒鳴るだけの総大将、長政を冷酷な制度役へ固定していない。

- 戦死者を又兵衛の成長材料だけにせず、命令、家族、旗、所属、扶持へ影響させた。
- 「退けば正解」という単純な結論にせず、撤退権限と報告経路の不足を次の課題として残した。
