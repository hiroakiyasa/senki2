## 2. 巻の完成形

### 表面目標

開戦の第一発までに、黒田家の返答を東軍の実働へ変え、又兵衛隊三百二十人・荷車十二台・火薬八櫃・水四桶を、友軍誤射なく固い二列目へ置く。

### 内面の問い

- 槍で届かない相手を、誰が、何で動かすのか。
- 書状と台帳は人を救うのか、それとも人を縛るのか。
- 一番手を失っても、人数・火薬・帰路を残せば勝ちと呼べるのか。

### 巻の外的勝利

- 吉川方への密書受領を確認する。
- 小早川方の未確定情報を確定戦力へ数えない。
- 黒田家の返書を家康本人の受領へ接続する。
- 十二家の友軍識別、二音応答、横縄停止、車軸縄、触覚結び、小黒旗分散を整える。
- 霧中の誤命令・誤射・行方不明を防ぐ。
- 第一発後も長政の手旗まで三百二十人を止め、全員の半歩をそろえる。

### 代価

- 黒槍組の一枚名簿は元へ戻らない。
- 又兵衛は政治書状の本文から外される。
- 種籾を守る代わりに軍の一日分が薄くなる。
- 替え馬一頭と荷車一台を置く。
- 霧中移動で兵二人が軽傷を負い、一番手を失う。
- 弦太・清十郎・又吉・小平・宗十郎の働きが、正式名簿では又兵衛一人の武名へ集まり始める。

## 3. 八話の因果鎖

1. **二通の返書**が黒田家中の裂け目を可視化する。
2. **横裂き密書**が、見える槍より見えない受領を戦力へ変える。
3. **三成の台帳**が、記録の救済と拘束を同時に示す。
4. **家康の書状網**が、返書だけでなく未着理由・受領者・時刻まで数える。
5. **東軍の槍**が、政治的返答を友軍識別・兵糧・停止条件へ翻訳する。
6. **大橋掃部**が、明日の決闘を個人技でなく間合い・交代制・救助対象の問題へ変える。
7. **霧の陣**が、前日の正しい地図を無効化し、又兵衛に判断訂正と槍の委託をさせる。
8. **撃ての合図**が、長政の調略と又兵衛の現場指揮を同じ第一歩へ接続する。

政治、兵站、制度、地形、槍術は別々の説明回にせず、前話で得た道具・傷・受領原則が次話の解決条件になるよう連鎖させた。

## 4. 主要な連続性更新

### 又兵衛

- 右肩は高く上がらず、黒槍の高い大振りを捨てて低い水平線を使う。
- 政治書状の本文を知らず、受領・護送・配置だけを任される苛立ちを抱える。
- 大橋掃部を追える機会より、斥候二人と土地の荷運び人を優先する。
- 自分の地図判断で兵二人を負傷させ、最短路を捨てて修正する。
- 宗十郎へ黒槍を百七十歩預け、礼を言って受け戻す。
- 第一発後も自分の本能を止め、三百二十人を長政の手旗まで待たせる。
- 掌に小さな火傷。右手指の軽傷はほぼ閉じている。

### 長政

- 吉川広家・小早川秀秋への調略功績を保持する。
- 吉川の受領を確定、小早川の空白を未確定として別管理する。
- 家康への黒田家返書を正式に送り、東軍側へ家の行動を固定する。
- 又兵衛へ全情報を渡さず、危険な現場と終了条件を渡す。
- 第168話で黒い手旗を下げ、調略を実戦命令へ変える。

### 三成

- 種籾、京枡、配給印、役目印を通じ、数えることが救済と動員を同時に生む人物として固定。
- 「数えなければ、消される人がいる。だから数える」を人物言語として使用。
- 冷たい帳面役ではなく、薄い配給を自分も食べ、来春の種を戻す。

### 黒槍組

- 一枚名簿は分割されたまま。
- 小黒旗が先頭、中央、火薬、救護、最後尾へ分散する。
- 二音応答、横縄停止、往復札、触覚結び、車軸二重縄が実働制度となる。
- 甚六本人は登場させず、点呼・退路・停止縄の習慣として残す。

### 大橋掃部

- 第21巻終了時点で生存。
- 又兵衛の右肩、短く前重心の黒槍、救助対象を優先する性格を知る。
- 又兵衛側は、大橋の半歩長い槍と二人交代制を知る。
- 決着と討死は第22巻へ送る。

## 7. 第22巻へのロック

第22巻第169話は、又兵衛隊が岡山東肩の二列目から前進路へ入る瞬間から始める。

第21巻では、次を描かない。

- 小早川秀秋の明確な下山と大谷勢への攻撃。
- 毛利・吉川勢が本戦で実際にどう動くかの確定。
- 大橋掃部の討死。
- 島津の退き口。
- 石田三成・大谷吉継の最期。
- 関ヶ原の勝敗、論功、黒田長政と又兵衛の戦後関係。

第22巻へ渡す具体条件は以下。

- 又兵衛隊三百二十人は二列目、火薬八櫃は乾燥、荷車は十一台。
- 右肩の可動制限、掌の小火傷、低い黒槍構え。
- 大橋の半歩長い槍・二人交代制と、又兵衛の右肩・救助優先を互いに認識。
- 小黒旗五節点、二音応答、北西土手の退路。
- 一番手を失った又兵衛の焦りと、先走りを止めた責任。
- 仲間の働きが又兵衛一人の武功へ集約される危険。

これらを消さず、関ヶ原本戦の勝利と代償へ接続する。
