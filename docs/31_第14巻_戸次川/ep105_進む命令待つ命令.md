# 『戦帰 SENKI』第14巻『戸次川』

## 第105話　進む命令、待つ命令

**時刻・場所**：天正14年12月11日夕刻〜夜半、豊後国府内近郊の仙石方陣所。  
**今回の問い**：同じ軍へ届いた「待て」と「進め」を、戦う前に一つへ揃えられるか。  
**次話へ送る代価**：又兵衛は反対しながら進軍命令を実務化し、悪い決定を止める者から動かす者へ変わる。

粟飯の湯気が消える前に、二人目の使者が陣へ入った。

一人目は西から来た。馬の腹まで泥をつけ、秀吉本軍の朱印を懐へ抱いていた。書状には、九州へ渡る大軍が整うまで島津方と決戦せず、府内と諸城を支えよとある。

二人目は戸次の方角から歩いてきた。馬を失い、草鞋の緒を血で固めている。鶴賀城からの訴えだった。城主利光宗魚が倒れたとの報があり、城は幾日も保たない。川を越えて島津勢を押し返してほしい。

二通は半刻も違わず届いた。

仙石秀久の陣幕では、濡れた書状を火鉢の左右へ置いた。片方には待てとあり、片方には今日来いとある。火鉢の向こうに長宗我部元親、信親、十河存保、大友方の使者が座った。誰も同じ人数を率いておらず、誰も全軍へ直接命じられない。

秀久は鶴賀城の書状を指で叩いた。

「城が落ちれば、府内まで道が開く」

元親は本軍の朱印を見た。

「渡った先で島津の本隊に食われれば、城と援軍を同時に失う」

大友方の使者が膝を進めた。

「待つ一日の間に、城内の者は死にます」

存保は黙っていた。火鉢へ差し出した手の爪に土が残っている。四国で元親と争い、敗れ、今は同じ陣へ座る男だった。軍議の前、彼は自分の味噌を兵の鍋へ入れさせていた。

「どちらの書状を、どの隊が受け取った」

存保が問うた。

返事が揃わなかった。

仙石勢の先手は進軍を聞いている。長宗我部勢の一部は待機を聞いた。大友勢は鶴賀城救援を急げと触れ回っていた。十河勢には、夜明けに川辺へ集まれという時刻だけが届いている。

陣幕の外でも、命令は兵の手を二つに割っていた。

出陣と聞いた足軽は濡れた火縄を懐へ入れ、飯を竹皮へ包む。待機と聞いた足軽は鎧を脱ぎ、薪を取りに行こうとする。同じ組の兄弟が、鍋を持つか槍を持つかで言い争っていた。

「俺らは、どっちを信じたらええ」

兄が又兵衛へ聞いた。

又兵衛は即答できなかった。どちらも本物の印を持ち、どちらも今日の命を数えている。

陣の外で、速水弦太が残りの粟を量っていた。全軍へ朝夕二度出せば三日。明朝に出れば、炊いた飯を腰へ結べる。待てば井戸と薪を確保しなければならない。

「命令が二つあると、米も二通り要る」

弦太は又兵衛へ、空になった升を見せた。

藤乃は鍋の隣で古い小袖を裂き、傷布へ変えていた。進めば矢傷が要る。待てば凍えた足と腹を診る。どちらの支度を先にするか、彼女にも命令は届いていなかった。

狭間清十郎は使者の出発時刻、到着時刻、通った道を二枚の紙へ書いた。一人目は途中の渡しで二刻待たされている。二人目は島津の斥候を避け、山際を回っていた。

「先に出された命令が、後から着いた」

清十郎が言う。

「着いた順に読めば、意味が逆になる」

槙島甚六は川筋の略図へ三本の退路を引いた。橋、浅瀬、上流の舟渡し。どれも全軍が一度に使える幅はない。

又兵衛は軍議の声を聞きながら、腰の焼け槍へ触れた。山崎では黒旗を見た兵が動いた。長久手では退却を進言し、四国では井戸と降伏兵を守った。それでも仙石家の席次では、決断する者より命令を運ぶ者に近い。

この軍を止められれば名が立つ。進むなら、帰れる形を作ってから進ませればよい。

又兵衛は陣幕へ入った。

「川へ出る前に、全隊へ同じ言葉を復唱させてください。誰が何を受けたか、印を取る」

秀久が見上げた。

「待てというのか」

「ばらばらに進むなと言うています」

「同じことだ」

信親が、二通の書状の間へ細い木札を置いた。

「進むなら、戻る合図を先に決めたい。仙石の法螺を土佐兵が聞き違えれば、川の中で列が向き合う」

又兵衛は頷いた。信親は戦う順より、退く時に誰の声を聞くかを先に尋ねた。

大友方の使者が、血の滲んだ草鞋へ目を落とした。又兵衛には、その足を前にして「明日まで待て」と言い切れなかった。

秀久は明朝の渡河を決めた。鶴賀城を救い、島津の先鋒を押し返す。元親は自家の祐筆へ反対の旨を記させた。清十郎はその時刻だけを自分の紙へ写し、信親は父の横で、各隊が退く時に使う旗印を確かめた。

又兵衛は進軍の触れを引き受けた。

甚六が陣幕の外で待っていた。

「止めるつもりで入って、渡る道を作って出てきたな」

「渡ると決まった。なら戻れるようにする」

「お前が戻すと言えば、悪い命令まで動く」

又兵衛は返事をせず、伝令を五人に分けた。清十郎が文面を一つにし、受け取った隊の小頭へ時刻を書かせる。弦太は明朝分の飯を握らせた。甚六は三つの退路へ印を置いた。

最初の四隊は、木札へ受領の傷をつけた。五隊目の大友組は「仙石の札へ印は押せぬ」と拒んだ。又兵衛は組頭の名だけを聞き、余白のまま戻した。命令の言葉を揃えても、命令する家は一つにならない。

夜半までに、進む命令は全隊へ届いた。

待つ命令は、又兵衛の懐に残った。
