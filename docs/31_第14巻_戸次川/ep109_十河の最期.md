# 『戦帰 SENKI』第14巻『戸次川』

## 第109話　十河の最期

**時刻・場所**：12月12日昼過ぎ、川下の冬田と細い畦。  
**今回の問い**：三十人幅の退路へ二百人を押し込まず、誰が残る順番を決めるのか。  
**次話へ送る代価**：存保は戦死し、全軍の命令権はさらに空白になる。又兵衛は四十六人の救援時間をもう一度使う。

十河存保の陣から、法螺が三度鳴った。

三度の法螺は、散った者へ自分の位置を知らせる鳴らし方だった。

存保の旗は川下の畑際にあった。島津勢が上流と東から回り、残る出口は西の細い畦だけである。そこへ逃げる仙石兵が流れ込み、十河勢は自分の退路を味方に塞がれていた。

畦の入口で、十河兵が土佐兵の帯を締め直していた。つい先年まで互いの首を狙った家の兵である。土佐兵は礼を言わず、十河兵も顔を見なかった。結び目だけを二度引き、別々の旗へ戻った。

小平が畦の脇で倒れていた。

又兵衛は彼を抱き起こした。腿へ弾が入り、木札は血で読めない。

「十河勢へ、何を伝えた」

「右へ……出ろと」

「三十ずつ戻れは」

小平は首を振った。

「先に、上の方の命を」

身分の高い武者の命令を選んだ。だが木札を二つに分けたのは又兵衛であり、全軍の命令を確かめず伝令を走らせたのも又兵衛だった。

弦太が追いついた。

「重傷者を動かすなら今や。日が山へ触れるまで一刻ない」

又兵衛は十河の旗を見た。

信親へ届かなかった。今度こそ、包まれた将を帰したかった。

「存保殿の道を開ける」

「四十六人を置いてか」

「存保殿の隊と合わされば、担ぐ手が増える」

弦太は「四十六」と炭で書いた木札を、又兵衛の胸へ押しつけた。又兵衛はそれを懐へ入れ、名のある将の旗へ向かった。

又兵衛は畦へ入った。

狭い。右は冬田の泥、左は用水。二人並べば槍を振れない。甚六が盾を縦にし、清十郎が足場へ白土を撒く。又兵衛は焼け槍の石突で倒れた竹を押し、幅を一尺広げた。

島津兵が畦へ槍を揃えた。又兵衛は先頭の穂先へ焼け槍を添え、押し合わず用水側へ滑らせる。甚六が空いた胸元へ盾を当て、敵を冬田へ落とす。倒すたびに進めるのは一歩だけだった。

後ろから来た味方が「押せ」と叫ぶ。甚六は盾を横へ向け、味方の胸も止めた。

「道を開けるのと、道へ詰めるのは違う」

十河勢の前衛が見えた。

存保は兜を失い、額から血を流していた。軍議で兵の鍋へ入れた味噌の匂いが、又兵衛の記憶へ戻った。

「道は何人通れる」

存保が聞いた。

「一度に三十。畦を守れば続けて通せます」

「ここには二百を越えておる」

「先に殿と負傷者を」

存保は笑わなかった。

「三十の道へ二百を押せば、三十も死ぬ」

存保は畦の幅を自分の足で測った。三歩。次に、負傷して座る兵を十人ずつ指さした。

「歩けぬ者、旗と行け。歩ける者が担げ。敵へ顔を向けたまま下がれ」

一人の老兵が首を振った。

「殿を担ぎます」

「わしは歩ける」

存保は老兵の竹筒を取り、隣の土佐兵へ渡した。

「昨日までの敵でも、今日ここで乾く必要はない」

後ろの槍音を聞き、旗手へ棹を渡した。

「旗を西へ持っていけ。散った者を一人でも連れろ」

旗手が動かない。

存保はその頬を張った。

「わしの傍で死ぬことを、忠義にするな」

又兵衛は存保の腕をつかんだ。

「一緒に来てください」

「お前は道を持ってきた。道までここへ埋めるな」

島津兵が畦の入口へ出た。甚六の盾へ弾が当たり、鉄縁が鳴る。

存保は又兵衛の手を外し、小平を見た。

「その若いのを先に運べ。命令を間違えた者ほど、生きて次へ伝えねばならん」

又兵衛は一歩残った。

存保はもう見なかった。十河勢へ向き直り、畦を守る人数を半分に分ける。前へ出る者と、旗を追って西へ走る者。自分は前の列へ入った。

又兵衛は小平を背負った。

小平は背中で、同じ言葉を繰り返した。

「川下、二つ目。三十ずつ」

遅れて届いた正しい命令は、もう誰も動かせなかった。

畦を戻る途中で、十河の法螺が止まった。

清十郎は存保の名の横へ、戦死と書かなかった。見た者の名を三人集め、同じ時刻、同じ場所を答えたのを確かめてから、筆を入れた。

十河存保。

その下に、旗とともに西へ抜けた二十七人の名を並べた。

又兵衛が持ってきた道は、存保本人へは届かなかった。
