# 『戦帰 SENKI』第14巻『戸次川』

## 第111話　川を渡れない者

**時刻・場所**：12月12日日没直前、戸次川中央浅瀬の東西両岸。  
**今回の問い**：残り時間で二十三人しか運べない時、四十六人全員を帰すと言い続けられるか。  
**次話へ送る代価**：甚六の左脚が折れ、又兵衛は自分の手で綱を切り、二十三人を東岸へ残す。

日没まで、あと四半刻だった。

西岸へ渡った兵は千を越えた。正確な全軍数は分からない。清十郎が数えられた者だけでも、朝より大きく減っている。

東岸の低い土手に、自力では川を渡れない負傷者が四十六人残った。

藤乃は傷の重い順に、草鞋を頭の横へ置いた。意識がある者には名と家を言わせ、清十郎が帰名帳へ書く。

木の櫛を握る男は、妻の名だけを答えた。袖に小さな手形を押した男は、熱で自分の名を言えない。草鞋の底へ「八」と刻んだ少年は、八番目に雇われたため皆から八と呼ばれていたが、本名を知る同郷の者が見つからなかった。

四十六人を、数字だけでは運べなくなった。

弦太は綱、担ぎ手、水深、残りの明るさを数えた。

「八人ずつ二往復。最後に歩ける七人を綱へ付ける。二十三人までや」

「四十六人おる」

「分かっとる」

「なら全員運ぶ」

「言うただけで、川幅は縮まらん」

又兵衛は担架を二つずつ綱へ結ばせた。片側を西岸から引き、東岸で二人が支える。一度に多く運べば間に合う。

弦太は一組ずつに戻そうとした。

「綱が人を引くんやない。支えるだけや。重ねたら底へ沈む」

「二つなら沈まん」

「さっき馬で擦れた綱や」

又兵衛は二つの担架を解かなかった。

一組目は渡った。

二組目で、馬が背後から突っ込んだ。黒旗を追ってきた荷駄馬が人の声に怯え、手綱を切って浅瀬へ入った。

甚六は子供ほどの伝令を盾の後ろへ押し込んだ。馬の肩が荷車へ当たり、外れた車輪が甚六の左脚を石へ挟んだ。

骨の鳴る音を、又兵衛は水の中で聞いた。

甚六は倒れず、盾を杖にした。

「列を止めるな」

藤乃が駆け寄り、膝から下を板で挟んだ。足首は外へ曲がり、草鞋の先が動かない。

弦太が又兵衛を見た。

一つの浅瀬へ全員を集めたため、荷駄馬まで押し寄せた。その混雑が甚六の脚を潰した。

又兵衛は三組目を入れた。

綱が張る。人を支える綱と、馬を渡した時に岩で擦れた綱は同じものだった。水中で開いていた麻が、一気に細くなる。

「戻せ」

甚六が叫んだ。

東岸では島津の斥候が土手へ現れた。鉄砲の火蓋が開く。

又兵衛は川へ入り、担架の下へ肩を入れた。冷たい水が胸まで上がる。焼け槍を横へ渡し、三人に掴ませた。

一発が水へ入った。

二十三人目が西岸へ引き上げられた時、綱の撚り半分が切れた。残る繊維だけで、東岸と西岸が繋がっている。

向こうには二十三人いる。

歩けない者が十九。片腕を使える者が二。意識のない者が二。清十郎は全員の名を聞き終えていた。三人は名を答えられず、持ち物と傷だけを書いた。

又兵衛は東へ戻ろうとした。

弦太が腰へ組みついた。

「行ったら二十四人になる」

「綱を直す」

「暗い。敵が来る。西岸の千人も動けん」

「手を離せ」

甚六が盾で又兵衛の胸を押した。折れた脚を地面へ引きずりながら、綱を見た。

「切れ」

「向こうにおる」

「分かっとる。切らんと、敵がこの綱で来る。次に張った時、西の連中まで川へ入る」

東岸の兵が叫んだ。

「早く行け」

声の主は、右腕を失った仙石兵だった。自分の担架を横へ倒し、動ける二人へ土手の陰へ隠れるよう指さしている。

「俺らを並べるな。藪へ分けろ。火縄が来たら、動ける者だけ先に伏せろ」

助けを待つ者が、残された後の手順を自分で決めていた。

木の櫛の男は、清十郎へ投げようとして届かず、櫛を胸へ戻した。袖の手形は川風に揺れた。

又兵衛は脇差を抜いた。

麻の最後の束へ刃を当てた。手が震え、最初の一度では切れなかった。

二度目で、綱が離れた。

東岸の端が水へ落ち、西岸の端が又兵衛の手を打った。

綱がなくなると、川幅が急に広く見えた。向こうの声は聞こえるのに、誰の口が動いたか分からない。

川向こうの二十三人は、夜の色へ沈んだ。捕らえられた者、生き延びた者、そこで死んだ者を、この時の又兵衛は知らない。

黒旗の列は西へ動き始めた。

又兵衛は最後尾へ立ったが、川の向こうに人がいる以上、自分が最後尾だとは言えなかった。
