# Stop Slop常設執筆ルール

『戦帰 SENKI』の物語、脚本、台詞、あらすじをChatGPTまたは他の生成AIで作る時は、`.claude/skills/stop-slop/SKILL.md`を必ず先に読む。

## 運用順

1. `00_正典ルールと30巻整合性ロック.md`
2. 最新の全30巻240話決定稿
3. キャラクター、技、負傷、伏線資料
4. `12_最終チェックリスト監査と制作憲法.md`
5. `13_全240話_話別設計テンプレート.md`
6. `.claude/skills/stop-slop/SKILL.md`
7. 本文執筆
8. Stop Slop採点と修正

## 禁止する書き癖

- 重要性を語り手が説明する。
- 「単なるXではない」「本当のYは」の型を連発する。
- 短い文を三つ並べ、擬似的な迫力を作る。
- 抽象語だけで感情、損失、戦況を処理する。
- 人物の選択より先に名言を作る。
- 敵を主人公の正しさを証明する道具へ落とす。

## 必須の描写

各話に次のうち三つ以上を置く。

- 時刻または残り時間
- 地形または距離
- 人数または物資量
- 身体疲労または負傷
- 誤った情報または届かない伝令
- 食事、仕事、家族など守る日常
- 選択後に元へ戻らない具体的変化

このファイルをリポジトリへ置くことで、会話履歴に依存せず、プロジェクト内の常設ルールとして維持する。
