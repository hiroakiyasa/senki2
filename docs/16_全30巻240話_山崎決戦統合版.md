# 『戦帰 SENKI』全30巻・全240話 山崎決戦統合版

> 有岡城、松寿丸救出、備中高松城、中国大返し、山崎の戦いへ又兵衛を黒田・秀吉側の直接参加者として配置する最終構成。各巻8話、全240話。

## 固定原則

- 秀吉＝総大将、官兵衛＝戦略中枢、又兵衛＝前線実行者。
- 又兵衛は光秀本人を討たない。渡河路確保、明智鉄砲隊の射線分断、長政隊の前進支援、坂本方面への再集結阻止によって山崎勝利へ直接貢献する。
- 詳細脚本化は `00`→`12`→対象巻→`13`の順で行い、人物シート、槍技、負傷、伏線、象徴を同期する。
