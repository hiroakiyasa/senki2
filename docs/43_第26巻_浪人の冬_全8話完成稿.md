# 第201話　雨漏りの家

夜明け前、京都の借家で雨が軍学図の中央へ落ちた。

又兵衛は畳を起こし、桶を三つ並べる。右肩が上がらず、最後の一枚は小夜が下から支えた。カヤは寝具を乾いた土間へ移し、墨の滲んだ図を油紙で挟む。家族の朝飯は冷えた麦粥一椀を三人で分ける。

家主は午前のうちに家賃を取りに来る。滞納は二月分。又兵衛が持つ現金は半月分しかない。黒槍は第25巻で質へ入ったまま、受戻し期限は残り十二日だった。

又兵衛は軍学の原図を売ろうとするが、小夜が止める。弟子たちへ写しを売れば毎月の銭になる。原図を一度売れば、次の冬に教えるものがなくなる。

家主は半金を受け取り、十日後までに残りを払えなければ退去と告げる。悪人ではない。屋根を直す大工へ払う銭がなく、隣家の家族も同じ雨漏りに困っていた。

又兵衛は「戦なら十日で道を作れる」と言いかけ、屋根から落ちる一滴を見た。戦場の道を作れても、家賃一月を作れない。

夕方、弟子の青木弥市が仕官試験の知らせを持ってくる。又兵衛は濡れた図を広げ、明日の稽古を休まず行うと決める。残り十日。家を守るための最初の仕事は、家から出ていく弟子を仕官させることになる。

# 第202話　軍学の弟子

鴨川の河原に、荷俵十二、竹札三十、濡らした火縄十本を並べた。

又兵衛の軍学は名将の奇策を暗記させない。弟子へ三十人分の米、水、負傷者、夜道、伝令の受領確認を割り振り、本人が倒れた後も進む手順を作らせる。

仕官試験を受ける弥市は、又兵衛の見栄えのよい包囲図を提出したがる。別の弟子・宗太は、殿の名を先頭へ書けば採用されると考える。又兵衛は二人へ、雨で橋一本が落ちた条件を足す。二人の計画は、図の中央へ置いた大将が動けなくなった瞬間に止まった。

小夜は計測縄を張り、カヤは河原の上流から偽伝令を一人流す。弥市は受領印のない命令を捨て、宗太は十二俵を九俵へ減らして負傷者用の舟賃を残す。二人は初めて、又兵衛が答えを言う前に手順を直した。

試験役は二人を採る。弟子たちは喜び、月謝の代わりに最後の米袋を置く。又兵衛は笑って送り出すが、明日から塾の収入は半分になる。

弥市は「先生もどこかへ仕官を」と言う。又兵衛は返事をせず、河原へ残った竹札を拾う。教えた者は家を得た。教えた本人だけが、雨漏りする家へ戻る。

# 第203話　旧臣の畑

大和の畑で、又吉は槍柄を鍬の柄へ削り直していた。

又兵衛は帰参交渉に備え、かつての旧臣がどこで暮らしているか確かめに来る。又吉の家には妻、幼い孫、借りた畑二反。水口が崩れ、田へ水が届くまで残り半日しかない。

又兵衛は昔の号令で人を並べようとする。又吉は従わない。畑では一番足の速い者より、土の癖を知る女と子の方が正しい場所へ立つ。又兵衛は黒槍の代わりに鍬を握り、右肩をかばいながら水路へ入る。

崩れた畦を直す途中、旧主の名を聞いた近隣の百姓が身構える。又吉は又兵衛を「昔の大将」ではなく「水口を手伝う男」と紹介する。日が傾く前に水が通り、孫が裸足で田へ入った。

夜、又兵衛は帰参の可能性を話す。又吉は槍を取らない。戦で得た扶持より、今年の麦を選ぶ。家族を二度、主家の都合へ乗せたくない。

又兵衛は説得しない。清十郎へ渡す所在札に、槍印でなく鍬印を付ける。又吉は「呼ばれなかった」のではなく、「行かないと答えた者」になる。

帰り道、小夜が問う。「父上は、皆を連れて行かないの」。又兵衛は泥のついた手を見て、「帰っている者まで戦へ戻したら、連れて帰ったことにならん」と答える。

# 第204話　長政を悪く言うな

京都の酒場で、塚本源八が黒田長政を臆病者と罵った。

源八は三年仕官できず、妻子を国へ帰した浪人だった。黒田の奉公構が又兵衛だけでなく周囲の者まで雇いにくくしたという噂を信じている。又兵衛は酒樽を運ぶ日雇いで、騒ぎを止めればその日の銭をもらえる。

最初は黙って床の酒を拭く。源八が官兵衛の死まで長政の策だと言ったところで、又兵衛の手が止まる。杯を握り潰す代わりに、源八の襟を掴んで外へ出そうとする。

源八は「捨てられた犬が主を庇うな」と叫ぶ。又兵衛は一度だけ殴る。源八も殴り返し、二人は酒樽を倒す。店主は役人を呼び、又兵衛は日当と働き口を失う。

番所で、又兵衛は長政を讒言した者を殴った理由を問われる。「あの人が間違えたことは、俺が知っとる。知らん者が嘘で足すな」と答える。

騒ぎを聞いた仲介人・榊原宗伯が現れる。黒田家と幕府筋の間で、又兵衛の帰参条件を探っていた。宗伯は「まだ主君と思うなら戻れるかもしれぬ」と言う。

又兵衛は腫れた拳を袂へ隠す。家賃期限は残り四日。失った仕事の代わりに、最も戻りたくて、最も戻れない門が開き始める。

# 第205話　戻れない条件

伏見の寺で、帰参条件が七枚に分けて置かれた。

黒田家の井口作左衛門は、長政の直筆が入った一枚を先に出す。又兵衛の家族へ扶持を付ける。雨の入らない屋敷を用意する。古傷の療治を認める。黒槍も買い戻す。長政は又兵衛の暮らしを具体的に守ろうとしていた。

残る六枚には、旧臣名簿の提出、他家との書状検閲、城外行動の届け出、家族の城下居住、黒槍の武具蔵保管、配下募集の禁止が書かれている。五十二万石を守る主君には、独自の人脈と兵を持つ又兵衛を無条件で戻せない。

又兵衛は自分への監視なら受けると言う。だが、又吉の畑、弥市の新しい主、かつての旧臣の妻子まで名簿へ載せる条件を外してほしい。井口は外せない。名簿を持たずに又兵衛だけを戻せば、誰が後から集まるか国が把握できない。

宗伯は妥協案として、十人だけを記すよう勧める。又兵衛は十人を選べない。名前を書けば、その者の暮らしへ再び黒田の目を向ける。

長政の直筆には、「戻れば家族を飢えさせぬ」とある。又兵衛は紙へ指を置き、長く離さない。帰りたかった気持ちは消えない。

それでも署名しない。寺の火鉢で、自分が用意した旧臣名簿の下書きだけを焼く。長政の書状は焼かず、宗伯へ返す。

井口は敵意を見せず、「これで殿も、戻せぬ理由を持たねばならぬ」と言う。二人とも家を守った結果、帰参の道が閉じる。

# 第206話　豊臣の使者

借家の退去日、豊臣方の塩谷半兵衛が銀と名簿を持って来た。

名簿には三十二行。又兵衛が声を掛ければ集まる兵として、旧黒槍組、浪人、負傷兵、農民まで並ぶ。塩谷は「大坂なら二千を預ける」と言い、家賃と黒槍の質代に足りる前金を置く。

又兵衛は最初の三名で名簿の誤りに気づく。一人は死者。一人は又吉で、すでに鍬を選んだ。一人は別人の通称が混ざっている。

カヤが紙を透かし、三種類の筆と紙継ぎを見抜く。元は借財帳、市場の宿帳、軍奉行の古い覚書だった。豊臣方は又兵衛の人望を欲しがるが、本人の意思を確かめていない。

塩谷は悪意だけで動かない。大坂城には帰る場所のない浪人が増え、指揮できる者が足りない。締切まで三日。又兵衛が来なければ、名簿の者たちは別の頭へまとめて売られる可能性がある。

又兵衛は前金へ手を伸ばしかける。銀があれば今夜の宿、黒槍、薬、米を戻せる。小夜は父の手より先に、三十二行の名簿を見る。

「この人ら、来るって言うたん？」

又兵衛は手を止める。塩谷へ一夜の猶予を求め、銀袋へ封をしたまま預かる。清十郎と弦太へ名簿を渡し、生死、所在、意思を分けて調べる。

大坂へ行くかを決める前に、又兵衛は自分の名で勝手に兵へされた者を、名簿から戻す仕事を始める。

# 第207話　欠けた椀の半分

退去前夜、三人は空になった部屋で欠けた椀を囲んだ。

清十郎の調査で、三十二行のうち死者四、重複二、所在不明二。連絡してよいと確認できたのは二十四人だった。又吉には知らせない。彼はすでに畑を選んだ。

黒槍の受戻し期限はその日暮れ。豊臣の銀袋を開けば間に合う。又兵衛は封へ指を掛けるが、カヤが自分の稼いだ銭を畳へ置く。情報売りと薬仕事の分。小夜も縫い仕事の銭を置く。足りない。

小夜は軍学原図を持って、仕官した弥市のもとへ行く。弥市は師の原図を買い、写本を後世へ残すと約束する。又兵衛は教える仕事の元手を失うが、黒槍を豊臣の前金に買われずに済む。

質屋で受け取った黒槍は、油の切れた布に包まれている。補修輪の錆、短くなった柄、偏った重心は変わらない。又兵衛は右肩へ担がず、左手で低く持つ。

家へ戻ると、カヤが三つの行き先を書かずに並べる。黒田へ条件を呑んで戻る。名を変えて町に残る。大坂へ入り、豊臣が負ければ全て失う。

又兵衛は家族へ大坂行きを命じない。カヤは「私は私の借りを返しに行く」と答える。小夜は「帰って来た後の家を、今度は私も決める」と言う。

三人で決めてから、銀袋の封を開く。弦太が受領量を数え、清十郎が使途を記す。二十四通の知らせには、参陣命令でなく、食料、危険、家族帯同、断る方法を書く。

欠けた椀の片割れを又兵衛が懐へ入れる。もう一片を持つ長政のもとへ帰る道を捨てたのではない。今は、自分で選んだ門へ向かう。

# 第208話　大坂へ

二十四通の返事が、伏見の河原へ集まった。

参陣十三、辞退六、届かず三、保留二。又兵衛は辞退者の名へ印を付け、もう呼ばない。集まった十三人へも、家族を捨てて来るなと告げる。

出発するのは、又兵衛、カヤ、小夜の三人、志願した十三人、その扶養家族と負傷者十人。合計二十六人。戦える人数だけなら十四人だった。

弦太は三日分の米、水桶、薬、雨具を荷車二台へ割る。清十郎は本名、通称、家族、断った者を別欄へ記す。黒槍は又兵衛が持つが、肩が固まる前に若い者と交代する。

伏見の関で、仕官した弥市が下役として一団を調べる。師だから通すことはできない。軍役札のない家族と負傷者は規定上、浪人隊へ数えられない。

弥市は又兵衛から学んだ通り、規則を破らず分類を増やす。戦闘員、扶養家族、療養者、荷役。全員の受領者を大坂方へ書かせ、門で追い返されない形を作る。

大坂城外の登録所は、又兵衛の隊を十四人と数える。家族十人とカヤ、小夜を兵数へ含めず、扶持を出さない。又兵衛は自分の指揮手当と馬一頭分の飼料を返し、弦太は自分の米を差し出す。二十六人分の三日扶持が揃うまで、門を越えない。

日暮れ前、登録札が二十六枚出る。書役が人数を尋ねる。

又兵衛は列を見て答える。

「二十五」

小夜がすぐに言い直す。

「二十六。父上も入る」

門が開く。又兵衛は訂正できず、黒槍を持って二十六番目に入る。

城内では、数千の浪人が別々の歩幅で進み、炊事場と武具蔵の命令がぶつかっていた。又兵衛が得たのは軍ではない。家を失った者の群れだった。

次巻、天満の閲兵へ続く。

# 第26巻終了時の台帳

## 人物

- **又兵衛**：黒田帰参の具体条件を断り、家族と志願者の選択を確認して大坂へ入る。黒槍を受け戻す。二十六人全員を門内へ通すが、人数確認では自分を除いて二十五と答える。
- **カヤ**：帰参・残留・大坂の三案を家族へ並べ、又兵衛の命令でなく自分の意思で大坂を選ぶ。情報仕事の銭を黒槍受戻しへ出す。
- **小夜**：家計、軍学原図の売却、名簿の意思確認へ参加する。父を二十六人目として数える役割を得る。
- **長政**：直接登場しない。家族扶持、屋敷、療治を含む帰参条件と、国家防衛上の監視条件を同時に示す。又兵衛を飢えさせたいのではなく、管理なしには戻せない。
- **弦太**：前金、米、扶持、移動人数を数える。大坂門前で自分の米を出し、全員分の登録を成立させる。
- **清十郎**：三十二行を死者・重複・所在・意思へ分け、二十四通へ直す。断った者も記録に残す。
- **又吉**：旧臣から農民へ生き方を変え、参陣しない。又兵衛はその選択を守る。
- **青木弥市 `[C]`**：又兵衛の弟子。仕官し、伏見の関で規則へ新しい分類を足して二十六人の通行を可能にする。
- **塚本源八 `[C]`**：長政を罵る浪人。失業と家族離散の怒りを又兵衛へぶつける。又兵衛の正しさを証明するだけの悪役にはしない。
- **榊原宗伯・井口作左衛門・塩谷半兵衛 `[C]`**：帰参仲介、黒田方実務、豊臣方勧誘をそれぞれ担う。三者とも所属組織の現実的な必要から動く。

## 道具と象徴

- **黒槍**：第25巻で質入れ。第207話で家族三人の稼ぎと軍学原図の代価により受け戻す。豊臣の前金を受戻しへ使わない。素槍、補修輪、偏った重心、右肩制限を維持。
- **欠けた椀**：又兵衛の片割れを大坂へ持つ。長政側の片割れとはまだ揃わない。
- **軍学原図**：雨漏りから守った後、弥市へ売る。失われず弟子側へ継承されるが、又兵衛は京都で教える元手を失う。
- **三十二行の名簿**：死者・重複・本人未確認を含む。清十郎が二十四通の意思確認へ直す。
- **二十六枚の登録札**：戦える十四人だけでなく、家族、療養者、荷役を大坂城内へ通した証拠。

## 情報

- 又兵衛は、黒田家が家族を守る具体策を持つ一方、旧臣と書状を管理しなければ自分を戻せないと知る。
- 長政側は、又兵衛が条件を拒み黒田へ戻らないことを知る。大坂入りはこの巻末時点では未確定情報。
- 豊臣方は、又兵衛の人望を実人数以上に見積もっていた。実際に自分で選んだ戦闘員は十三人。
- 又兵衛一家は、大坂方が劣勢となる危険を理解したうえで入城を選ぶ。

## 生活

- 京都の借家は退去。家財は荷車二台へ収まる量まで減る。
- 移動人数は二十六人。三日分の米、水、薬を持つ。
- 断った六人と保留二人へ再勧誘しない。届かなかった三人は清十郎の未達欄へ残す。
- 又吉の畑と家族は戦から切り離される。

## 第27巻への不可逆な条件

- 又兵衛は大坂方へ入った。黒田帰参の交渉へすぐ戻ることはできない。
- 二十六人は登録されたが、又兵衛の指揮下にある戦闘員は十四人しかいない。
- 城内には帰る場所のない浪人が数千規模で集まり、旗、歩調、武器、炊事、命令系統が揃わない。
- 又兵衛は全員を門内へ入れたが、自分を人数へ含める答えはまだ小夜に代弁されている。
- 第27巻第209話「天満の閲兵」は、又兵衛が寄せ集めの浪人を軍へ変える作業から始まる。
