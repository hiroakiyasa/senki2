# 第10巻「清洲会議・賤ヶ岳」史実監査

> 対象：第10巻『勝者の空席』通算73〜80話。  
> 目的：史実上の大事件を又兵衛へ奪わせず、確定史実［A］、有力説・後世整理［B］、物語上の創作［C］、視覚的推定［D］を明示する。  
> 本監査は物語の面白さを削るためではなく、創作を置いてよい「史実の継ぎ目」を広く確保するために行う。

---

## 1．結論

第10巻は、以下の境界を守る限り、正典と史実の両方へ整合する。

1. 清洲会議そのものの後継・領地決定へ、又兵衛たちを関与させない。
2. 会議室内の秀吉・勝家の台詞や劇的な直接対決を確定再現しない。
3. 賤ヶ岳合戦の主戦、秀吉の帰還判断、大岩山砦の攻防、中川清秀の運命、柴田勝家の敗北を又兵衛の働きで変えない。
4. 「賤ヶ岳七本槍」は後世の呼称として扱い、1583年当日に七人が固定集団名を自称する描写をしない。
5. 長政は1582年に15歳で初陣、賤ヶ岳で16歳という年代感を守る。
6. 又兵衛の論功、冬米輸送、板橋救援、褒美保留、両家請状、継ぎ宿はすべて創作［C］として明示する。
7. 後方の民衆、兵糧、飼葉、道普請を描く場合、後世の合戦図を同時代写真のように扱わず、生活描写の参考［D］に留める。

## 2．史実ラベル

| ラベル | 意味 | 第10巻での扱い |
|---|---|---|
| ［A］ | 年代、場所、人物経歴など複数の信頼できる資料で確認できる骨格 | 日付・年齢・主要事件・主要勝敗を固定 |
| ［B］ | 後世の呼称、軍記的整理、複数説のうち有力な理解 | 断定台詞を避け、ナレーションで距離を取る |
| ［C］ | 物語上の創作 | 人物・文書・輸送数・橋・宿を明記して自由に設計 |
| ［D］ | 視覚的・生活史的推定 | 衣食住・荷役・道具の参考。史実の直接証拠とはしない |

## 3．固定する史実［A］

### 3-1．清洲会議

- 清洲会議は、本能寺の変後の戦後処理として1582年6月27日に開かれたとされる。
- 会議では織田家の継承と領地配分が扱われた。
- 物語では、四重臣の会議を閉じた戸、座順、使者、会議後の告知で示し、又兵衛たちは外郭・台所口・待合に置く。
- 現在の清洲城模擬天守は平成元年の再建施設であるため、漫画背景へその外観を流用しない。16世紀の木造城館・外郭として再設計する。

### 3-2．賤ヶ岳合戦

- 賤ヶ岳合戦は1583年4月20日から21日にかけ、現在の長浜市木之本町の賤ヶ岳から余呉町柳ケ瀬周辺を中心に行われた。
- 大岩山砦方面の攻防、余呉湖周辺の山地・湿地・狭路を、物語の地形骨格へ使える。
- 又兵衛の架空任務は東岸の板橋・兵糧路・後送路へ限定し、主戦の勝敗を変えない。

### 3-3．黒田長政の年齢

- 黒田長政は1568年生まれ。
- 福岡市博物館の展示解説では、1582年に15歳で初陣、賤ヶ岳で16歳とされる。
- 第73〜74話では15歳、第76〜80話では16歳として扱う。若さを理由に無能化せず、実戦経験を持ち始めた嫡男として描く。

## 4．断定しない史実［B］

### 4-1．清洲会議の「秀吉対勝家」

伝統的な物語では、会議室で秀吉と勝家が後継者をめぐり激しく争い、秀吉が三法師を抱いて勝つ構図が強調される。一方、会議前から一定の調整が進んでいた可能性や、後世の軍記・物語で対立が劇化された可能性を指摘する研究紹介もある。

したがって、第74話では次を守る。

- 会議室内の具体台詞を描かない。
- 秀吉がその場の一言だけで全てを決めたと断定しない。
- 勝家を時代遅れの敗者、秀吉を全知の勝者として単純化しない。
- 外周の人物が知れるのは、出入り、座順、使者、会議後の告知まで。

### 4-2．「賤ヶ岳七本槍」

長浜城歴史博物館は、七本槍を「後の世に言う」呼称として説明し、いつ頃から呼ばれ、構成員が固定していたかを検討課題としている。長浜市の解説では、1583年4月21日の追撃戦で感状を受けた九人のうち、江戸時代に七人が注目されたと説明される。

したがって、第76・78話では次を守る。

- 七人を一列の固定部隊として登場させない。
- 当人たちに「我ら七本槍」と自称させない。
- 個別褒賞額を全員同額として断定しない。
- 福島正則、加藤清正らを名誉欲だけの若者にせず、準備、恐怖、負傷者の後送、食事も描く。
- ナレーションは「後の世は七本と数えた」とする。

## 5．生活史・視覚参考［D］

長浜城歴史博物館所蔵の「賤ヶ岳合戦図屏風」は江戸時代19世紀の制作であり、1583年当日の同時代記録ではない。ただし、湖北・長浜の民衆が足軽へ兵糧を振る舞い、馬へ飼葉を与える場面を持つ点は、合戦を武将だけでなく後方の生活者から描く参考になる。

第10巻で採用するのは、次の視覚的発想までとする。

- 民衆が兵糧、飼葉、水、道普請、荷役を担う。
- 戦場の外周に炊事場、荷駄、馬、担架、家族がいる。
- 勝者側の民衆も徴発、腐敗、未納、空き家化の被害を受ける。

屏風に描かれた具体配置・服装・人物を、そのまま1583年の確定事実として写さない。

## 7．両家請状［C］の扱い

第79話の「両家請状」は、仙石方の過去扶持と黒田方の密命が混在する又兵衛を、物語上の継ぎ目へ置くための創作文書である。

### できること

- 任務ごとに命令主を一人へ固定する。
- 黒田・仙石のどちらが給付、弁済、負傷者米を負うか残す。
- 又兵衛が命令者へ損耗を請求できる。
- 第10巻から第11巻へ、所属未定のまま出陣させる。

### できないこと

- 黒田家への正式帰参を成立させない。
- 仙石家の過去扶持・権利を消さない。
- 所領、屋敷、恒久扶持を保証しない。
- 現代的な雇用契約、二重雇用、法廷強制力として描かない。

作画では、折紙、花押、印、紐、別々の帳へ同じ札が挟まる構図で示す。整然とした現代契約書レイアウトを避ける。

## 9．作画・背景の禁止事項

### 清洲

- 現在の金鯱を持つ再建模擬天守を16世紀の清洲城として描かない。
- 観光橋、舗装、電灯、コンクリート石垣を出さない。
- 大広間を江戸後期の豪華な御殿のようにしない。
- 会議参加者の家紋旗を巨大な戦場のぼりとして室内へ並べない。

### 北近江・賤ヶ岳

- 余呉湖周辺を乾いた平原へしない。山、湿地、狭路、泥、板橋を使う。
- 七人を同一甲冑・同一顔・同一ポーズで並べない。
- 又兵衛に七本槍の一人のような固定称号を与えない。
- 火薬箱を近代弾薬箱、ダイナマイト、金属コンテナとして描かない。
- 和鞍・和鐙を守り、西洋鞍・細い輪鐙を出さない。

### 戦後集落

- 「空き家」を無人の廃墟記号にしない。織りかけの布、種籾、背丈傷、椀、鍬を残す。
- 美代・いとを同情のためだけの無力な母子にしない。
- 又兵衛を最初から家を譲る聖人にしない。
- 継ぎ宿を無料・無負担の理想制度にしない。

## 10．Stop Slop史実適用

- 「政治が動いた」ではなく、座布団、縄の内外、竹筒の水、味噌湯の濃さを描く。
- 「補給が苦しかった」ではなく、180俵、腐敗18俵、橇12台、三砦各48俵を描く。
- 「退路を守った」ではなく、一人幅、弱板、継ぎ縄、73人、火薬箱8棹、追手12人を描く。
- 「所属が曖昧」ではなく、飯帳、命令帳、弁済帳の印が揃わない状態を描く。
- 「家を失った」ではなく、織り機、背丈傷、種籾、三つの椀を描く。
- 歴史人物の格を上げるために架空人物を無能化せず、架空人物の格を上げるために歴史人物の功を奪わない。

## 12．最終判定

| 監査項目 | 判定 | 理由 |
|---|---|---|
| 正史整合 | 合格 | 清洲・賤ヶ岳の主要決定と勝敗を歴史人物へ残す |
| 年齢整合 | 合格 | 長政15〜16歳を固定 |
| 呼称整合 | 合格 | 七本槍を後世呼称として処理 |
| 創作表示 | 合格 | 輸送数、橋、請状、宿を［C］として明記 |
| 主人公の功績過剰 | 合格 | 又兵衛は主戦を変えず、後送・橋・帳・宿の継ぎ目で働く |
| 歴史人物の悪役化 | 合格 | 勝家方、書役、門役、村書役へ合理的責任を与える |
| 生活史 | 合格 | 米、薪、飼葉、道普請、椀、種籾を勝敗と接続 |
| 次巻送付 | 合格 | 仙石家小頭としての次の召集だけを提示し、第11巻冒頭で1584年春へ時間を進める |

第10巻は、史実の中心へ又兵衛を置くのではなく、勝者の記録・補給・退路・空き家の外周へ置くことで成立する。中心の歴史を変えず、「勝ったのに帰る席がない」という本作固有の物語を最大化できる。
