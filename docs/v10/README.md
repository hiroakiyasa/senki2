## 連続性

第11巻『徳川の壁』では、又兵衛が賤ヶ岳で得られなかった「誰にも奪えない武功」を求め、仙石家の五十二人を率いて小牧・長久手へ入る。第10巻で退路役を離れて七人を失った傷が、第11巻の性急な反撃と撤退判断へ接続する。
