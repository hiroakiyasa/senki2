# 『戦帰 SENKI』正典ルールと30巻整合性ロック

> 本書は、既存の `README.md`、`docs/01`〜`docs/08` の記述が食い違った場合に優先する「正典ロック案」です。  
> 第一巻だけを独立完結させるのではなく、第1〜3巻を全30巻の**第一大章**として完成させます。

## 1. 作品の一行企画

家も名もない少年・後藤又兵衛と、国を背負って生まれた若君・松寿丸。  
「又兵衛が人を連れて帰り、松寿丸が帰る場所をつくる」と誓った二人が、同じ願いから正反対の答えへ進み、最後に「強い大将とは何か」を問い直す全30巻の歴史群像劇。

---

## 2. 全30巻を貫く二人の約束

### 又兵衛の夢

> **俺は、どんな負け戦でも、最後の一人まで連れて帰る大将になる。**

象徴台詞：

> **俺より後ろに、誰も残さない。**

異名：

> **最後尾の大将**

ただし、この夢は最初から完成した正解ではない。

- 表面の美点：弱い者、負傷者、名のない者を見捨てない
- 隠れた欠点：自分だけは「連れて帰る一人」に数えない
- 長期的な誤信：自分が最後尾へ一人で残れば皆を救える
- 最終到達：責任を仲間へ分け、自分も守られる側に入れる

### 松寿丸／黒田長政の夢

子どもの言葉では、次の形にする。

> **なら僕は、帰ってきた者が、もう追い出されない場所をつくる。**

二人の最初の約束：

> **又兵衛：俺が連れて帰る。**  
> **松寿丸：僕が帰る場所をつくる。**

この約束が、後に二人を結び、同時に引き裂く。

- 又兵衛は「目の前の一人」を優先する
- 長政は「帰る場所である国」を守るため、多数と制度を優先する
- 又兵衛は命令を破ってでも救う
- 長政は国を壊さないため、個人を役割へ置く
- どちらも第1巻の約束を守ろうとして対立する

## 3. 第一大章の範囲

### 第一大章「名なしの槍」――第1〜3巻・全24話

第一巻だけで政治問題、父の過去、黒田家の危機、又兵衛の成長をすべて解決しない。

| 巻 | 表面の物語 | 内面の問い | 決着 |
|---|---|---|---|
| 第1巻『雨の夜、二人の大将』 | 夜明けまでに松寿丸と村人を橋砦から救う | 命の価値は身分で決まるのか | 局地救出には勝つが、松寿丸へ正式な人質命令が来る |
| 第2巻『五人で帰れ』 | 五人組の正式試験と、松寿丸の人質護送 | 大将が倒れても仲間は帰れるか | 五人は仕組みとして動けるようになるが、又兵衛は門の外へ残される |
| 第3巻『帰れない二人』 | 有岡城の官兵衛と、処刑危機の松寿丸 | 大切な二人を同時に救えない時、何を選ぶか | 黒田家は存続するが、二人は正反対の誤った教訓を得る |

第一大章の外的勝利：

- 官兵衛が有岡城から生還する
- 松寿丸が処刑危機を生き延びる
- 黒田家が滅亡を免れる
- 又兵衛が正式に黒田家の槍となる
- 最初の五人が、後の黒槍組の原型になる

第一大章の内的敗北：

- 又兵衛は「自分が全部背負わなければならない」と思い込む
- 松寿丸は「大切な者を守るには、強い家と完全な統制が必要」と思い込む
- 二人は互いを愛しながら、後の決裂を生む種を手に入れる

## 5. 歴史上の固定順序

### 有岡城

1. 松寿丸が織田方への人質となる
2. 荒木村重が信長へ反旗を翻す
3. 官兵衛が説得のため有岡城へ入り、幽閉される
4. 信長が官兵衛の離反を疑い、松寿丸の処刑を命じると伝わる
5. 竹中半兵衛が松寿丸を匿う
6. 有岡城落城後、黒田家臣団が官兵衛を救出する
7. 又兵衛は救出の中心人物を独占せず、栗山利安ら黒田家臣団の一員として動く

### 備中高松城

1. 秀吉軍が高松城を水攻めする
2. 本能寺の変で信長が死ぬ
3. 秀吉は事実を秘して毛利方との早期講和を急ぐ
4. 城兵助命などを条件として交渉する
5. 清水宗治が自刃し、和睦が成立する
6. 秀吉軍が中国大返しへ移る

「宗治が死んだから偶然帰れた」ではなく、信長の死を知った秀吉軍が帰還のため講和を急ぎ、その条件として宗治の命が置かれた順序を守る。

### 大坂夏の陣

- 又兵衛は最終的に生還しない
- ただし、死に場所を求めて出陣する人物のまま終わらせない
- 一度は本気で生きて帰る意思を選ぶ
- その後、孤立した若年兵と別隊を救うため戻る
- 「死にたかったから残る」のではなく、「生きたい者として他者を助けに戻る」
- 歴史上の死と、人物の精神的成長を両立させる

## 6. 黒槍の正典ロック

黒槍は「格好いい武器」ではなく、又兵衛の過去、主従、失敗、身体、戦い方を保存する経歴書とする。

### 名称の段階

1. 第1巻：**焼け槍**  
   父が持っていた黒田家貸与の無銘槍。火で黒くなっている。
2. 第2〜13巻：**継ぎ槍**  
   戦ごとに補修輪が増え、姿と重心が変わる。
3. 第14巻以降：**黒槍**  
   又兵衛の名と一体化し、周囲が呼び始める。
4. 第27巻以降：**無城の黒槍**  
   城、身分、主君を失っても残る本人の生き方になる。

### 所有権

- 第1巻：黒田家の槍を「預かる」
- 第14巻：又兵衛が城主格へ上がった時、約束どおり一度正式に返す
- 同じ場で長政が「黒田の貸し槍」ではなく「後藤又兵衛の槍」として贈り直す
- 第26巻：出奔時、又兵衛は黒田家の飾り紐と家紋金具だけを外し、槍そのものは持って出る
- これにより、黒田家の所有物を勝手に持ち逃げする矛盾をなくす

### 七つの補修輪

| 輪 | 巻 | 傷の意味 |
|---|---:|---|
| 1 | 1〜2 | 父の死、橋砦、最初の救出 |
| 2 | 4〜5 | カヤを救うのではなく、選択を尊重する |
| 3 | 8〜9 | 清水宗治の自己犠牲 |
| 4 | 10〜12 | 九州で又兵衛自身が父と同じ失敗をする |
| 5 | 15〜18 | 朝鮮で敵味方の境界が崩れる |
| 6 | 20〜22 | 関ヶ原の勝利と、失った友 |
| 7 | 25〜26 | 長政との決裂、城と身分の喪失 |

補修のたびに実用上の代価を付ける。

- 重心が変わる
- 柄が短くなる
- 特定の構えでしか最大威力を出せない
- 古傷へ負担がかかる
- 周囲を巻き込みやすくなる
- 又兵衛一人では扱いきれず、仲間の位置取りが必要になる

## 7. 第1巻の「初読と再読で意味が変わる」設計

| 第1巻の要素 | 初読 | 再読 |
|---|---|---|
| 父のいない馬 | 父の危機 | 名のない兵を使い、記録から消す戦国社会 |
| 城門 | 身分差の障害 | 長政が後に人を守り、同時に排除する制度 |
| 又兵衛の誓い | 熱い英雄宣言 | 自分を一人に数えない自己破壊の始まり |
| 松寿丸の誓い | 優しい国づくり | 大切な人を役割で管理する統制思想の芽 |
| 焼け槍 | 父からの継承 | 黒田家から借りた身分と居場所 |
| 五人の共闘 | 仲間の力 | 又兵衛が一人で背負うたび失敗する答え |
| 源六の命の値段 | 悪人の理屈 | 長政・三成・家康が直面する「人数を決める責任」の粗悪な原型 |
| 若党見習いの札 | 成功と昇進 | 父を消した制度へ又兵衛自身が入る瞬間 |
| 正式な人質命令 | 次巻の危機 | 盗賊より合法的な政治の方が人を奪うという反転 |

## 8. 又兵衛の学びを一巻で完成させない

第1巻で学ぶこと：

> 仇の首より、橋に残る人を選ぶ。

まだ学べないこと：

> 自分一人で全員を救おうとしない。  
> 自分も帰すべき一人に数える。  
> 仲間に任せても、約束を捨てたことにはならない。

この未学習部分があるため、九州、朝鮮、黒田家出奔、大坂で同じ問題がより大きな規模で再発しても「成長の巻き戻し」にならない。

## 9. 敵将を同じ問いへの異なる答えにする

| 人物 | 同じ問いへの答え |
|---|---|
| 橋砦の源六 | 捨てられたくなければ、他人の命へ値段を付ける |
| 荒木村重 | 家と領地を守るため、残した者から逃げる |
| 清水宗治 | 一人の命で皆が助かるなら、自分を差し出す |
| 島津義弘 | 全滅を避けるため、誰を残すか将が決める |
| 島津豊久 | 名を上げる突撃から、未来を守る殿へ変わる |
| 石田三成 | 数えなければ消える人を、法と兵站で拾う |
| 黒田長政 | 国を守るため、大切な人も役割へ置く |
| 徳川家康 | 一つの城を滅ぼして、戦国そのものを終わらせる |
| 後藤又兵衛 | 目の前の一人を見捨てないが、自分を数えられない |

敵の評価軸を「帰還」に統一しない。武力、軍略、統率、国家観、野望、責任で別格にし、又兵衛だけが勝利の裏で消える人間へ異常にこだわる。

## 11. 第27巻を「第二の第1巻」にする

第26巻で長政と決裂した直後、すぐ天下級の戦へ進まない。

第27巻は世界を小さくする。

- 城を失った又兵衛
- 家臣ではなくなった昔の仲間
- 二十人ほどの浪人と家族
- 一つの関所
- 足りない米
- 病人
- 追手
- 誰を先に渡すか

普通の若い浪人または農民の視点から、伝説の又兵衛を外側から見る。

初読では「無城の黒槍が再び立つ巻」。  
再読では「城も身分も失ったことで、やっと仲間を所有せずに見られる巻」。

第1巻との鏡像：

| 第1巻 | 第27巻 |
|---|---|
| 名がないため門へ入れない | 名が有名すぎるため門へ入れない |
| 父の槍を借りる | 自分の槍だけが残る |
| 五人を集める | かつての仲間が自分の意思で戻る |
| 若党見習いへ上がる | すべての肩書きを失う |
| 松寿丸を連れて帰る | 帰る家を失った浪人を生き方へ戻す |

## 12. 最終巻の正典

又兵衛は大坂夏の陣で、一度は退却を選ぶ。

仲間：

> **お前も、連れて帰る一人だ。**

又兵衛：

> **分かった。今度は俺も帰る。**

その後、別隊と若年兵が孤立したことを知る。又兵衛は死に場所を求めて戻るのではなく、帰る意思を持ったまま救援へ向かう。

最終戦で重要なのは、又兵衛一人の超人的覚醒ではない。

- 弦太が退路と兵站を作る
- 清十郎が地形と残存兵を接続する
- カヤが偽命令を破る
- 過去の敵から得た技術が統合される
- 又兵衛が倒れても部隊が動く
- 若い兵が生き延びる

又兵衛は死ぬ。  
しかし「一人で死ねば皆を救える」という誤信は否定される。

最終的な勝利は、又兵衛が生き残ることではなく、

> **又兵衛がいなくても、人を見捨てない者たちが動き続けること**

である。

## 13. 制作時の絶対チェック

各巻の執筆前に、必ず次を確認する。

1. この巻で又兵衛が救おうとする対象は誰か
2. その対象本人の意思を尊重しているか
3. 又兵衛は自分だけで背負おうとしていないか
4. 長政の判断は単なる冷酷さではなく、国を守る責任から出ているか
5. 勝利に具体的な代価があるか
6. 戦の結果が村、商人、家族、物流、記録へ残るか
7. 黒槍の傷と補修が物語上の事件に対応しているか
8. 第1巻の門、椀、鈴、名簿、父の言葉のどれかが自然に響いているか
9. 史実確定事項を創作の都合で逆転していないか
10. 一巻の表面目標を一文で説明できるか
11. 深いテーマを人物の行動で見せ、説明台詞だけにしていないか
12. 又兵衛の「欲しいもの」と「本当に必要なもの」が同じ方向になりすぎていないか
