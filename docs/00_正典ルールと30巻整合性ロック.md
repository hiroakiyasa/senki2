## 2．史実区分

- `[A]`：比較的確度が高い史実。年代、勝敗、主要人物の生死、主要な所属を変更しない。
- `[B]`：有力説だが細部に異説がある。作中では断定しすぎない。
- `[C]`：史実の空白へ置く創作。史実人物の功績を奪わない。
- `[D]`：軍記、講談、地域伝承。噂、回想、敵味方の誇張として使い、確定史実のように描かない。

後藤又兵衛の諱は一般読者向けには「基次」を使用してよい。ただし作中文書や巻末資料では、本人発給文書に見える「正親」の名も扱い、名前そのものが後世に作り替えられた人物であることを示す。

## 3．作品の一行企画

戦国の実力主義によって百石から一万石級の城主へ上り、近世の組織秩序によって居場所を失った後藤又兵衛が、「どんな負け戦でも最後の一人まで連れて帰る」という未完成な夢を抱き、仙石家の敗北、黒田家での出世、朝鮮、関ヶ原、主家出奔、奉公構、浪人、大坂の陣を通して、強い大将とは一人で残る者ではなく、責任を仲間へ渡し、自分も帰る一人に数える者だと知る全30巻の歴史群像劇。

## 4．又兵衛と松寿丸／長政の約束

### 又兵衛

> **俺は、どんな負け戦でも、最後の一人まで連れて帰る大将になる。**

> **俺より後ろに、誰も残さない。**

### 松寿丸／長政

> **なら僕は、帰ってきた者が、もう追い出されない国を作る。**

二人の約束は `[C]` だが、史実上の関係を壊さないため次を守る。

- 少年期に親密だった可能性を創作する。
- 1578年の有岡城事件前後で、又兵衛の一族が黒田家を離れる。
- 又兵衛は官兵衛救出や松寿丸救出の功績を独占しない。
- 1586〜1587年頃、仙石家の没落後に栗山利安の与力、百石級で帰参する。
- 長政との関係は、再会、信頼、競争、主従、監視、決裂の順に変化する。

## 5．又兵衛の中心矛盾

| 層 | 内容 |
|---|---|
| 表面の夢 | 誰も置いていかない大将になる |
| 欲しいもの | 名、槍、旗、身分、城、自分の軍 |
| 本当の欠落 | 家や主君の都合で追い出されない居場所 |
| 才能 | 地形、敵の継ぎ目、退路、攻城法、兵の恐怖を読む |
| 長所 | 危険を部下だけへ押しつけず、自分が前へ立つ |
| 欠点 | 自分の判断を信じすぎ、組織へ判断を渡せない |
| 誤信 | 自分一人が最後尾へ残れば全員を救える |
| 最終回答 | 指揮と責任を仲間へ渡し、自分も生きて帰る一人に数える |

又兵衛を最初から無私の聖人にしない。武名欲、誇り、独立心、他者に負けたくない気持ちを持たせる。救いたい思いと名を上げたい思いが混ざるからこそ、戸次川、城井谷、朝鮮、関ヶ原、出奔、大坂で選択が揺れる。

## 6．歴史上の固定順序

### 播磨・有岡城

1. 1577年、松寿丸が織田方への人質となる。
2. 1578年、荒木村重が反旗を翻す。
3. 官兵衛が有岡城へ入り幽閉される。
4. 信長が官兵衛の離反を疑い、松寿丸処刑を命じたと伝わる。
5. 竹中半兵衛らが松寿丸を匿う。
6. 又兵衛の一族は誓紙拒否、別所方との関係などを理由に黒田家を離れたとされる `[B]`。
7. 有岡城落城後、黒田家臣団が官兵衛を救出する。又兵衛は救出の主役にしない。

### 仙石家・戸次川

1. 又兵衛は黒田家を離れた後、仙石秀久に仕えたとされる `[B]`。
2. 1586年、戸次川で仙石・長宗我部・十河勢が島津家久軍に大敗する。
3. 又兵衛が参加した範囲は断定せず、仙石家中の一員として敗戦と逃走の余波を経験させる `[B/C]`。
4. この敗戦で、退路、情報、統一指揮を欠く軍の恐ろしさを学ぶ。

### 黒田家帰参・豊前

1. 1586〜1587年頃、栗山利安の与力、約100石で帰参 `[B]`。
2. 城井谷で又兵衛と吉田長利が地形の危険を進言したという伝承を使用できる `[D]`。
3. 長政は進軍し、黒田軍は敗れる。
4. 剃髪を拒んだ正確な台詞は伝承として扱う `[D]`。
5. 長岩城攻めで又兵衛が瀕死の重傷を負ったとされる `[B]`。
6. 又兵衛を城井鎮房の直接殺害者にしない。

### 朝鮮出兵

1. 1592年、黒田長政に従い渡海する。
2. 先鋒は偵察、渡河点確保、展開地点確保、撤退路管理を含む役割として描く。
3. 1593年の晋州城攻撃で、亀甲車と呼ばれる防護攻城具を用いた功績を描く `[A/B]`。
4. 虎退治、川中の長政を助けなかった会話は伝承として扱う `[D]`。
5. 朝鮮の兵と民、明軍、通訳、医師、船乗り、捕虜を複数視点で描く。

### 関ヶ原

1. 黒田長政は東軍に属し、調略と本戦の双方で重要な役割を担う。
2. 又兵衛は黒田軍の実戦部隊を指揮する。
3. 大橋掃部を討った伝承を採用できるが、完全な一騎討ちとして単純化しない。
4. 戦後、筑前大隈城を預かる一万〜一万六千石級の重臣へ上る `[B]`。

### 官兵衛死去・出奔・奉公構

1. 1604年、官兵衛死去。
2. 他大名との書状、家中統制、嫡男問題、長年の不遜逸話などを複合原因として描く。
3. 1606年頃、又兵衛は一族を伴い黒田家を出奔する。
4. 細川忠興を頼るが、黒田・細川両家の緊張と幕府仲裁で退去する。
5. 奉公構により安定した再仕官が難しくなる。
6. 池田家、京都・大和での浪人生活、軍学教授、1611年頃の帰参交渉を描く `[B]`。
7. 又兵衛は長政の悪口を言わなかったという伝承を採用できる `[D]`。

### 大坂の陣

1. 1614年、大坂城へ入城する。
2. 天満の閲兵、摩利支天の再来という称賛は伝承として扱う。
3. 冬の陣では約六千規模の遊軍を率い、鴫野・今福方面で戦う `[B]`。
4. 講和後、堀が埋められ、夏の陣では城外決戦しか残らない。
5. 大和郡山城爆破は確定史実にせず、郡山周辺への攻撃・放火を下敷きにした情報戦・陽動 `[C/D]` とする。
6. 家康から播磨一国を提示された話は伝承 `[D]` とする。
7. 1615年5月5日夜、約2800を率いて平野を出発したとされる `[B]`。
8. 濃霧、情報漏洩、後続遅延、国分先取によって計画が崩れる。
9. 小松山で午前4時頃から午前10時頃まで約六時間戦ったとする `[B]`。
10. 又兵衛は道明寺・小松山付近で戦死する。生還させない。

## 7．全30巻の固定区分

- 第1〜3巻：播磨、有岡城、一族追放。
- 第4〜6巻：仙石家、武名への渇望、戸次川敗戦。
- 第7〜10巻：百石帰参、城井谷、長岩城、豊前統治。
- 第11〜13巻：文禄・慶長の役、晋州城、敵国の民。
- 第14〜15巻：関ヶ原、大隈城主、一万石級への上昇。
- 第16〜18巻：官兵衛死去、長政との確執、黒田家出奔。
- 第19〜20巻：奉公構、細川・池田、京都・大和の浪人生活、帰参交渉不成立。
- 第21〜24巻：大坂入城、冬の陣、鴫野・今福、講和と堀埋立。
- 第25〜27巻：郡山周辺の陽動、寝返り工作、道明寺作戦と情報漏洩。
- 第28〜30巻：濃霧、国分先取、小松山六時間、又兵衛戦死と生存者の帰還。

## 8．黒槍の正典

黒槍は無敵武器ではなく、又兵衛の所属、負傷、補修、戦い方を保存する経歴書である。

1. 少年期：父または一族から残された焼け槍 `[C]`。
2. 仙石家時代：主家の紋を付け替えながら使う「借り物の槍」。
3. 黒田帰参後：百石の身分に合わせて短く補修された継ぎ槍。
4. 朝鮮：亀甲車の金具、船材、異国の革で補修される。
5. 関ヶ原後：黒漆を施され、初めて正式に「黒槍」と呼ばれる。
6. 出奔時：黒田家の紋と飾り紐を外すが、槍そのものは持ち出す。
7. 大坂：主家のない「無城の黒槍」となる。

右肩、脚、指、古傷を消さない。年齢と負傷によって高い振りかぶりを失い、低い水平構え、隊列、交代、地形利用へ戦い方を変える。

## 9．長政を悪役にしない

長政が必要とするのは、52万石を統治できる命令系統である。又兵衛は他大名と独自に書状を交わし、兵から主君とは別の信頼を集め、戦場判断を優先する。長政が恐れることには合理性がある。

又兵衛もまた、自分を育てた黒田家と官兵衛の恩を忘れない。二人の決裂は、恩を忘れた裏切りではなく、戦国の実戦指揮官と近世大名の統治者が、同じ家の中で共存できなくなる悲劇とする。

---

## 10．最終決断

又兵衛は道明寺で、最初から死に場所を求めない。一度は本気で撤退し、仲間へ指揮を渡す。

> **俺も、生きて帰りたい。**

その後、取り残された若年兵と伝令の声を聞き、戻る。戻る理由は、名誉や死への憧れではない。

> **俺より後ろに、誰も残さない。だから、お前たちも俺を一人にするな。**

又兵衛は史実どおり戦死する。しかし夢は「英雄の死」で完成しない。生き残った者が、名簿、退路、食卓、墓、語りとして又兵衛を連れて帰ることで完成する。
