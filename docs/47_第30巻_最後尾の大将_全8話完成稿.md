## 史実・創作区分

- **A（史実確定）**：1615年5月6日の道明寺・小松山周辺の戦闘、後藤又兵衛の戦死、大坂夏の陣の帰結。
- **B（伝承）**：又兵衛の最期の具体像、各地の墓、生存・落ち延び伝説。
- **C（創作）**：黒槍組、弦太・清十郎・カヤらの現場行動、黒旗の継承、若兵救援、帰名帳の最終記述。
- 異説は断定で潰さず、第240話で「生き残った者が、自分の土地へ帰した物語」として束ねる。

## 終幕で守る十則

1. 又兵衛を超人的な単騎無双にしない。勝因も敗因も人数、火縄、足場、伝令、時刻で描く。
2. 徳川方を卑怯な悪党の壁にしない。奥田勢の先走り、水野勢の修正、本多・松平の包囲を別の指揮系統として描く。
3. 「俺も帰る」は撤退が安全になってからの美辞麗句ではなく、まだ死傷が続く最中の行動宣言にする。
4. 又兵衛の死より、指揮を渡す手順を先に描く。
5. 若兵救援は旧欠陥への逆戻りに見せない。戻る前に代理指揮、退却時刻、救援人数、戻らない条件を定める。
6. 黒槍は必殺武器ではなく、距離を作り、倒れた者を引き、列を整える道具として終える。
7. 最終台詞だけでテーマを説明しない。命令、交代、記録、食べ残し、墓の手入れで示す。
8. 死者を全員美しく死なせない。恐怖、失禁、聞き違い、置き去りの荷、名の分からない死者も残す。
9. 第239話で又兵衛を神格化しない。帰名帳には失敗、戻った選択、帰還者数を併記する。
10. 最終話の最後は戦場ではなく、誰かが隣の人へ椀を渡す生活へ帰す。

# 第233話「午前四時」

## 話情報

| 項目 | 内容 |
|---|---|
| 時刻 | 1615年5月6日 午前四時頃 |
| 視点 | 又兵衛 |
| 即時質問 | 後続の来ない山腹で、先に攻め上がる奥田勢をどう止めるか |
| 勝利条件 | 山頂を守ることではなく、最初の一刻で後藤隊の横腹を開けない |
| 主機能 | 最終戦の物理条件を固定する |
| 引き | 退けた敵の後ろに、別の隊列が三方から現れる |

## 12頁・43コマ脚本

- **P1（1）**：薄明前。小松山の斜面。濡れた草、浅い壕、息を白くする兵。清十郎の時刻札「午前四時」。山下から奥田勢の鬨。音「オオオ」。
- **P2（3）**：弦太が後続の足音を聞くが「ない」。又兵衛は二千八百を山頂へ固めず、山腹三段へ分ける。「高い所を取った者が勝つんやない。下りる道を持った者が帰れる」。
- **P3（7）**：杭を抜く、濡れ縄を張る、火縄を雨覆いから出す、石を手渡す、負傷者置場を谷側へ移す、伝令路へ白布を結ぶ、黒旗を中央ではなく退路側へ立てる。擬音を細かく刻む。
- **P4（3）**：奥田勢が急斜面を上がる。先頭は味方到着を待たず功を焦る。又兵衛は鉄砲を撃たせず、足元の泥が崩れる距離まで待つ。「まだや」。
- **P5（3）**：敵の顔が読める距離。弦太が指を折る。又兵衛「今」。一斉射ではなく三列の順射。音「ドン、ドン、ドン」。
- **P6（3）**：敵先頭が止まり後列と衝突。黒槍隊は突き殺すより槍柄で斜面へ押し返す。又兵衛は倒れた敵兵を踏まず脇へ転がし道を残す。
- **P7（7）**：左で縄が切れる、若兵が滑る、甚六系の古参が襟を掴む、敵槍が壕を越える、又兵衛が受け流す、弦太が射手を下げる、清十郎が最初の死者三名を書く。
- **P8（3）**：奥田勢が一度退く。後藤隊から歓声が出かけるが、又兵衛が止める。「勝ってへん。息を一つ買うただけや」。水を一口ずつ回す。
- **P9（2）**：若い兵・新吉が握り飯を半分残し懐へ戻す。「母への土産やない。帰って食う分です」。又兵衛がその言い方を覚える。
- **P10（7）**：東の銃声、北の旗影、南の馬蹄、伝令の転倒、敵陣の法螺、後藤隊の旗が風向きで逆へなびく、弦太が「奥田だけやない」と告げる。
- **P11（3）**：又兵衛が斜面へ三本の短線を引く。水野、本多、松平。「敵は一つやない。せやから一度に勇ましく負けるな」。
- **P12（1）**：薄明の山を三方向から別々の隊が包む。中央手前に又兵衛の背、退路側に黒旗。N「午前四時。六時間の戦が始まった」。

## 台帳更新

- 後藤隊は山腹三段配置。黒旗は退路指標として置かれる。
- 新吉が「帰って食う半握り」を持つ。
- 死者三名を清十郎が記録開始。

# 第234話「三方向の敵」

## 話情報

| 項目 | 内容 |
|---|---|
| 時刻 | 午前五時前後 |
| 即時質問 | 三方向から圧縮される陣を、どこまで縮めれば退路を失わないか |
| 勝利条件 | 包囲完成前に部隊間隔を半分へ縮め、谷側の一本を空ける |
| 主機能 | 戦場を「敵の強さ」ではなく異なる指揮の重なりで見せる |
| 引き | 縮めた陣には、撃てる弾が一人二発もない |

## 12頁・43コマ脚本

- **P1（1）**：東の水野勢が土手を測り、北の本多勢が射線を開け、南の松平勢が馬を降りる。三隊の動きは揃っていないが、結果として山を絞る。
- **P2（3）**：又兵衛は旗の高さで距離を測る。カヤが南の馬が騎乗突撃ではなく退路封鎖だと読む。清十郎は敵名を断定せず印だけ記す。
- **P3（7）**：右隊を十間下げる、中央の壕を捨てる、負傷者を担架へ二人一組、矢玉箱を手渡し、死者の槍を回収、飲水桶を蹴り割って軽くする、谷道だけ踏み固めない。
- **P4（3）**：若い組頭が「頂を捨てれば負け」と反発。又兵衛は山頂の土を握り落とす。「土は連れて帰れへん」。
- **P5（3）**：水野勢が先に射撃。後藤隊は伏せるが、北から本多勢の弾が斜めに入る。敵同士の射線が交差する一瞬だけ又兵衛が移動を命じる。
- **P6（3）**：松平勢は味方の射線へ入らず南へ回る。カヤ「こっちは急がん。出口が閉じるのを待っとる」。
- **P7（7）**：負傷兵の足袋を切る、弾を抜かず布で固定、二人が担ぐ、一人が盾を持つ、名を聞く、聞こえず再度叫ぶ、清十郎が仮名で印を付ける。
- **P8（3）**：又兵衛は陣を円でなく細い楔へ縮める。先端が敵、尾が谷道。「前が戦い、後ろが帰り道や」。
- **P9（2）**：敵の奥田隊にも負傷者を回収する兵がいる。又兵衛はそこへ撃たせない。新吉が驚く。「敵にも最後尾はおる」。
- **P10（7）**：北の法螺、東の太鼓、南の笛、別々の命令音。後藤隊の伝令が一つ聞き違え、右翼が早く下がる。又兵衛自らでなく副将が修正する。
- **P11（3）**：三方向の敵線が近づく。又兵衛は黒旗をさらに谷側へ十間移す。弦太が矢玉箱を逆さにする。
- **P12（1）**：箱底に散るわずかな弾。弦太「一人二発もない」。又兵衛の顔に初めて計算不能の影。

## 台帳更新

- 陣形は細い楔。黒旗は谷道へ移動。
- 又兵衛以外の副将が命令修正を担い始める。
- 残弾不足が確定。

# 第235話「弾を数えろ」

## 話情報

| 項目 | 内容 |
|---|---|
| 時刻 | 午前六〜七時 |
| 視点 | 弦太を強い副視点に置く |
| 即時質問 | 弾が足りない時、誰に何発を渡すか |
| 勝利条件 | 射手ごとの残弾と確実射程を共有し、空撃ちと重複射撃を止める |
| 主機能 | 弦太の生涯の才能を最終戦の仕組みにする |
| 引き | 弾を節約して得た時間の先に、退路が一度だけ開く |

## 12頁・43コマ脚本

- **P1（1）**：弦太が泥の上へ全隊の火縄銃を並べ、銃ではなく弾袋を数える。「銃の数やない。撃てる数を言え」。
- **P2（3）**：各組が七、十一、三、零と申告。虚勢で「まだある」と言う組頭の袋を弦太が自分で開く。空。
- **P3（7）**：鉛玉を大中に分ける、合わない玉を布で包む、火薬を竹筒へ均等化、湿った火縄を切る、射手名を木札で割り当て、二人一銃へする、撃ったら石を一つ裏返す。
- **P4（3）**：又兵衛が「前へ多く」と言いかけ、弦太が遮る。「戻る列にも要る」。又兵衛は一拍置き「お前が決めろ」。
- **P5（3）**：敵が遠距離から誘い撃ち。若兵が引き金へ指を掛ける。弦太は銃口を下げる。「顔が見えるまで撃つな」。
- **P6（3）**：敵が近づく恐怖を生活音で描く。歯が鳴る、火縄が焦げる、汗が目へ入る。新吉が半握りを触って耐える。
- **P7（7）**：敵の草鞋、膝、家印、目が順に見える。弦太が一列目、二列目、三列目を別々に撃たせる。音を重ねず間を置く。
- **P8（3）**：命中より敵の足を止める。又兵衛隊はその間に負傷者を谷へ送る。鉄砲兵自身も射撃後すぐ担架を持つ。
- **P9（2）**：弦太の耳が銃声で一時聞こえなくなる。口の動きだけで又兵衛の命令を読み、「右へ二十」と手信号で返す。
- **P10（7）**：石を裏返す、袋が空く、敵が伏せる、北隊が東隊の前へ重なる、南の封鎖兵が負傷回収で一度薄くなる、カヤが谷道の開口を指す、黒旗が風で立つ。
- **P11（3）**：弦太「今だけや。次はない」。又兵衛は全隊ではなく第一陣五百を谷へ下げる命令を出す。
- **P12（1）**：谷道に人一列分の隙間。黒旗の下を最初の負傷者が通る。N「弾が買ったのは勝ちではない。帰る順番だった」。

## 台帳更新

- 火縄銃は二人一銃、石による残弾管理。
- 弦太へ配弾権限が正式に渡る。
- 第一陣五百の撤退開始。

# 第236話「俺も帰る」

## 話情報

| 項目 | 内容 |
|---|---|
| 時刻 | 午前八時頃 |
| 即時質問 | 又兵衛は撤退を命じながら、自分を帰還者へ数えられるか |
| 勝利条件 | 全隊へ「大将も退く」時刻と順番を宣言し、無意味な殿死を防ぐ |
| 主機能 | 全30巻の主人公欠陥を言葉と手順で反転する |
| 引き | 又兵衛の生還宣言を受け、仲間が指揮を分ける準備を始める |

## 12頁・43コマ脚本

- **P1（1）**：谷へ下る負傷者列。担架の一人が「大将は」と問う。誰も答えない。
- **P2（3）**：又兵衛はいつものように「先に行け」と言う。新吉が半握りを差し出す。「帰って食う分、二つにしました」。
- **P3（7）**：又兵衛が半握りを見る、父へ残した半椀、お菊の問い、松寿丸の背、戸次川の未帰還、朝鮮の渡海、長政との別れ、現在の濡れた手へ戻る。説明台詞なし。
- **P4（3）**：又兵衛は清十郎へ現在人数を聞く。清十郎「生きて歩ける者二千百余、担架二百余、死者と不明はまだ数え切れません」。
- **P5（3）**：又兵衛「帰る人数に、俺を一人足せ」。清十郎の筆が止まる。「聞き違いやない」。
- **P6（3）**：又兵衛が全組頭へ叫ぶ。「俺も帰る！　せやから俺を待って全員死ぬな。俺が遅れたら、決めた時刻で下りろ！」
- **P7（7）**：驚く古参、泣き笑う若兵、命令を復唱する副将、退却時刻の縄結び、黒旗へ二本目の白布、担架列の速度測定、新吉が半握りを戻す。
- **P8（3）**：敵弾が又兵衛の肩袖を裂く。英雄的に無視せず、カヤが止血し腕の可動を確認。「帰る言うた口で、傷を隠すな」。
- **P9（2）**：又兵衛は傷を清十郎へ申告させる。「右肩、浅い」。自分の身体も隊の資源として台帳へ入る。
- **P10（7）**：第二陣が下る、敵が追う、弦太が最後の二発を撃つ、黒槍組が追手を止める、副将が又兵衛を下がらせる、又兵衛が一度従う、部下がその事実に息を呑む。
- **P11（3）**：谷の中腹で又兵衛が振り返る。山腹にはまだ千余。又兵衛「俺の下りる刻を、九つ目の法螺にする」。
- **P12（1）**：清十郎が帰還人数欄へ「又兵衛 一」と書く手元。背後で九つ目まで数える縄が結ばれる。

## 台帳更新

- 又兵衛は初めて自分を帰還人数へ入れる。
- 右肩浅傷を公開記録。
- 九つ目の法螺を又兵衛自身の撤退期限とする。

# 第237話「指揮を渡す」

## 話情報

| 項目 | 内容 |
|---|---|
| 時刻 | 午前九時前後 |
| 即時質問 | 大将が傷つき伝令路が切れた時、誰がどの範囲を決めるか |
| 勝利条件 | 黒旗・退却時刻・負傷者・射手・最後尾を五つの指揮へ分割する |
| 主機能 | 主人公の思想を組織へ移す |
| 引き | 指揮を渡した直後、撤退列の外から若兵の呼び声がする |

## 12頁・43コマ脚本

- **P1（1）**：敵弾で伝令二人が同時に倒れ、又兵衛の命令が左右へ届かない。
- **P2（3）**：又兵衛が全て自分で走ろうとするが右肩が上がらない。弦太「帰る言うたのは、全部自分でやるいう意味やない」。
- **P3（7）**：黒旗を副将へ、残弾を弦太へ、負傷者列をカヤへ、人数と時刻を清十郎へ、前面の槍列を又兵衛へ。五本の縄を地図の別方向へ置く。
- **P4（3）**：又兵衛「最後尾は交代する。百歩ごとに次の組が受けろ。前の組は必ず列へ戻れ」。古参が「殿は名誉」と反発。
- **P5（3）**：又兵衛「名誉で人数は増えへん。最後尾は役目や。人やない」。黒旗の柄を副将へ渡す。
- **P6（3）**：副将が黒旗を受け取る手が震える。又兵衛は握り直させず、震えたまま持たせる。「怖い手でも命令は出せる」。
- **P7（7）**：第一最後尾が百歩守る、白石を置く、第二組が受ける、第一組が走って列へ戻る、負傷者が道を空ける、カヤが速度を調整、清十郎が交代時刻を書く。
- **P8（3）**：敵も交代制を見抜き追撃を強める。又兵衛は槍列を斜めにし、一点で勝たず追手の速度だけ落とす。
- **P9（2）**：黒槍の穂が欠ける。又兵衛は折れた先を捨てず、柄で倒れた味方の帯を引く。「最後まで武器やなく、手やった」。
- **P10（7）**：九つ目の法螺が近づく、清十郎が指を八まで出す、弦太の弾は零、カヤの担架列が谷を抜ける、副将が独断で黒旗を下げる、全隊が一段下がる、又兵衛がその命令へ従う。
- **P11（3）**：又兵衛は指揮が自分なしで動くのを見る。「それでええ」。新吉の姿が列にないことをカヤが気づく。
- **P12（1）**：霧の薄い山腹外から「大将――！」。倒木の向こうで三人の若兵が取り残されている。

## 台帳更新

- 黒旗は副将へ譲渡。
- 最後尾を百歩ごとの交代制にする。
- 又兵衛抜きで全隊が一段撤退できる。
- 新吉ら三名が撤退列外に取り残される。

# 第238話「戻る槍」

## 話情報

| 項目 | 内容 |
|---|---|
| 時刻 | 午前十時前後 |
| 即時質問 | 三人を救うため戻ることは、全隊を危険へ戻すことにならないか |
| 勝利条件 | 救援を七人・半刻・法螺一回に限定し、本隊の撤退を止めない |
| 主機能 | 又兵衛の死を欠陥の反復ではなく、継承後に選んだ限定救援として描く |
| 引き | 又兵衛は三人を列へ返し、自分は致命傷で山腹に残る |

## 12頁・43コマ脚本

- **P1（1）**：又兵衛が呼び声へ一歩戻る。同時に黒旗は谷へ進み続ける。二方向の動きを同じ画面へ置く。
- **P2（3）**：副将が止めようとする。又兵衛「本隊は止めるな。七人だけ。半刻。法螺一つで打ち切る」。清十郎へ条件を復唱させる。
- **P3（7）**：又兵衛、弦太、カヤ、槍兵四名を選ぶ。弦太は弾なしの銃を杖へ、カヤは帯二本、又兵衛は欠けた黒槍柄、四名は盾二枚と縄を持つ。
- **P4（3）**：倒木の向こうに新吉と二人。一人は脚を挟まれ、一人は耳が聞こえず逆方向へ這う。敵の追手も近い。
- **P5（3）**：又兵衛は敵を倒し切ろうとせず倒木を梃子で動かす。黒槍柄を差し込み七人で押す。音「ミシ」。
- **P6（3）**：新吉が「俺を置け」と言う。又兵衛「置くかどうかは、お前一人の権限やない」。半握りを新吉の口へ押し込む。
- **P7（7）**：縄を脇へ通す、脚を抜く、耳の聞こえない兵へ目で合図、盾が弾を受ける、槍兵一人が倒れる、カヤがその名を叫ぶ、弦太が空銃で追手の顔を打つ。
- **P8（3）**：法螺一回。時間切れ。又兵衛は倒れた槍兵も縄へ結び、「生死は谷で数えろ」と送る。
- **P9（2）**：若兵三人と負傷槍兵が斜面を下る。新吉が振り返る。又兵衛「半分、残しとけ」。
- **P10（7）**：又兵衛の腿へ弾、脇腹へ槍、黒槍柄で間を作る、弦太が戻ろうとする、又兵衛が命令札を投げる、札には可読文でなく九結びの縄、弦太が意味を理解しカヤと下がる。
- **P11（3）**：又兵衛一人に見えるが、遠景では交代最後尾がまだ射線を切っている。又兵衛は完全な孤立ではなく、仕組みの最後の一端として残る。
- **P12（1）**：又兵衛が膝をつき、谷へ消える黒旗を見る。N「千余の背が、彼より前にあった」。音は遠い法螺のみ。

## 台帳更新

- 新吉ら三名は救出される。
- 救援は七人・半刻・法螺一回の限定行動。
- 又兵衛は腿銃創・脇腹槍傷で致命傷。
- 弦太とカヤは命令に従って撤退。

# 第239話「帰名帳の一行」

## 話情報

| 項目 | 内容 |
|---|---|
| 時刻 | 5月6日昼〜夜 |
| 視点 | 清十郎 |
| 即時質問 | 大将の死を、英雄譚でなく何と記すか |
| 勝利条件 | 生還者、戦死者、不明者、又兵衛の命令と失敗を同じ頁へ残す |
| 主機能 | 死の確定と記録による帰還 |
| 引き | 帳面の一行が、各地で別々の墓と物語へ増えていく |

## 12頁・43コマ脚本

- **P1（1）**：谷を抜けた黒旗が地面へ伏せられる。誰も勝鬨を上げない。人数を数える声だけ。
- **P2（3）**：清十郎が歩ける者、担架、運ばれた死者、不明を別々に数える。数が合わず最初からやり直す。
- **P3（7）**：名前を呼ぶ、返事、二度呼ぶ、別人が「見た」と答える、死者の懐から札、札のない者の特徴、仮名欄を作る。
- **P4（3）**：新吉が半握りを清十郎へ見せる。「大将に食わされた残りです」。清十郎は遺品欄でなく生還理由欄へ書く。
- **P5（3）**：弦太は又兵衛の最期を断定しない。「見届けてへん」。カヤは傷の深さと歩けない状態を事実として述べる。
- **P6（3）**：敵方から回収された遺体の特徴が届く。黒い槍柄、右肩の裂け、古傷。清十郎は筆を握れない。
- **P7（7）**：墨をする、筆先を整える、又兵衛の名を書く、線を引き直す、「戦死」と書く、消さない、横へ小さく「撤退命令後、三名救援へ戻る」。
- **P8（3）**：弦太が「美しく書くな」と言う。清十郎「美しくは書かん。帰れた人数を書く」。
- **P9（2）**：清十郎は「生還 千余名」と記し、確定できない端数は空欄のまま残す。数字を誇張しない。
- **P10（7）**：黒旗を畳む、折れた槍柄を布へ包む、九結びの縄を帳へ挟む、負傷者へ水、敵兵の死者名も分かる範囲で別紙、夜の焚き火、誰かが又兵衛の椀を探すが見つからない。
- **P11（3）**：新吉が半握りを食べようとして止まる。清十郎「食え。残すために帰ったんやない」。二人で半分ずつ食べる。
- **P12（1）**：帰名帳の頁。又兵衛の一行と、その下に千余名の帰路を示す長い線。N「名を書けば死者が生き返るわけではない。ただ、置き去りにはしない」。

## 台帳更新

- 又兵衛の戦死を確定。
- 帳面に失敗・救援・生還者数を併記。
- 黒旗、折れた槍柄、九結びの縄が継承物になる。

# 第240話「それぞれの墓」

## 話情報

| 項目 | 内容 |
|---|---|
| 年代 | 1615年以後。数年から数十年を飛ぶ |
| 視点 | 生還者たち、各地の名もなき生活者 |
| 即時質問 | 遺体も結末も一つに定まらない人を、どこへ帰すのか |
| 勝利条件 | 生存伝説と複数の墓を矛盾として処理せず、継承された行動へ着地する |
| 主機能 | 全240話の終幕 |
| 最終余韻 | 欠けた椀を隣へ渡す。最後尾には次の人が入る |

## 12頁・43コマ脚本

- **P1（1）**：小松山の雨上がり。名のない塚へ一人の農夫が小石を置く。顔は新吉かもしれないが断定しない。
- **P2（3）**：大和、播磨、筑前、伊予など異なる土地の小さな墓。立派な廟ではなく、畑端、寺裏、峠道。刻字は絵として読ませず土地と手入れで違いを出す。
- **P3（7）**：老人が草を抜く、子が水を運ぶ、旅人が黒い布を結ぶ、武士が槍柄を供える、百姓が握り飯を半分置く、別の者が「生き延びた」と語る、聞く子が首をかしげる。
- **P4（3）**：清十郎の帰名帳が写されるたび、又兵衛の最期の表現が少しずつ違う。だが「千余を先へ」「三人へ戻る」は残る。
- **P5（3）**：弦太は若者へ鉄砲を教えるが、最初に残弾石を渡す。「撃ち方より、残りを言えるようになれ」。
- **P6（3）**：カヤは村の避難訓練で最後尾を交代させる。子どもが「一番強い人が最後やないの」と問う。「違う。次の人へ渡せる人や」。
- **P7（7）**：黒旗が葬具、道標、避難布、荷車の目印へ形を変える。戦の象徴を生活の道具へ戻す七つの短景。
- **P8（3）**：成長した新吉が家へ帰る。老母へ土産ではなく、あの日残した半握りの話をする。母は笑い「古すぎて食えん」と椀へ新しい粥をよそう。
- **P9（2）**：食卓には一椀足りない。新吉が自分の椀を隣の子へ半分分ける。第1話の半椀を反復するが、父を待つ欠けではなく生きた隣人との分け合いに変える。
- **P10（7）**：松寿丸＝長政の不在を直接再会で埋めない。筑前の黒田家中で、若い家臣が「又兵衛は帰らなかった」と言う。老臣が「帰らんかったんやない。帰し方を残した」と訂正する。窓外を兵が家族の元へ戻る。
- **P11（3）**：各地の墓を一枚の地図へまとめない。別々の場所で、別々の人が同じ所作をする。後ろの人数を数え、次の者へ振り返る。
- **P12（1・断ち切り）**：雨上がりの細い道。荷を背負う一団が村へ帰る。最後尾の男が後ろを確認し、前の者と交代する。手前の家では湯気の立つ粟粥を子どもが隣へ半椀渡す。N「欲しいものは前にあった。大事なものは、いつも隣にいた」。下段小さく「戦帰 SENKI　完」。

## 最終台帳

### 人物

- **後藤又兵衛**：1615年5月6日、小松山で戦死。大将も帰還人数へ入ると宣言し、黒旗と指揮を渡した後、限定救援へ戻る。自分一人で最後尾を独占する欠陥を、交代制へ変えて終える。
- **弦太**：残弾管理と射撃権限を継承。戦後は「残りを申告する」技術を伝える。
- **清十郎**：帰名帳へ又兵衛の失敗・選択・生還者数を併記し、神話化を抑える記録者になる。
- **カヤ**：負傷者列と撤退速度を管理し、戦後は避難の最後尾交代を生活へ残す。
- **新吉**：半握りを持って生還。又兵衛の言葉を武勇譚でなく食卓の分け合いとして次代へ渡す。
- **松寿丸／黒田長政**：最終戦で再会しない。又兵衛との約束は、黒田家の若い世代が「帰し方」として受け取る。

### 道具・象徴

- **黒槍**：穂が欠け、最後は救助の梃子と帯を引く柄になる。
- **黒旗**：大将個人の旗から、退路指標・避難布・生活の道標へ変わる。
- **帰名帳**：死者名だけでなく、失敗、選択、生還者数、未確認を残す。
- **九結びの縄**：又兵衛自身の撤退期限。命令を守らせる継承物。
- **半握り／半椀**：第1話の「帰らない父を待つ半椀」から、最終話の「帰った者が隣へ渡す半椀」へ反転する。
- **複数の墓**：史実の不確定さではなく、各地の生存者が又兵衛を自分の土地へ帰した証。

# manga-spread制作規約

- 各話12頁・43コマ。基本配分は `1 / 3 / 7 / 3 / 3 / 3 / 7 / 3 / 2 / 7 / 3 / 1`。
- P1・P12は全面一コマ、P3・P7・P10は速射頁。
- 小松山を巨大な岩山や城郭にしない。低い山、畑、土手、用水、濡れ草、浅い壕で描く。
- 後藤隊二千八百、徳川方約二万超は群衆クローンで埋めず、旗系統、火線、法螺、道の占有、奥行きで規模を示す。
- 又兵衛の負傷は右肩浅傷→腿銃創→脇腹槍傷の順。前話より軽く戻さない。
- 生成画像へ台詞・題字・札の可読文字を描かせない。写植は分割後に行う。
- 父の栗毛、少年期の母・妹は第236話の無言断片のみ。新規会話や死後幻影を作らない。
- 最終頁は英雄の巨大肖像にしない。交代する最後尾と半椀の生活を主景にする。
