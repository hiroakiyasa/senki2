# Manga spread asset reference policy

1. Resolve the character ID and age/status version from the canon script.
2. Select the exact committed path from `manifest.json`.
3. Add that sheet to reference-board section ③ for every spread in which the character appears.
4. For non-Matabei characters, `v01.png` is the absolute face master. Later versions retain eye size, iris ratio, eye spacing, face outline, nose, mouth, chin, and defining hair structure.
5. If the required age version is absent, stop and create/approve it. Never improvise a different face inside a spread.
6. Use `world_assets.html` as the continuity inventory. Only assets with an actual approved image and manifest entry may enter reference-board section ④.
7. Authority: canon script > exact character sheet > approved world/prop sheet > approved style anchor > previous spread.
