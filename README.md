# 戦帰 SENKI

戦国時代を舞台に、後藤又兵衛を中心として描く全30巻・240話の歴史群像漫画企画です。

> **又兵衛が人を連れて帰り、松寿丸が帰る場所を作る。**

> **俺は、どんな負け戦でも、最後の一人まで連れて帰る大将になる。**

## 物語本文の唯一の入口

第1巻から第30巻までの最新物語本文は、次の一つのフォルダーだけにあります。

- [最新正典 第1巻〜第30巻](story/latest_canon_v01-v30/README.md)

## フォルダーの役割

- `story/latest_canon_v01-v30/`：第1〜30巻の最新物語本文。唯一の本文正典。
- `docs/`：正典ルール、人物設定、史実監査、全体設計、制作憲法。物語本文は置かない。
- `scripts/v01`〜`scripts/v30`：見開き生成・写植へ進むための各話制作脚本。
- `production/`：承認済み人物、建物、小道具、画像制作物。
- `.codex/skills/`・`.claude/skills/`：漫画制作と品質監査の手順。

物語本文と制作資料を混在させず、本文の版管理は `story/latest_canon_v01-v30/` に一本化します。
