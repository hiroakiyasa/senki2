# 戦帰 SENKI

戦国時代を舞台に、後藤又兵衛と黒田長政を軸に描く、全30巻・240話想定の歴史群像漫画企画です。

本作は単なる「戦国版キングダム」ではありません。家も地位もない少年が、武力・人間力・身分を高めながら、多様な仲間と敵に出会い、「強い大将とは何か」「守るために誰かを切り捨ててよいのか」「夢を叶えた先に本当に大切なものは何か」を知っていく物語です。

## 作品の核

> **俺は、どんな負け戦でも、最後の一人まで連れて帰る大将になる。**  
> **俺より後ろに、誰も残さない。**

この夢は、初読では勇敢な誓いに見えます。

しかし又兵衛は、守る人数の中へ自分を入れていません。人を守る長所と、自分だけは犠牲になってよいと思う欠点が、同じ言葉から生まれます。

全30巻で問うのは、又兵衛が大勢を帰せるかだけではありません。

> **又兵衛自身も、仲間が連れて帰りたい一人だと認められるか。**

作品全体を貫くもう一つの言葉は、次の通りです。

> 欲しいものは前にある。大事なものは、いつも隣にいる。

## 第1巻の位置づけ

第1巻『雨の夜、二人の大将』は、一巻で30巻分の答えを説明する巻ではありません。

表面の物語は単純です。

> **父と若君を、夜明けまでに連れて帰る。**

この一夜で、又兵衛は松寿丸、村人、仲間を救い、最初の勝利を得ます。一方で、次の問題は解決しません。

- 父が隊列を離れた本当の理由
- 松寿丸の行路を漏らした内通者
- 焼けた無銘槍の所有と七度の補修
- 「俺より後ろに誰も残さない」という誓いの危うさ
- 松寿丸が人質として差し出される政治
- 又兵衛と長政が、同じ願いから反対の決断へ至る未来

したがって第1巻は「一巻完結の全部盛り」ではなく、**第1部第1章として局地的な事件を閉じ、全30巻の問いを開く巻**です。

## 基本方針

### 史実と創作の区分

- **A：史実確定** — 年代、所属、勝敗、主要人物の生死など
- **B：伝承** — 軍記、家譜、地域伝承に基づく要素
- **C：創作** — 会話、架空人物、私的任務、象徴物、仲間関係など

創作によって史実上の大きな勝敗や、歴史人物の決定的役割を奪いません。歴史書に残りにくい救出、撤退、潜入、情報戦、兵站、民間人避難を物語の主戦場にします。

### 深くする方法

複雑さを、最初から国名・派閥・設定説明で読ませません。

1. 表面は一文で分かる任務にする
2. 勝利が次の問題を生む
3. 同じ言葉の意味を巻が進むほど反転させる
4. 敵を、主人公と同じ傷への別の答えにする
5. 事件の真相より、真相を知った人物の選択を重くする

### 作品の最終的な問い

> 武将は、何のために強くなるのか。

- 本多忠勝は、味方を戦わせないために強くなる
- 石田三成は、法と兵站で万人を支えるために強くなる
- 立花宗茂は、家臣の信頼に応えるために強くなる
- 黒田長政は、家と領民を守るために強くなる
- 徳川家康は、戦国時代そのものを終わらせるために強くなる
- 後藤又兵衛は、最後の一人を見捨てないために強くなる

ただし「兵を帰すこと」を戦国全体の共通評価軸にはしません。敵将は武力、軍略、統率、野望、国家観によって評価され、その中で又兵衛だけが、勝利の裏で消える一人へ異常にこだわります。

最終章で又兵衛は、自分もまた仲間にとって守る価値のある一人だと知ります。
