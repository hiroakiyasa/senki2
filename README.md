# 戦帰 SENKI

戦国時代を舞台に、後藤又兵衛を中心として描く全30巻・240話想定の歴史群像漫画企画です。

本作は単なる「戦国版キングダム」ではなく、身分の低い若者が武力・人間力・身分を高めながら、多様な仲間と敵に出会い、「強い大将とは何か」「夢を叶えた先に本当に大切なものは何か」を知っていく物語を目指します。

## 作品の核

> 欲しいものは前にある。大事なものは、いつも隣にいる。

後藤又兵衛は、家柄も地位もない少年から始まります。強さ、名、城、家臣を求めて戦国の世を駆け上がりますが、夢を叶えた時、最も大切だったのは、それを自分のことのように喜んでくれる仲間だったと気づきます。

又兵衛の強さは、単なる槍の強さではありません。

- 相手の身分や過去で価値を決めない
- 本人が捨てようとした長所を拾い上げる
- 仲間の夢を自分の夢と同じ重さで扱う
- 言葉より先に危険へ飛び込む
- 敵だった者にも、生き方を選ぶ機会を与える
- 自分だけは犠牲になってよいと思う危うさを持つ

この人間的魅力によって、かつての敵さえ一人ずつ仲間や理解者へ変わります。

## 基本方針

### 史実と創作の区分

- **A：史実確定** — 年代、所属、勝敗、主要人物の生死など
- **B：伝承** — 軍記、家譜、地域伝承に基づく要素
- **C：創作** — 会話、架空人物、私的任務、象徴物、仲間関係など

創作によって史実上の大きな勝敗を変更せず、歴史書に残らなかった救出、撤退、潜入、情報戦、兵站、民間人の避難を物語の主戦場として描きます。

### 作品の最終的な問い

> 武将は、何のために強くなるのか。

- 本多忠勝は、味方を戦わせないために強くなる
- 石田三成は、法と兵站で万人を支えるために強くなる
- 立花宗茂は、家臣の信頼に応えるために強くなる
- 黒田長政は、家と領民を守るために強くなる
- 徳川家康は、戦国時代そのものを終わらせるために強くなる
- 後藤又兵衛は、弱い者を見捨てなくても勝てる大将になるために強くなる

最終章では、それぞれの答えが大坂夏の陣に集まり、又兵衛は自分もまた仲間にとって守る価値のある一人だと知ります。
