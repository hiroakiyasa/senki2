# 戦帰 SENKI

戦国時代を舞台に、後藤又兵衛を中心として描く全30巻・240話想定の歴史群像漫画企画です。

本作は単なる「戦国版キングダム」ではありません。帰る場所を持たない少年・又兵衛と、国を背負って生まれた若君・松寿丸が、

> **又兵衛が人を連れて帰り、松寿丸が帰る場所を作る**

と約束し、同じ願いから正反対の答えへ進む物語です。

## 作品の核

> **欲しいものは前にある。大事なものは、いつも隣にいる。**

又兵衛は、家柄も地位もない少年から始まります。強さ、名、城、家臣を求めて戦国の世を駆け上がりますが、夢を叶えた時、最も大切だったのは、それを自分のことのように喜んでくれる仲間だったと知ります。

又兵衛の夢は、次の一文へ統一します。

> **俺は、どんな負け戦でも、最後の一人まで連れて帰る大将になる。**

象徴となる言葉は、

> **俺より後ろに、誰も残さない。**

です。

ただし、又兵衛は自分だけを「連れて帰る一人」に数えません。この長所と欠点が同じ場所にあることが、全30巻の物語を動かします。

## 各巻・各話を作る時の必須手順

1. `00`で正典、年代、史実A・伝承B・創作Cを確認する。
2. `17`で対象巻と前後巻の最新構成を確認する。
3. `09_全キャラクター正典_v2`で人物の夢、欠落、技能、関係、負傷、生死を確認する。
4. 槍戦がある場合、`06_武力と身分の成長`と`14_旧senki槍術資産継承`で、武器構造、技法、負傷、足場、間合いを確認する。
5. `12`で、その巻が中心矛盾と20項目を満たすか確認する。
6. `13`の話別設計カードを埋め、ハードゲートを全て通す。
7. 対象巻の完成稿・制作脚本を確認して本文・ネームを書く。
8. 執筆後、人物、情報、負傷、道具、死、日常、象徴の台帳を更新する。

## 第1〜14巻の大きな波形

- **第1〜3巻**：少年と若君、五人組の誕生。
- **第4〜7巻**：仲間が家族になり、それぞれの夢を持つ。
- **第8〜9巻**：高松城と中国大返しで天下規模の黄金期へ上がる。
- **第10巻**：成功と昇進が仲間を別々の役職へ分ける。
- **第11巻**：小牧・長久手で徳川軍の強さと、勝てない相手から退く勇気を知る。
- **第12巻**：四国の海、一宮城の水、降伏兵の保護を経て、仙石の出世と自分の武名へ酔う。
- **第13巻**：島津が九州を席巻し、退路を先に奪う統一軍の恐ろしさを知る。
- **第14巻**：戸次川で命令不統一と焦りが大敗を招き、又兵衛の「全員帰す」という約束が壊れる。

## 基本方針

### 史実と創作の区分

- **A：史実確定** — 年代、所属、勝敗、主要人物の生死など
- **B：伝承** — 軍記、家譜、地域伝承に基づく要素
- **C：創作** — 会話、架空人物、私的任務、象徴物、仲間関係など

創作によって史実上の大きな勝敗を変更せず、歴史書に残らなかった救出、撤退、潜入、情報戦、兵站、民間人の避難を物語の主戦場として描きます。

### 作品の最終的な問い

> **武将は、何のために強くなるのか。**

- 本多忠勝は、味方を戦わせないために強くなる。
- 石田三成は、法と兵站で万人を支えるために強くなる。
- 立花宗茂は、家臣の信頼に応えるために強くなる。
- 黒田長政は、家と領民を守るために強くなる。
- 徳川家康は、戦国時代そのものを終わらせるために強くなる。
- 後藤又兵衛は、弱い者を見捨てなくても勝てる大将になるために強くなる。

最終章では、それぞれの答えが大坂夏の陣へ集まり、又兵衛は自分も仲間にとって守る価値のある一人だと知ります。
