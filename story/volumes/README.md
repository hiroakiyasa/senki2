# 『戦帰 SENKI』第1巻〜第30巻 統合フォルダー

## 完成の定義

各巻は次の5条件をすべて満たした時だけ「完成」とする。

- 8話すべてに本文または完成稿がある
- 各話が12頁・原則43コマの制作仕様まで落ちている
- 前巻からの負傷・道具・情報・人物関係が接続される
- 巻末で次巻の不可逆条件が明記される
- 完成稿、制作脚本、READMEの三者が同じ状態を示す

現状の不足は [INCOMPLETE_AUDIT.md](./INCOMPLETE_AUDIT.md) に集約する。
