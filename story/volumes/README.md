## 巻間整合

全巻の負傷、黒槍、欠けた椀、帰名帳、所属、人数、史実境界、前後巻不可逆条件は [`CONTINUITY_AUDIT.md`](./CONTINUITY_AUDIT.md) に統合した。

## 完成判定

物語正典については、全30巻・240話に本文または統合完成稿があり、前後巻の開始条件と終了台帳を接続済みとする。各話制作は既存 `scripts/vXX/` または本フォルダーの43コマ統合稿を入口とする。

画像生成、写植、96頁レンダリング、Kindle・印刷入稿は漫画製造工程であり、物語正典完成とは別管理とする。
