## 第17話　長浜の朝

| 項目 | 内容 |
|---|---|
| 視点 | 松寿丸 |
| 表面目標 | 朝餉までに人質屋敷の全員がいることを確かめる |
| 即時質問 | 昨夜、戻らなかった小者はどこへ行ったのか |
| 選択 | 自分の膳へ手をつける前に、名も知らない小者の所在を尋ねる |
| 不可逆な変化 | 松寿丸は、人質屋敷でも「帰らなかった者」を数える習慣を持つ |
| 次話への代価 | 監視役に、若君が人と出入りを見すぎていると警戒される |

夜明け前、松寿丸は廊下の板が鳴る回数で目を覚ました。

一人、二人、三人。炊事場へ向かう女中が二人。井戸へ水を汲みに行く小者が一人。門の内側で槍を立て直す番士が二人。

昨夜までは、もう一人いた。

松寿丸は薄い布団から起き、障子を指一本だけ開けた。外は白い霧だった。長浜の朝は、播磨より水の匂いが濃い。琵琶湖から上がる湿り気が庭石と軒を濡らし、番士の草鞋の裏へ黒い土を貼りつかせていた。

枕元には小さな黒田の手旗が畳んである。橋砦で握っていたものと同じだった。旗竿は人質屋敷へ入る時に取り上げられ、布だけ返された。

「お目覚めでございますか」

監視役の小寺新七が障子の外から声をかけた。

「水汲みの弥助は」

新七は少し黙った。

「若君が気にする者ではございません」

「昨夜、帰っていない」

「里へ使いに出ました」

「いつ帰る」

「用が済めば」

松寿丸はその答えを覚えた。帰る時刻を言えない者は、帰らない理由も言っていない。

朝餉には白い飯が出た。黒田の屋敷でも祭りの日にしか見ない量だった。味噌汁には豆腐が浮き、皿には小さな鮎が一尾置かれている。

隣の間では、番士が冷えた麦飯を食べていた。

松寿丸は箸を取らなかった。

「毒見は済んでおります」

「弥助の分は」

「ございません」

「昨日はあった」

新七の眉が動いた。

松寿丸は膳の鮎を半分に割った。飯も半分、椀の汁も半分だけ残した。

「帰ったら温めてやれ」

橋砦で又兵衛が言った言葉を、そのまま使った。

新七は笑わなかった。

昼前、弥助は戻った。袖口が濡れ、右足を引きずっていた。里への使いだと言われたのに、裾には山道の赤土が付いている。

松寿丸は何も尋ねなかった。ただ、朝に残した飯を指した。

弥助は困った顔をし、番士を見た。

「若君の御膳には触れられません」

「なら、僕が食べさせる」

松寿丸は飯を一口ずつ箸で運んだ。弥助は膝をついたまま食べた。

その夜から、松寿丸は毎朝、屋敷の人数を数えた。

名を知っている者は名で。知らない者は、草鞋の音、咳、薪を割る癖で。

人質として覚えるべきは礼法と家格だと教えられていた。

けれど松寿丸が最初に覚えたのは、帰れなかった者の顔だった。

## 第18話　若君の値段

| 項目 | 内容 |
|---|---|
| 視点 | 松寿丸 |
| 表面目標 | 黒田家から届いた冬支度の荷を、自分付きの者へ公平に分ける |
| 即時質問 | なぜ松寿丸の寝具一枚が、番士三人分の扶持として記録されるのか |
| 選択 | 上等な夜着を受け取らず、屋敷全員の蓑と足袋へ換えるよう求める |
| 不可逆な変化 | 松寿丸は自分の食事・寝床・病まで政治の勘定に入ると知る |
| 次話への代価 | 役人は松寿丸が人質の価値を自分で下げようとしていると疑う |

冬支度の荷は、長持一つでは足りなかった。

黒田家から送られた綿入りの夜着、干柿、薬種、紙、燭台、炭。荷札には一つずつ値が書かれ、受取役の織田方役人が算木を置いていった。

「夜着一領、銀三匁相当」

「そんなにするのか」

松寿丸が問うと、役人は顔を上げずに答えた。

「若君が風邪を召されれば、黒田家の忠節に疑いが出ます。病ませぬための費えは、政の費えです」

「僕が寝る布が、どうして忠節になる」

「人質とは、そこにいるだけで証文になる者です」

役人は夜着の端をめくり、綿の厚さを確かめた。

「食事、寝床、医者、警固。すべて、若君を預かる値であり、黒田家を信じる値でもある」

庭では門番たちが破れた蓑を縄で縫っていた。朝から冷たい雨が降り、門番の子・庄吉が父の足袋へ藁を詰めている。

松寿丸は夜着を抱えた。柔らかく、温かかった。お菊ほどの年の頃なら、顔を埋めて眠りたくなる布だった。

「これを返す」

役人が初めて顔を上げた。

「不足がございましたか」

「これ一枚で、蓑はいくつ買える」

「品が違います」

「値を聞いている」

役人は算木を動かした。

「粗い蓑なら十二。足袋なら二十足ほど」

「換えてくれ」

新七が慌てて口を挟んだ。

「若君、それでは黒田家の面目が」

「僕が寒くないことが面目なら、門を守る者が凍えるのは誰の面目だ」

役人は夜着を畳み直した。

「若君は、ご自分の値を下げたいのですか」

「人の値を布で決めるのが嫌なだけだ」

役人は受取帳へ何かを書いた。

後で松寿丸が覗くと、そこにはこうあった。

――黒田松寿丸、支給品を拒む。扱いに注意。

夜着は換えられなかった。代わりに門番へ古い蓑が四枚だけ出た。

松寿丸は、その晩も厚い夜着を使わなかった。布団の上へ置き、足元には薄い小袖を重ねた。

寒くて眠れなかった。

だがもっと眠れなかったのは、自分が寒さを我慢しても、帳面の値は一文も下がらなかったからだった。

## 第19話　門番の子

| 項目 | 内容 |
|---|---|
| 視点 | 松寿丸 |
| 表面目標 | 門外へ転がった薬包を、刻限までに屋敷へ戻す |
| 即時質問 | 敵方の門番の子は、なぜ薬を盗もうとしたのか |
| 選択 | 庄吉を告発せず、自分の薬を半分渡す代わりに門外の様子を教えてもらう |
| 不可逆な変化 | 松寿丸は敵側にも帰りたい家と、病む家族があると知る |
| 次話への代価 | 庄吉との密かな受け渡し口ができ、監視を破る可能性と危険が生まれる |

薬包が門の外へ落ちたのは、荷改めの最中だった。

胃薬、傷薬、熱冷まし。黒田から届いた包みを新七が並べ、役人が一つずつ封を切っていた。風が吹き、薄い紙包みが庭を滑り、門の下の隙間から外へ出た。

庄吉が拾った。

松寿丸は格子越しに見ていた。庄吉は門番の子で、父の昼飯を運ぶため毎日来る。年は松寿丸と同じくらいだが、背が低く、右の袖がいつも短い。

庄吉は薬包を懐へ入れた。

「今、何を取った」

松寿丸が声をかけると、庄吉の肩が跳ねた。

「何も」

「紙が見えた」

「落ち葉や」

冬の門前に葉はなかった。

松寿丸は門内の番士を見た。呼べば庄吉は捕まる。盗みは門番の父にも及ぶ。

「誰が病気だ」

庄吉は黙った。

「その薬は胃の薬だ。熱には効かない」

「妹が咳をしとる」

「なら違う」

松寿丸は熱冷ましの包みを一つ持った。格子の下へしゃがみ、門の隙間から半分を押し出した。

「こっちだ」

庄吉は手を出さなかった。

「人質から物をもろたら、父ちゃんが叱られる」

「盗めばもっと叱られる」

「返したら、妹が死ぬかもしれん」

その言葉は、敵味方より先に松寿丸の胸へ入った。

庄吉の家は門から二町ほど先、川沿いの裏長屋にある。父は夜番が続き、母は産後から寝込んでいる。妹は三日熱が下がらない。

「僕も、ここへ来なければ黒田の者が死ぬかもしれなかった」

松寿丸は薬をもう少し押した。

「だから来た」

「帰りたくないんか」

「帰りたい」

「人質でも」

「人質だからだ」

庄吉は薬を取った。

翌朝、門前に小さな笹舟が置かれていた。中に、炭で丸が一つ描かれた木片が入っている。

妹の熱が下がった印だった。

それから二人は、門の隙間で短い言葉を交わした。長浜の町で米が高くなったこと。北から来た兵が増えたこと。黒田の使者がどの宿へ泊まるか。

松寿丸は初めて、門の外の敵方の町を、人の家として見た。

庄吉も初めて、門の内の人質を、帰りたい子として見た。

## 第20話　届かない椀

| 項目 | 内容 |
|---|---|
| 視点 | 後藤又兵衛→松寿丸 |
| 表面目標 | 欠けた椀を次の定期便で松寿丸へ届ける |
| 即時質問 | なぜ検問は椀を壊し、破片一つだけを通したのか |
| 選択 | 又兵衛は役人へ食い下がるより、破片そのものを合図として使う |
| 不可逆な変化 | 二人をつないだ椀は元へ戻らない。代わりに欠落が連絡手段になる |
| 次話への代価 | 松寿丸は破片の数から、又兵衛が門外で監視の仕組みを読んでいると知る |

又兵衛は欠けた椀を藁で三重に包んだ。

橋砦の夜、五人で飯を回した椀だった。縁が大きく欠け、黒い漆も剥げている。松寿丸が持っていた片方とは対になる傷があった。

「食い物でも文でもない」

弦太が荷車へ積みながら言った。

「こんなもん、何の役に立つ」

「向こうで飯を食う時、五人分を思い出す」

「六人やろ。若君を入れたら」

又兵衛は答えず、包みの縄を締め直した。

長浜の検問所で、役人は包みを開いた。

「破損した椀」

「松寿丸様の私物です」

清十郎が荷目録を差し出した。

「木地の中へ文を隠せる」

役人は小刀を取った。

又兵衛の手が先に柄を押さえた。

「割るな」

番士が二人寄った。甚六が又兵衛の肩をつかむ。

「ここで止められたら、他の荷も届かん」

「これは、あいつのや」

「だからや」

役人は椀を石へ打ちつけた。

乾いた音がした。

椀は四つに割れた。中に文はなかった。

「一片だけなら通す」

役人は最も小さな破片を荷へ戻した。

又兵衛は残る三片を拾った。指先に漆の欠片が刺さり、血がにじんだ。

「何個に割れた」

清十郎が尋ねた。

「四つ」

「届くのは一つ」

清十郎は目録の余白へ、小さな四角を四つ描き、その一つだけを塗った。

松寿丸へ届いたのは、親指ほどの木片だった。

新七は笑った。

「黒田家では、これを贈物と呼ぶのですか」

松寿丸は木片を掌へ乗せた。割れ目は新しい。漆の縁に、細い赤黒い染みがある。

又兵衛の指の血だと分かった。

庄吉から、黒田の荷が検問で長く止められたと聞いていた。

松寿丸は木片を畳へ置き、同じ大きさの炭を三つ並べた。

四つに割られ、一つだけ届いた。

なら、届かなかった三つもある。

見えないものを、ないことにしてはいけない。

松寿丸は木片を小袋へ入れた。欠けた椀はもう戻らない。

それでも、割られた数は届いた。

## 第21話　信長の城

| 項目 | 内容 |
|---|---|
| 視点 | 松寿丸 |
| 表面目標 | 安土への随行中、列から遅れず宿所へ入る |
| 即時質問 | なぜこれほど強い城を持つ者が、なお人質を必要とするのか |
| 選択 | 城の華美に見惚れるだけでなく、荷・門・職人・兵の流れを数える |
| 不可逆な変化 | 松寿丸は「強い国なら人質を出さずに済む」という願いを持つ |
| 次話への代価 | 強さを城と命令の速さで測る危うい物差しが生まれる |

安土城は、遠くからでも山を変えて見せた。

石垣が段々に積まれ、その上へ建物が重なっている。板葺きと瓦、朱の柱、白い壁。播磨の低い砦や長浜の屋敷とは、同じ人間が作ったものと思えなかった。

松寿丸は随行の列で歩いた。人質であるため馬には乗せられず、前後を番士に挟まれている。

道には米俵、材木、瓦、鉄、紙、酒樽が絶えず運び込まれていた。職人が走り、役人が札を改め、兵が道を空ける。

「すごいでしょう」

新七が誇らしげに言った。

「これが信長公の城です」

松寿丸は天主を見上げた後、荷車を見た。

「一日に何台入る」

「何がです」

「荷車」

「数えきれません」

「門はいくつ」

「若君は城見物へ来たのでしょう」

「城は、門と飯で立つ」

官兵衛が地図を広げる時に言っていた言葉を思い出した。

松寿丸は数えた。南から上る荷車が三十七台。途中で止められたものが五台。門札の色が違う荷は、同じ列でも先へ通された。

高い石垣の陰に、荷を担いだ男が座り込んでいた。足から血が出ている。監督役は交代を呼ばず、荷だけ別の男へ移した。

城は止まらない。

一人が倒れても、別の一人が穴を埋める。

松寿丸は、その強さに恐れと憧れを同時に覚えた。

「黒田も、これほど強くなれば、人質を出さなくて済むか」

新七は少し考えた。

「人質を取る側になれます」

松寿丸は黙った。

それは望んだ答えと違った。

夕方、宿所の二階から城下を見下ろした。灯が順にともり、道を役人が走り、命令が山の上から下へ落ちていく。

強い国なら、誰も差し出さずに済む。

そう思いたかった。

けれど目の前の強い国は、自分を人質にして立っていた。

## 第22話　半兵衛の目

| 項目 | 内容 |
|---|---|
| 視点 | 松寿丸 |
| 表面目標 | 竹中半兵衛が示した庭の異変を、香が燃え尽きる前に言い当てる |
| 即時質問 | 命令どおりに見張っていた番士は、なぜ侵入の兆しを見落としたのか |
| 選択 | 人ではなく、濡れていない飛石と鳥の沈黙から隠れた者を指す |
| 不可逆な変化 | 半兵衛は松寿丸を保護すべき子ではなく、観察し判断できる後継者として見る |
| 次話への代価 | 松寿丸は命令に従うだけでは家を守れないと知り、監視役の文章まで疑うようになる |

竹中半兵衛は、咳を隠さなかった。

白い布で口を押さえ、しばらく息を整えてから、庭を指した。

「若君。あそこに、命令を破った者が一人おります」

庭には誰も見えなかった。

番士は所定の位置に二人。庭師は松の枝を切り、女中が縁側を拭いている。門は閉じ、塀の上にも影はない。

「香が尽きるまでに見つけてください」

小さな香炉から細い煙が上がった。

松寿丸は人の顔を順に見た。誰も慌てていない。

番士の一人は、命じられた通り門を見ている。もう一人は蔵の前。庭師は枝だけを見ている。

命令を守っている。

だから、見ていない場所がある。

雨上がりの庭で、飛石はどれも濡れていた。蔵の裏へ続く一枚だけ、表が乾いている。誰かが足を置き、その後で裏返したように土の色が違う。

雀が庭へ降りてこない。松の枝ではなく、蔵の屋根を避けて飛んでいる。

松寿丸は蔵の軒下を指した。

「そこ」

半兵衛が扇を一度鳴らした。

軒下から、小柄な兵が降りた。侵入役を命じられた半兵衛の家臣だった。

新七が感心した声を出した。

「番士は怠けておりませんでしたが」

「怠けていないから見落とした」

松寿丸は答えた。

半兵衛の目が細くなった。

「命令は、人の目を同じ方へ向けます。敵は、その背中へ回る」

「なら、命令を守らない方がよいのですか」

「違います。命令が何を守ろうとしているかを考え、その外で失うものを数えるのです」

半兵衛は咳をした。布に薄い赤が付いたが、すぐ畳んだ。

「若君は朝ごと、人を数えておられるそうですな」

松寿丸は新七を見た。監視役は目を伏せた。

「数えるだけでは足りません」

半兵衛は言った。

「なぜ一人欠けたか。誰が欠けさせたか。欠けたことを誰が隠したか。そこまで見て、初めて家を守れます」

松寿丸は小袋の中の椀の破片を握った。

見える一つだけでなく、届かなかった三つを数える。

半兵衛はそれ以上、椀のことを尋ねなかった。

ただ帰り際、新七へ言った。

「この若君へ渡す文は、捨てずに全て見せなさい。読ませぬ文があるなら、読ませぬ理由も残すことです」

命令ではなく、釘だった。

## 第23話　黒田への手紙

| 項目 | 内容 |
|---|---|
| 視点 | 松寿丸→又兵衛 |
| 表面目標 | 黒田家へ無事を知らせる手紙を、定期使者の出立前に書き終える |
| 即時質問 | 監視役はどの一文を書き換えたのか |
| 選択 | 松寿丸は本文を争わず、人数・句読・紙の折り方へ本当の情報を残す |
| 不可逆な変化 | 公的な手紙と、二人だけが読める手紙が分かれる |
| 次話への代価 | 又兵衛は改竄を見抜くが、人質屋敷へ直接入れば連絡路そのものを失う |

松寿丸は、黒田家へ送る手紙を三度書き直した。

一度目は、朝の人数が一人欠けたことを書いた。

新七が首を振った。

「屋敷の警固に不備があるように読めます」

二度目は、安土で見た荷車と倒れた人足を書いた。

「信長公の御城を批判したと取られます」

三度目は、庄吉の妹の熱が下がったことを書いた。

「門番の家と私的に交わるのはお控えください」

紙は残り一枚だった。

松寿丸は、教えられた通りの文を書いた。

長浜にて恙なく過ごしております。御屋形様、家中の皆々に心配なきようお伝えください。学問、弓、礼法に励み、織田家、羽柴家の御恩を忘れず、黒田の名を汚さぬよう努めます。

新七は満足した。

「結構です」

松寿丸は筆を置く前に、一つだけ加えた。

――朝夕、七度ずつ庭を見ております。

屋敷の人数は本来八人だった。今は七人。

新七は数字の意味に気づかなかった。

封をする時、松寿丸は紙を四つ折りにし、一角だけ内側へ折り込んだ。四つに割れ、一つだけ届いた椀の印だった。

手紙は検問所で開かれた。

監視役とは別の役人が本文を写し、「御恩を忘れず」を「御威光を仰ぎ」へ変えた。黒田家への忠誠より、織田への服従が強く見える文になった。

又兵衛は姫路で手紙を受け取った。

清十郎が最初に首をかしげた。

「松寿丸様は『御威光』という言葉を使いません」

「なぜ分かる」

「前の三通では一度もない。それに、ここの墨だけ濃い」

弦太は紙を鼻へ寄せた。

「封の糊が二種類や。一度開けて、別の米糊で閉じとる」

甚六は文を声に出して読み、七という数で止まった。

「朝夕、七度ずつ庭を見る。若君は、こんな回りくどいことを書くか」

又兵衛は紙を裏返した。

一角が内側へ折れている。

欠けた椀の形だった。

「八人おった」

又兵衛が言った。

「何が」

「人質屋敷の内回り。前の使者が八人と言うとった。今は七や」

清十郎が改竄された語句へ薄い紙を重ねた。

「本文は見せるための文。数と折り目が、若君の文です」

又兵衛は立ち上がった。

「長浜へ行く」

甚六が入口を塞いだ。

「入ってどうする」

「一人欠けた理由を聞く」

「お前が門で捕まれば、次の手紙は来ん」

又兵衛は手紙を握った。

走れば届く距離にいるのに、走ってはいけない。

門の外に残るとは、近づかないことまで含むのだと初めて知った。

## 第24話　帰る場所

| 項目 | 内容 |
|---|---|
| 視点 | 又兵衛／松寿丸交互 |
| 表面目標 | 次の定期便までに、監視下でも松寿丸の無事と異変を確認できる連絡法を作る |
| 即時質問 | 又兵衛は門へ入らずに、どうやって松寿丸を守るのか |
| 選択 | 自分で忍び込まず、庄吉・使者・荷目録・折り目・人数をつないだ仕組みを仲間へ渡す |
| 不可逆な変化 | 二人は「帰る場所」を別々の立場から定義し、後の約束の第二段階へ進む |
| 次巻への接続 | 官兵衛が有岡へ向かう。連絡法は処刑命令下で松寿丸を救う生命線になる |

又兵衛は長浜の門へ行かなかった。

代わりに、道を四つに分けた。

弦太は定期便の馬と荷車を調べ、途中で止められた時間を記す。清十郎は松寿丸の過去の手紙を写し、使わない語、字の傾き、墨の継ぎ目を比べる。甚六は使者が姫路を出た人数と、戻った人数を数える。

又兵衛は、門番の子へ届く物を考えた。

薬でも金でも、見つかれば庄吉の父が罰を受ける。そこで荷車の藁縄へ、黒田では普通に使う結び目を一つだけ混ぜた。橋砦で五人が荷を分けた時の結び方だった。

一重なら無事。二重なら病人。三重なら人が欠けた。結び目が逆なら、文を開かれた。

「子どもにこんな役をさせるんか」

弦太が言った。

「選ばせる。嫌なら切って捨てろと伝える」

「お前なら、嫌でもやるやろ」

「だから俺が決めたらあかん」

又兵衛は、自分で言ってから黙った。

松寿丸へ役目を背負わせた時、自分は同じことをしていなかったか。

長浜では、庄吉が荷縄の結び目を見つけた。

父に見つからないよう切り取り、門の隙間へ押し込む。松寿丸は一重の結び目をほどき、同じ縄を二重にして返した。

病人がいる。

誰かは書けない。

次の便で、又兵衛は薬種を全員分として送った。特定の一人へ宛てなければ、役人も止めにくい。清十郎は目録へ八人分と書き、実際には九人分を薄く分けた。

松寿丸は九つの包みを見て、門外の者も人数へ入れた。

「なぜ一つ多いのです」

新七が尋ねた。

「帰ってくる者の分だ」

「誰が帰るのです」

「まだ分からない」

その晩、松寿丸は半兵衛と再び会った。

半兵衛は地図の上へ、城、街道、川、村を示す小石を置いた。

「若君は、どのような国を作りたいですか」

松寿丸は以前なら、強い国と答えただろう。

安土のように高い城を持ち、命令が速く届き、人質を出さなくてよい国。

けれど強い城にも、倒れた人足がいた。門の外には、敵方でも妹の薬を求める子がいた。自分の手紙は、強い者の都合で書き換えられた。

「帰ってきた者が、疑われずに飯を食える国」

半兵衛は小石から手を離した。

「それは、城を建てるより難しい」

「だから作る」

同じ頃、姫路では又兵衛が欠けた椀の三片を紐でつないでいた。

元の形には戻らない。隙間が残り、水を入れれば漏れる。

お菊が横から覗いた。

「直ってへんやん」

「直しとるんやない」

「ほな、何しとる」

「どこが欠けたか、忘れんようにしとる」

又兵衛は三片の間に、一片分の空白を残した。

そこに松寿丸の持つ破片が入る。

今は離れている。だが、形はつながっている。

数日後、黒田官兵衛が有岡城へ向かうという知らせが入った。

荒木村重が織田へ反旗を翻した。官兵衛は説得に行く。日帰りの予定だった。

又兵衛は馬の腹帯、道の泥、帰路の橋を確かめた。清十郎は官兵衛の書状の癖を写し、弦太は有岡から姫路までの水場を数え、甚六は夜門の交代刻を書いた。

まだ何も起きていない。

だからこそ、帰るための手順を先に作った。

長浜の松寿丸は、朝の人数を数えた。

姫路の又兵衛は、出ていく者の人数を数えた。

二人の間には、城壁と街道と、開けられる手紙がある。

それでも、数える者が両側にいれば、誰かが消えた時に分かる。

官兵衛の一行が門を出た。

又兵衛は最後尾の馬まで見送った。

帰る場所とは、ただ門が開いている所ではない。

帰らなかった一人に、最初に気づく者がいる所だった。

# 第3巻終了時の台帳

## 人物

- **松寿丸**：人質屋敷で朝ごと人数を数える。自分の食事・寝床・病が政治的価値として扱われると知る。庄吉との交流、欠けた椀の破片、安土城、半兵衛の試問、改竄された手紙を経て、「帰ってきた者が疑われず飯を食える国」を目指し始める。
- **又兵衛**：松寿丸へ直接会いに行く衝動を抑え、弦太・清十郎・甚六へ役割を渡す。荷縄、人数、語尾、折り目を用いた門外からの連絡法を作る。ただし自分が最も危険な役を抱える傾向は残る。
- **竹中半兵衛**：松寿丸の観察力を試し、命令の外で失われる者を数えよと教える。松寿丸を単なる人質ではなく、判断できる後継者として見始める。
- **庄吉**：長浜の門番の子。病気の妹のため薬を盗もうとし、松寿丸と出会う。敵側にも帰りたい家があることを示し、後に秘密連絡の細い経路となる。
- **小寺新七**：人質屋敷の監視役。松寿丸を害する悪人ではないが、政治的事故を避けるため情報を削り、若君の言葉を管理する。
- **弦太**：馬、荷車、糊、匂い、止められた時間から検問の異常を読む。
- **清十郎**：語彙、墨、折り目、過去の書状を比較し、文章の改竄を見抜く。
- **甚六**：出入りする人数を数え、又兵衛が衝動で門へ走ることを止める。

## 道具と象徴

- **欠けた椀**：検問で四つに割られ、一片だけ松寿丸へ届く。完全な共有物から、欠落そのものを数える通信手段へ変わる。
- **椀の三片**：又兵衛が保管し、一片分の空白を残して紐でつなぐ。離れた二人の関係を示す。
- **荷縄の結び目**：一重＝無事、二重＝病人、三重＝人数欠け、逆結び＝開封済み。後の秘密連絡の原型。
- **黒田への手紙**：公的本文は改竄されるが、数字、墨、折り目が真の情報を運ぶ。
- **安土城**：強い国への憧れと、人質を必要とする強さの矛盾を同時に示す。

## 情報

- 人質屋敷の文書と荷は恒常的に検査され、一部は書き換えられる。
- 松寿丸と又兵衛は、人数・折り目・結び目を用いて監視下でも最低限の情報を交換できる。
- 半兵衛は松寿丸の身辺と能力へ注意を払い、監視役へ過度な情報遮断をさせない立場を取る。
- 松寿丸は安土の威容を見て強い国を志向するが、同時に「帰還者が疑われない国」という生活側の定義を得る。
- 官兵衛が有岡城へ向かい、第4巻の時計が動き始める。

## 第4巻への不可逆な条件

- 松寿丸は監視下にあり、普通の手紙だけでは危機を伝えられない。
- 又兵衛は門外から情報を読み、非公式に実働する方法を覚えた。
- 半兵衛は松寿丸を観察し、保護に値する後継者だと認識している。
- 官兵衛が有岡へ向かい、帰還確認の手順を又兵衛たちが既に準備している。
- 二人の約束は、又兵衛の「人を連れて帰る」と松寿丸の「帰った者を迎える国」へ具体化した。

# 制作検品

- 全8話とも、人物・場所・物・時刻または手順から開始し、抽象的な主題説明を入口にしていない。
- 各話に表面目標、即時質問、選択、不可逆な変化、次話への代価を設定した。
- 松寿丸を受動的な人質にせず、観察、数、物資、文章を読む主体として描いた。
- 又兵衛を人質屋敷へ自由に侵入させず、権限の低さと門外の立場を維持した。
- 竹中半兵衛の史実上の松寿丸保護を奪わず、又兵衛は保護を可能にする情報経路を担う。
- 安土城の威容を単純な礼賛にせず、強い国が人質を必要とする矛盾を残した。
- 巻末は短い決め台詞だけで閉じず、官兵衛出立の手順と人数確認で第4巻へ接続した。
- 第4巻完成稿の開始条件「官兵衛が有岡から戻らない」「書状の異常を仲間が読む」へ矛盾なく接続する。
