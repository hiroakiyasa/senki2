# 第137話「釜山の岸」

夜明け前、黒田勢を載せた船が釜山の岸へ近づく。黒槍組50人のうち17人が海酔いで立てない。又兵衛は海外戦の一番上陸を欲し、立てる者だけを先に走らせようとする。

荷板の中央で佐吉が止まり、戻り波で船と板の隙間へ落ちる。又兵衛は左手で襟をつかむが、砕けた右肩が動かず引き上げ切れない。甚六が腹ばいで帯をつかみ、七郎の投げた縄を脇へ通して救う。その間に長政の先陣は丘の向こうへ消え、一番上陸の席も消える。

又兵衛は吐いた者を「歩けても」戦列から外す。弦太は水を一口ずつ分け、宗十郎は荷板を寝台へ変え、清十郎は吐いた回数、歩けるか、荷の濡れを別々に記録する。又兵衛自身の欄も作られ、右肩を使った事実を隠せなくなる。

浜の先には焼けた低い家、倒れた板戸、井戸、灰に埋もれた木匙がある。佐吉は初めて「ここ、戦場ですか」と問う。又兵衛は答えを突き放すが、木匙が踏まれないよう小石で囲う。救えた生活ではなく、壊した後へ残す小さな境界にすぎない。

長政は又兵衛へ、先鋒でなく最後の荷船まで浜を空ける役を命じる。又兵衛は不満を隠さない。長政は「後から来る者を詰まらせぬ者が、今日は先だ」と返す。

夕刻、最後の兵と荷が砂へ上がる。50人全員が岸へ着く。又兵衛の最初の海外任務は一番槍ではなく、海酔いした17人と荷を船へ残さないことだった。黒槍の第一補修輪には海の塩が入り、布で拭いても内側に残る。

### 終了条件

- 黒槍組50人。死者なし。
- 佐吉は胸部打撲。又兵衛の右肩痛が増す。
- 海酔い17人を戦列から外す手順が成立。
- 干し飯は五日で尽きる量しかなく、次話で村への徴発命令を受ける。

# 第138話「言葉のない村」

上陸五日後、黒槍組の干し飯が尽きる。又兵衛は米、麦、塩、薪を夕刻までに集める命令を受ける。慶尚道の村は戸を閉じ、人影を隠している。床下で鶏が鳴き、空腹の兵が板戸を破る。

兵が梁の袋を槍の石突で落とすと、籾のついた種が床へ散る。弦太はそれが食う米でなく春に蒔く種籾だと見抜く。家の裏には、老婆、女、子どもが鶏籠と鍬を抱えている。空腹の兵が鶏籠へ手を伸ばし、又兵衛は黒槍の穂でなく柄を胸へ当てて泥へ座らせる。

又兵衛は銭紐と木札を見せ「買う」と身振りする。しかし村人には、命令札を見せて奪う兵にしか見えない。言葉が通じないのではなく、侵略する側とされる側で同じ物の意味が違う。

そこへ捕らえられた朝鮮人ユン・ハジュンが連れてこられる。対馬・釜山の交易で日本語を少し知る男で、村人の言葉を「売るとは言っていない。兵が来たから取られると思っている」と訳す。又兵衛が代わりの品を置くと言うと、ハジュンは「取引ではない。侵略する者が、少し壊さないだけだ」と切る。

又兵衛はハジュンの縄を切る。ハジュンは逃げず、まず村人へ向き直る。弦太は種籾、家族の三日分、交換できる湿った麦を分ける。宗十郎が塩、釘、布を並べ、女が感謝でなく計算の末に麦袋一つを出す。又吉は門へ小さな黒布を結ぶが、それは全軍を止める万能札ではない。

黒槍組の一食は底の見える麦粥になる。又兵衛は自分の椀を子どもへ渡さない。その場だけ善人に見えるため兵の飯を減らし、次の家で奪えば同じだからだ。

黒槍組が村を出ると、後方から別の日本軍100人ほどが近づく。又兵衛は戻らず本隊へ進む。ハジュンは日本軍を助けたいからでなく、次の村へ知らせるため同行する。弦太は黒槍組50人と、別の一人としてハジュンを数える。

### 終了条件

- 黒槍組50人。死者なし。
- ハジュン初登場。縄を解かれるが、黒槍組へ加入しない。
- 種籾、鶏、村人を奪わず、湿った麦一袋だけを交換する。
- 小さな黒布を残すが、後続部隊への効力は未確認。
- 又兵衛は「村を守った」とは言えないまま進む。

# 第139話「先鋒の仕事」

黒槍組は本隊より先に街道脇の宿営地へ着く。選んだ窪地には三棟の納屋と井戸があり、一見便利だが、弦太が床へ棒を差すと泥水が上がる。雨が来れば池になる。千人を越える本隊の到着まで一刻しかない。

林に朝鮮斥候の青い布が見え、又兵衛は10人を連れて追う。手柄を得て読み違いを埋めようとするが、落ち葉の下の穴へ膝まで落ちる。黒槍の石突が木根へ挟まり、右肩だけでは抜けない。斥候は弓で牽制して消える。

戻ると窪地は足首まで水が来ている。長政は又兵衛へ、敵を追った間に宿を失ったのかと問う。又兵衛は失敗を隠さず、黒槍を地面へ置いて50人を役割へ分ける。

弦太が火と水、清十郎が寝床、甚六が北外周、七郎が排水と出口、宗十郎が板と杭、又吉が合図、小平が到着案内を担う。又兵衛が自分の役を言おうとすると、甚六が「八つが止まらんよう見ろ。穴へ入るな」と遮り、長政がそれを先鋒の仕事だと認める。

三つの火だけを守り、寝床を縄で区切り、盾を北へ厚く並べ、南を退路として空ける。排水溝は水が崩さない角度で曲げ、黒槍を溝幅の物差しへ使う。又吉の黒い小旗と小平の往復で、疲れた本隊を区画へ流す。

夜、朝鮮斥候が鳥声を合図に短い夜襲を仕掛ける。ハジュンが鳥ではないと見抜く。黒槍組は火を消さず、眠る兵を踏ませず、北外周だけを守る。敵が退くと兵は追撃を求めるが、又兵衛は追わず外周を戻す。

翌朝、敵を捕らえた者はいない。千人超の本隊は何もなかったように眠っている。長政は、先鋒の手柄は朝まで何もなかったように見えると言う。又兵衛は褒美をつけにくい仕事だと返す。甚六は長政と又兵衛の両方へ筵を投げ、交代して休めと命じる。

### 終了条件

- 黒槍組50人。死者なし。
- 八役が自走し、又兵衛は中央で全体を止めない役へ置かれる。
- 黒槍は排水溝の物差しとして使われる。
- 斥候追跡は失敗、宿営は成功。次話は増水した副渡河点。

# 第140話「渡河点」

増水した川が昨日の道を呑んでいる。黒槍組へ与えられたのは、主力の勝敗を決める正面渡河ではない。負傷者と荷駄を中州へ渡す副渡河点である。杭12本、縄3巻、盾8枚、残り一刻半。

七郎は小枝の流れと渦から、浅い場所でなく「底が歩く場所」を選ぶ。ハジュンは村人が隠した舟の場所を教えない。教えれば日本軍が舟まで奪うからだ。

工作兵の庄兵衛は杭の節を槌で聞き、割れる一本を外す。朝鮮弓兵は距離を測る矢を射ち、杭打ち組へ照準を合わせる。遠い丘では女、老人、子どもの牛車が逃げている。弓兵の目的は勝つことでなく、避難の時間を稼ぐことだった。

又兵衛は下流へ囮の渡河線を作り、弓を二方向へ割る。庄兵衛は第四杭を打つ最中、脇腹へ矢を受ける。それでも最後の一打で杭を底へ噛ませるが、水圧で足を外し腰縄が張る。

又兵衛は水へ一歩入る。七郎は、今全体を止めれば流木で杭組全員が流されると叫ぶ。又兵衛は自分で庄兵衛へ飛び込まず、救い上げ役二人だけを向け、残りへ第五杭を命じる。

庄兵衛は岸へ戻されるが、木槌は川へ沈み、脈はない。又兵衛は駆け寄らず第六杭の位置を示す。痛みを後回しにしたことは正解ではなく、四十九人を渡すために一人の最期へ間に合わなかった事実として残る。

杭は11本で中州へつながる。七郎は12本目を打たず渡河を始める判断を出し、又兵衛も認める。黒槍は岸と第一杭の間の手すりになり、負傷兵の手を受ける。朝鮮弓兵は避難民が消えた後に退く。敵も自分たちの勝利条件を満たす。

岸へ残った12本目の杭を庄兵衛の盾脇へ置く。清十郎は運んだ12でなく、打てた11を書く。又兵衛は「四十九人や」と口にする。

### 終了条件

- 庄兵衛死亡。黒槍組は50人から49人。
- 杭12本を運び、11本を打つ。残り1本は庄兵衛の盾脇。
- 庄兵衛の木槌は濁流へ失う。
- 黒槍の第一補修輪へ川泥が加わる。
- 濡れた米、薪不足、冷水疲労を次話へ送る。

# 第141話「凍る米」

冬の黄海道方面。夜の冷えで炊いた飯が桶ごと凍り、杓文字が立ったまま抜けない。黒槍組49人に対し、薪は6束だけ。飯を戻せば寝床が凍り、寝床を温めれば水を飲めない。

兵が自分の小火へ薪を持ち去り始める。弦太は薪の上へ座り込んで止める。又兵衛が間へ入ろうとすると、「物資の判断は俺や」と掌を向ける。又兵衛が大将へ命令するのかと問うと、弦太は「四十九人の薪へ命令する」と返す。

ハジュンは床下へ火を通す朝鮮家屋を示す。又兵衛が空き家かと聞くと、ハジュンは「逃げた家だ。空いた家ではない」と訂正する。弦太は一室16人ずつの三交代、床2束、湯2束、夜2束を決める。

又兵衛は負傷者を全員先に入れようとするが、弦太は見張りと炊事が倒れれば次に全員が倒れると退ける。甚六は又兵衛を最初の16人へ押し込み、「お前も一人や」と言う。又兵衛の札も他の15枚と同じ束へ置かれる。

宗十郎が煙道を直し、七郎が雪を溶かす水桶を火口から離す。ハジュンは火を強くし過ぎれば家を焼くと教える。床へ熱は回るが、16人は横になれず膝を抱える。温まる場所は休める場所とは限らない。

弦太は凍飯を割り、湯へ入れて薄い粥へ戻す。又吉の梁打ちで三組を交代させる。清十郎が家の使用を「借用」と書こうとすると、ハジュンは「持ち主が返せと言える時だけ借りたと言う」と止める。清十郎は「占有、一夜」と改める。

そこへ家の持ち主である老婆、母、子ども2人が戻る。同じ床で日本兵と眠ることを拒む。又兵衛はすぐ家を返そうとするが、弦太は今出せば凍傷者が出ると止める。ハジュンを介し、家族は納屋で一夜過ごし、日本兵が翌朝に戸板と薪を戻す条件を出す。感謝ではない。自分の家を取り戻すための最低条件である。

小平の右手二指が白くなり、凍傷が判明する。藤乃は火へ直接当てず布と体温で戻す。弦太は小平を伝令から一時外す。翌朝、戸板を直し薪2束を残して家を空ける。清十郎は帳面へ「占有一夜、戸板一、薪二、粥四」と記す。

### 終了条件

- 黒槍組49人。死者なし。
- 小平の右手二指に継続する凍傷。
- 弦太が物資判断で又兵衛を実際に退ける。
- 凍飯を薄粥へ戻し、凍った一塊を今後の炊事教育用に保存。
- 朝鮮家屋の利用を「借用」でなく「占有」と記録する。

# 第142話「捕虜の地図」

雪中行軍で宿場を探すため、朝鮮人捕虜が描いた地図を使う。清十郎は日本の陣地図と似た印を合わせ、三角を高所、丸を集落、曲線を道と読む。ハジュンは、同じ印を同じ意味で使うとは限らないと警告する。

清十郎は写しを二枚作り、藤助組と小平組へ渡す。藤助は丸印を宿と思い尾根へ向かい、小平は曲線に沿う低地へ向かう。吹雪が足跡を消す。小平組は曲線が道でなく凍った水路だと気づいて戻るが、藤助組が戻らない。

捕虜は嘘を描いていない。丸は地方によって烽火台や墓地を示す可能性があり、清十郎が「宿」と決めたことが誤りだった。救索組が丸印と同じ配置の低い石積みへ着くと、そこは墓地である。

藤助組の二人は墓陰で見つかるが、藤助だけがいない。一本残った足跡、枝の布片、手跡、膝跡を追い、石積みの陰で地図を握ったまま倒れている藤助を見つける。戦って死んだのではない。正確だと思った写しと、宿へ急ぐ責任で一人先へ進み、雪中で死んだ。

清十郎は藤助を背負う。又兵衛が代わろうとすると、地図を渡したのは自分だと言う。又兵衛は、運べば返る話ではないと告げ、身体でなく地図箱を持つ。

捕虜は地図へ妻と娘の名を書き、家族のいる道へ日本軍を近づけたくなかったと明かす。「使えない形で本当を描いた」のであり、日本側の使用目的へ合わせなかっただけだった。

清十郎は新しい地図を作る。宿、墓地、烽火台を別の記号にし、凍水路には昼夜の通行条件を足す。地名を一つの日本音へ決めず、ハジュン、又吉、小平、弦太にどう聞こえたかを並べ、朝鮮文字の形も別欄へ残す。不確実さを消さない地名帳が成立する。

又兵衛は捕虜の縄を火へ入れて解放する。捕虜は日本軍へ加入せず、南へ去る。清十郎は藤助の地図を胸へ入れ、黒槍組の人数を「四十八人」と改める。

### 終了条件

- 藤助死亡。黒槍組は49人から48人。
- 捕虜を解放。黒槍組へ加入させない。
- 音の地名帳が成立。複数音、朝鮮文字形、生活目印、通行条件を並記する。
- 正確になった地図は、味方の救援だけでなく日本軍の侵攻も遠くへ進める。

# 第143話「川中の長政」

厳冬の支流。渡す対象は121人と荷車9台。胸までの濁水の中で、水牛兜の角だけが人の頭越しに見え、一度川面へ沈む。長政が朝鮮の小頭と川中で組み合っている。

七郎は水位が朝より一尺上がり、半刻で車輪の半分まで来ると読む。弦太は荷へ赤、白、黒の布を付け、沈んだ時は予備槍、弾薬の一部、米と薬の順に守ると決める。清十郎の新地図には柳、割れ岩、深み、受け場が別の記号で残る。

渡河を始めると4台目の車輪が深みへ落ち、荷車が横を向く。弦太は赤布の予備槍を切り捨て、負傷兵のため荷重を減らす。上流の葦から朝鮮兵約20人が現れ、その後ろでは避難民の牛車が南へ逃げる。彼らの目的もまた、牛車が消えるまで渡河を止めることである。

長政は自分で岸へ駆け下り、綱を狙う兵を退ける。馬が浮氷で滑り、長政は鐙を外して川へ降り、朝鮮小頭と槍柄をつかんで組み合う。

水牛の角を見た又兵衛は川へ一歩下りる。しかし渡河列では5台目が深みへ入り、6台目に熱病の兵9人が乗る。甚六は盾を離せず、又兵衛の名だけを呼ぶ。

又兵衛は足を戻し、七郎へ「長政様へ6人。お前が選べ」と命じる。自分は土手へ残り、5台目の赤と白の荷を切り、熱病兵を二台へ分ける。長政を救いたい気持ちと、救出に最も適した者を行かせる判断を初めて分ける。

七郎の一度目の縄は流され、二度目は水牛兜の角へ絡む。長政は顎紐を外し、兜だけが下流へ流れる。家臣は角を失って長政を見失う。又兵衛は「角を見るな。旗と声を見ろ」と渡河列を保つ。

三度目の縄が長政の腕へ入り、同じ輪が朝鮮小頭の腰帯にも掛かる。小頭は自分の帯を切って縄から外れ、仲間側へ生還する。長政は七郎組へ引かれる。双方の指揮官が生きて戻り、避難民の牛車も林へ消える。

121人と9台の渡河が完了する。佐吉は救い縄で右手二指を脱臼するが生存する。焚火前で又兵衛は、すぐ助けへ行かなかったことを長政へ詫びる。長政は七郎が来たと返す。又兵衛は、七郎の方が川を知り、自分が行きたかった理由は「自分が行きたかっただけ」だと認める。

長政は役ごとの代行者を2人ずつ、又兵衛には3人置くよう清十郎へ命じる。翌朝、又兵衛が立ち止まっても旗と列は進む。

### 終了条件

- 黒槍組48人。死者なし。
- 佐吉は右手二指を脱臼。小平の凍傷、又兵衛の右肩を継続。
- 長政救出の実働は七郎ら6人。又兵衛は121人と9台の全体指揮へ残る。
- 八役に主担当と代行2人、又兵衛には代行3人を置く。
- 朝鮮小頭は捕虜にならず自軍へ生還する。

# 第144話「晋州へ」

1592年末。秋の第一次晋州城攻防で焼けた梯子が残る城外。高い城壁下の窪みに先遣の梯子組23人が取り残されている。歩ける者11、歩けない者7、動かない者5。日没まで半刻。

城壁上では朝鮮兵と義兵が弓手を交代し、石を手渡す。壁内の通路には水甕を運ぶ女と少年がいる。城を守るのは兵だけでなく、逃げ込んだ民の生活そのものだ。

日本側は戸板盾と縄で二度救援に失敗している。又兵衛は戸板を黒槍で頭上へ上げようとするが、右肩が途中で止まり盾を落とす。甚六に「分かって、またやった」と指摘される。

清十郎は矢の刺さった場所から、壁の折れ目の南だけ三息ごとに薄くなると読む。七郎は排水溝の浅い窪みが城壁下まで続くと見つける。弦太は戸板2枚と盾1枚を5歩だけ運ばせ、重くて歩けないことを確かめる。

そこで動かす発想を一度捨てる。戸板と盾を短杭で固定し、人一人がうずくまれる小さな遮蔽を5か所へつなぐ。進む屋根ではなく、戻る者が一つずつ移る「止まる場所」である。

又兵衛は黒槍を地面へ横に置き、救援線を5区間へ分ける。甚六が遮蔽、宗十郎が杭、七郎が窪み、弦太が人数、清十郎が矢、又吉が音、小平が返事を担う。又兵衛は自分の札を前線へ置かず土手の指揮点へ置く。

宗十郎が杭を打ち、甚六が戸板2枚を斜めに重ね、弦太が火矢面へだけ濡れ筵を巻く。七郎が排水溝へ縄を通し、又吉の梁打ちと窪みの白布で合図を往復させる。小平は凍傷の右手を使わず、左の小旗で生存18人の返事を取る。

負傷者を載せた戸板を縄で滑らせ、遮蔽ごとに受け渡す。固定杭が抜ければ宗十郎が予備杭を打ち、佐吉は脱臼した指を使わず足で縄を押さえる。又兵衛は一度土手を下りかけるが、又吉の打音を聞いて足を戻し、低い黒槍で迂回線だけを示す。

歩ける11人は、生者だけでなく5人の遺体も戸板へ結ぶ。壊れた戸板は甚六が盾の鉄縁を重ね、半分でも次へ渡す。弦太は受け取り場所を生存18と死者5へ分ける。日没直前、23人全員が土手内へ帰着し、黒槍組に追加死者は出ない。

救援後、矢だらけの戸板、盾、壊れた荷車の車輪が積まれる。宗十郎が戸板を車軸へ水平に載せ、「止まる場所を、動かせたら」と言う。弦太は濡れ筵を載せて重さに首を振る。ハジュンは、押せるようにした時どちらへ向けるのかと問う。

夜、又兵衛は泥へ黒槍の石突で低い屋根と2つの車輪だけを描く。誰もまだ木を切らず、実物の移動屋根は存在しない。第一の補修輪には海の塩、川泥、晋州の矢羽が付く。ハジュンは輪の外から城内を見る。

### 終了条件

- 黒槍組48人を維持。追加死者なし。
- 梯子組23人は生存18、死者5として全員帰着。
- 又兵衛は救援線へ入らず、八役と代行者で任務を完遂。
- 固定した戸板・盾・短杭・縄を使用。実物の移動屋根はまだ作らない。
- 泥へ「人を覆う動く屋根」の着想だけを描く。
- 正式な亀甲車、命名、火矢対策、壁際到達、第二の補修輪は第19巻へ送る。
