# 第17巻『長岩城』統合完成稿

- 通算：第129話〜第136話
- 年代：天正十五〜十六年（1587〜1588）
- 形式：全8話、各12頁・6見開き・43コマ
- 前巻から：城井谷で長政の進軍命令を実行可能にした責任を又兵衛が認め、仲間には「前へ出すぎた又兵衛を止める権限」が与えられた。焼け槍に補修輪はまだない。
- 次巻へ：右肩の恒久障害、第一の補修輪、役割分担された五十人の黒槍組が成立し、1592年の渡海へ接続する。

## 巻の問い

一人が先頭に立ち続けることと、倒れても隊が帰れる仕組みを残すことは、同じ「強さ」なのか。

## 固定制作規格

全話の頁別コマ数は `1 / 3 / 7 / 3 / 3 / 3 / 7 / 3 / 2 / 7 / 3 / 1 = 43`。P1とP12は全面、P3・P7・P10は速射。各話に物資・時刻・地形・命令者・遅延要因・負傷・終了台帳を置く。長岩城攻略の史実上の主体を又兵衛一人へ移さず、黒田方諸隊、吉田長利、栗山利安、在地案内人へ判断と功を分ける。

## 第129話「石の城」

### 話機能
長岩城の崖、石垣、狭い登路を測り、正面攻撃では兵が尽きると示す。又兵衛は反対するだけでなく代案と中止条件を提出する。

### 12頁設計
P1 高俯瞰。崖上の長岩城、三本の登路、黒田方の先遣百二十人。／P2 又兵衛・弦太・清十郎が傾斜、落石痕、井戸煙を測る。／P3 七つの観察：濡れ苔、割れ石、矢穴、風向、縄跡、死角、退路。／P4 長政の使者が翌朝正面攻撃を命じる。／P5 又兵衛は正面なら最初の百人が石を受けると説明。／P6 栗山利安は「止めるなら別の道を出せ」と返す。／P7 夜襲候補を七手に分解。／P8 在地の炭焼きが北壁の古い修理口を示す。／P9 甚六が梯子長と担ぎ手を算出。／P10 風、月、交代、縄、梯子、盾、撤退鐘を速射で準備。／P11 又兵衛は自分が先頭に立つ案を出し、仲間が中止権を確認。／P12 夜の崖へ八本の梯子が運ばれる。

### 終了台帳
兵120、梯子8、長縄16、盾24。死者0、負傷2。北壁修理口を確認。翌話は月没二刻前から開始。

## 第130話「夜の梯子」

### 話機能
夜襲の不確実性を、英雄的潜入でなく風と重量と合図のずれとして描く。

### 12頁設計
P1 強風で揺れる梯子。／P2 先頭三人が足場を作る。／P3 手、縄、釘、息、石、風、合図を七コマ。／P4 又兵衛は最上段へ上がるが、第二梯子が遅れる。／P5 清十郎は予定より半刻遅いと札を裏返す。／P6 弦太が下の兵を二列から一列へ変更。／P7 城兵の気配、灯、犬、石臼、足音、弓弦、戸板。／P8 又兵衛は見張りを討たず口を塞ぎ、開門場所を問う。／P9 見張りは修理口が偽入口だと示す。／P10 三梯子撤収、一梯子転用、盾移動、負傷者降下、縄切断、伝令、再登攀。／P11 甚六が「先頭を替われ」と命じ、又兵衛が従う。／P12 城内から最初の落石音。

### 終了台帳
梯子8→使用5、破損1、予備2。負傷7、死者0。又兵衛は先頭交代命令に初めて従う。

## 第131話「落石」

### 話機能
城兵側にも家族と守る理由を与え、落石を単なる罠でなく合理的防御として描く。

### 12頁設計
P1 巨石が梯子列へ落ちる。／P2 甚六が盾を重ねて退路を守る。／P3 石の跳ね、盾割れ、縄切れ、悲鳴、土煙、手信号、鐘。／P4 又兵衛は前進を命じかけ、清十郎が中止札を掲げる。／P5 城内では老兵と農民が石を運ぶ。／P6 又兵衛は敵の石置場が尽きる時間を読む。／P7 七回の落石と間隔変化。／P8 弦太が負傷者を下ろし、空いた盾を前へ回す。／P9 甚六の盾が割れ左腕を切る。／P10 予備盾、梯子角度、縄支点、囮灯、退路線、担架、鐘を再配置。／P11 又兵衛は鐘二声で全員を一度下げる。／P12 敵は撤退と誤認し、石置場を開ける。

### 終了台帳
死者3、重傷9、軽傷18。甚六左前腕裂傷。落石間隔と石置場を特定。撤退は敗北ではなく次の進入条件を作る選択として固定。

## 第132話「折れた肩」

### 話機能
又兵衛の身体に不可逆な代価を刻み、以後の槍術と指揮を変える。

### 12頁設計
P1 石置場へ入った又兵衛の右肩へ横木が落ちる。／P2 肩関節と鎖骨周辺の損傷を、腕が上がらない動作で示す。／P3 痛み、槍落下、指の痺れ、呼吸、敵足音、仲間の声、暗転。／P4 又兵衛は左手で槍を拾い前進しようとする。／P5 甚六が身体ごと止める。／P6 又兵衛は「門まで三十歩」と言うが、弦太は残兵数を答える。／P7 指揮権移譲の七手：地図、鐘、白縄、赤縄、担架、予備槍、撤退役。／P8 清十郎が又兵衛の命令不能を宣言。／P9 仲間が又兵衛を担架へ縛る。／P10 城兵接近、盾列形成、煙投入、梯子下ろし、担架移動、殿交代、鐘三声。／P11 又兵衛は「俺を置け」と叫ぶが誰も従わない。／P12 意識を失う直前、全員が自分より後ろへ下がるのを見る。

### 終了台帳
又兵衛：右肩重傷、以後高い振り下ろし・長時間保持不可。指揮権は弦太、記録と合図は清十郎、退路は甚六へ移譲。

## 第133話「大将不在」

### 話機能
主人公不在でも物語と任務が進むことを証明する。

### 12頁設計
P1 夜明け、又兵衛不在の作戦図。／P2 弦太が残兵・水・縄を数える。／P3 七人の小隊長が異なる意見を出す。／P4 清十郎が又兵衛の旧案と現在条件を分離。／P5 甚六は正面攻撃を拒否し北壁の排水口を選ぶ。／P6 吉田長利隊が南側で圧力をかけるとの報。／P7 時刻、煙、鐘、旗、排水、水位、門番交代。／P8 弦太は三隊に役割を割り、誰も又兵衛の代役を名乗らない。／P9 又兵衛は治療所で目覚め、作戦を聞いて口を挟む。／P10 医師、カヤ、伝令、肩固定、槍回収、地図修正、沈黙。／P11 又兵衛は「俺なしで行け」と正式に言う。／P12 三隊が別々の入口へ消える。

### 終了台帳
指揮は分散。又兵衛は作戦参加せず。黒田方本隊との合図を同期。次話で門開放を実行。

## 第134話「開いた門」

### 話機能
仲間が又兵衛を置かず、かつ又兵衛抜きで任務を完遂する。

### 12頁設計
P1 排水口から入る小隊。／P2 南側の陽動と北側の潜入を同時に描く。／P3 鍵、閂、番兵、油、鐘縄、足場、退路。／P4 清十郎が開門時刻を一刻遅らせる。／P5 弦太が捕虜を殺さず門の構造を聞く。／P6 甚六は負傷腕で閂受けを支える。／P7 七つの連携動作。／P8 門が半分開き黒田方諸隊が入る。／P9 城兵の一部は家族のいる曲輪へ退く。／P10 追撃停止、井戸確保、火消し、降伏旗、負傷者分離、武器回収、人数確認。／P11 弦太は又兵衛を迎えに戻る隊を別に出す。／P12 担架の又兵衛が開いた門を通る。

### 終了台帳
長岩城攻略成功。黒田方の複数隊の功として記録。味方死者11、重傷24。城内非戦闘員を分離保護。又兵衛は戦果の中心名義を拒否。

## 第135話「第一の補修輪」

### 話機能
焼け槍が黒槍へ変わる第一段階と、身体障害に合わせた戦い方の変更を描く。

### 12頁設計
P1 鍛冶場で曲がった槍柄。／P2 鍛冶が廃棄を勧める。／P3 焦げ、割れ、緩み、鉄輪、重心、肩、握り。／P4 又兵衛は右腕が肩より上がらない。／P5 鍛冶は第一の補修輪を巻き、柄を短くする。／P6 黒漆は装飾でなく傷と継ぎ目を湿気から守るため塗る。／P7 七つの試技：低構え、押し、返し、絡め、足払い、受け流し、退き突き。／P8 又兵衛は以前の大振りを捨てる。／P9 仲間が新しい槍を「黒槍」と呼ぶ。／P10 右肩限界、左手補助、交代時刻、予備槍、担架位置、合図、止める権限。／P11 又兵衛は槍へ黒田の飾りを付けず、役目札だけを結ぶ。／P12 黒い槍と割れた盾が並ぶ。

### 終了台帳
焼け槍→第一補修輪付き黒槍。短く重く、低い構え中心。右肩障害は治癒しない。甚六の盾は修理不能。

## 第136話「黒槍組」

### 話機能
個人武勇の隊ではなく、五十人が役割で帰還率を上げる組織として黒槍組を成立させる。

### 12頁設計
P1 五十人が武器別でなく役割札ごとに並ぶ。／P2 又兵衛は先鋒、盾、縄、火消し、記録、担架、殿を説明。／P3 七役の実演。／P4 若兵が「黒槍を持つ者だけが黒槍組か」と問う。／P5 又兵衛は槍を地面へ置き「これがなくても動く」と答える。／P6 弦太は米と水の担当を戦闘役と同格に置く。／P7 合図不通、指揮者負傷、夜、雨、敵味方混在、橋崩落、退却の七訓練。／P8 清十郎が全員の名と家族の連絡先を帰名帳へ写す。／P9 甚六は又兵衛を止める権限を全員の前で確認。／P10 指揮交代、負傷分類、武器放棄、旗集合、人数二重確認、最後尾交代、自分を数える。／P11 又兵衛は五十人を数え、自分を含めて「五十一」と言い直す。／P12 海の向こうへ向かう軍船の報が届く。

### 巻末台帳
- 黒槍組：隊員50＋又兵衛。七役制、指揮交代制、停止権を明文化。
- 又兵衛：右肩恒久障害。黒槍は第一補修輪、黒漆、短縮柄。
- 弦太：兵站・人数。清十郎：記録・合図。甚六：退路・停止権、左腕に傷。
- 死者：長岩城攻略で味方11。帰名帳へ記載。
- 第18巻開始条件：渡海命令、黒槍組50人、第一補修輪のみ、右肩障害継続。
