# 第25巻『奉公構』統合完成稿

- 通算：第193話〜第200話
- 年代：慶長十一〜十六年（1606〜1611）
- 形式：全8話、各12頁・6見開き・43コマ
- 前巻から：官兵衛死後、又兵衛は黒田家の飾りを黒槍から外し、家族・同行者と城門を出た。右肩古傷、黒槍の補修輪、帰名帳、欠けた椀を保持。
- 次巻へ：細川・池田での仕官が奉公構と政治圧力で崩れ、黒槍を質入れし、京都の雨漏りする借家へ移る。

## 巻の問い

大名が欲しがるほど強い男が、なぜ家族の米を買えないのか。武名は生活を守る力になるのか。

## 固定制作規格

全話の頁別コマ数は `1 / 3 / 7 / 3 / 3 / 3 / 7 / 3 / 2 / 7 / 3 / 1 = 43`。P1とP12は全面、P3・P7・P10は速射。奉公構を一枚の命令書だけで説明せず、国境警備、市場、宿代、扶持米、雇用契約、家族の移動、旧臣の離脱として見せる。長政を嫉妬だけの悪役にせず、家臣流出・軍事情報・主従秩序を守る合理を持たせる。

## 第193話「小倉の客将」

### 話機能
細川忠興が又兵衛を評価しながら、雇うこと自体が黒田との国境緊張を生む構造を示す。

### 12頁設計
P1 小倉城門、又兵衛一家と同行者六十四人。／P2 細川家役人が武器・家族・荷車を分けて登録。／P3 札、槍、米、宿、馬、肩、国境の七確認。／P4 忠興は客将として千石相当の扶持を示すが正式知行を保留。／P5 又兵衛は旧臣二十六人の住居も求める。／P6 細川側は国境の黒田兵増加を報告。／P7 市場の噂、関所増員、船荷検査、宿値上げ、密偵、手紙停止、家族不安。／P8 カヤは監視者が黒田だけでないと気づく。／P9 又兵衛は兵法指南を始める。／P10 稽古、米配給、傷の診察、子どもの学校、家賃、国境報、書状封印。／P11 忠興は「雇うが、戦の理由にはしない」と期限付き滞在を告げる。／P12 遠賀川の両岸に黒田と細川の見張り火。

### 終了台帳
小倉滞在許可90日。同行64人。扶持は仮給付。黒槍は武器蔵へ預けず又兵衛所持。

## 第194話「二つの国境」

### 話機能
又兵衛の存在が市場の小競り合いと軍備増強へ変換される。

### 12頁設計
P1 市場で黒田商人と細川足軽が米俵を奪い合う。／P2 又兵衛は武器を抜かず人垣を分ける。／P3 値札、通行札、荷印、拳、抜刀、泣く子、倒れた升。／P4 黒田側は又兵衛が兵を集めていると抗議。／P5 細川側は客将の自由だと反論。／P6 清十郎は噂の発信元が複数あると記録。／P7 国境の柵、番所、舟止め、鉄砲、米蔵、伝令、夜警が増える。／P8 弦太は扶持米の搬入が三日遅れたと示す。／P9 又兵衛は旧臣へ市場へ出る時は二人組と命じる。／P10 喧嘩仲裁、負傷手当、荷返却、札再発行、密偵追跡、宿移動、人数確認。／P11 小夜が「父上がいるから戦になるのか」と問う。／P12 又兵衛は答えられず、国境地図を畳む。

### 終了台帳
負傷者7、死者0。扶持遅延。細川家中で雇用継続派と退去派が割れる。

## 第195話「家康の仲裁」

### 話機能
天下人の秩序が個人の武名より強いことを示す。

### 12頁設計
P1 江戸からの朱印状が小倉へ届く。／P2 忠興、家老、又兵衛の三者評定。／P3 文言、印、使者、期限、扶持、家族、武器。／P4 家康は黒田・細川双方へ国境安定を命じ、又兵衛処遇を忠興へ委ねる。／P5 忠興は又兵衛を守りたいが領民を戦の危険へ置けない。／P6 又兵衛は自分だけ退去し家族を残す案を出す。／P7 家族分離の七つの危険をカヤが示す。／P8 忠興は三十日以内の退去と旅費を提示。／P9 又兵衛は扶持残額を旧臣へ分ける。／P10 荷車売却、宿精算、墓参、稽古納め、通行札、別れ、国境越え。／P11 忠興は「お前を雇えぬのは弱いからではない」と言う。／P12 小倉城が遠ざかり、又兵衛一行が播磨へ向かう。

### 終了台帳
細川仕官終了。同行者64→57（7人は細川領で別職を選ぶ）。旅費30日分。

## 第196話「播磨へ」

### 話機能
故郷が時間によって別の場所になっていることを描く。

### 12頁設計
P1 雨の播磨、父の家があった土地には別家の蔵。／P2 又兵衛は古い井戸だけを見つける。／P3 墓、畦、橋、馬場、焼け跡、寺札、知らない子。／P4 村役人は旧名主の土地返還を拒む。／P5 法的には現在の耕作者が年貢を納めている。／P6 又兵衛は力で取り返さず借家を探す。／P7 旧知の者の死、移住、改名、仕官、帰農、病、忘却。／P8 清十郎は帰名帳に「帰ったが家なし」と欄を作る。／P9 カヤは子どもたちの寝床を寺へ確保。／P10 屋根修理、薪集め、水汲み、米購入、肩痛、槍手入れ、仕事探し。／P11 池田家の使者が千人扶持の話を持ってくる。／P12 又兵衛は故郷の井戸水を一口飲み、池田家へ向かう。

### 終了台帳
同行57人。播磨に恒久住居なし。欠けた椀を再使用。池田家から正式交渉。

## 第197話「千人扶持」

### 話機能
又兵衛が再び大きな組織と生活を得る高揚を置き、その脆さを同時に準備する。

### 12頁設計
P1 池田家の大広間に千人扶持の書付。／P2 役人が扶持人数と実人数の違いを説明。／P3 米、屋敷、馬、足軽、指南、国境、契約。／P4 又兵衛は旧臣全員の雇用を求める。／P5 池田側は戦時召集と平時指南を分ける。／P6 弦太が初めて半年分の米を受け取る。／P7 屋根、畳、鍋、学校、馬小屋、稽古場、墓地。／P8 又兵衛一家の食卓に椀がそろう。／P9 旧臣の一部が戻り人数57→83。／P10 名簿、役割札、肩に合う槍架、扶持配分、夜番、家族登録、黒旗保管。／P11 又兵衛は城主時代より小さい席で安堵する。／P12 黒田家の封書を持つ使者が池田城へ入る。

### 終了台帳
池田家で千人扶持。同行・再集合83人。住居と扶持安定。黒田抗議書到着。

## 第198話「黒田からの使者」

### 話機能
奉公構を、長政の感情ではなく家中統治と他家外交の圧力として具体化する。

### 12頁設計
P1 黒田使者が又兵衛の無断出奔と軍事情報持出しを列挙。／P2 池田家老が契約書と照合。／P3 誓紙、知行、軍図、旧臣、境界、幕府、面目。／P4 又兵衛は軍図を持ち出していないと帰名帳と私物を開示。／P5 使者は事実より「他家が雇えば黒田の処分が無効になる」点を問題視。／P6 池田側は戦争を避けるため契約停止を検討。／P7 家中の賛否七声。／P8 長政からの私信はなく、正式抗議だけがある。／P9 又兵衛は使者へ長政を罵らず、直接会談を求める。／P10 返書、証拠封印、扶持停止、屋敷期限、旧臣選択、家族説明、人数確認。／P11 池田家は三十日後の解雇を通告。／P12 米蔵の又兵衛札が外される。

### 終了台帳
扶持停止。83人のうち池田残留希望31、同行希望39、未決13。又兵衛は選択を強制しない。

## 第199話「槍を質に入れる」

### 話機能
象徴である黒槍を生活のため手放し、武名と家族の優先順位を可視化する。

### 12頁設計
P1 空の米櫃と黒槍。／P2 弦太が残金を五日分と計算。／P3 米、薬、家賃、草鞋、紙、薪、槍。／P4 又兵衛は鎧を売るが値が足りない。／P5 質屋は黒槍を名物として高く評価する。／P6 又兵衛は補修輪と黒漆の由来を語らず値だけ聞く。／P7 質札、秤、袋、戸棚、肩、子の咳、欠けた椀。／P8 小夜は槍を売らないでと言いかけ、母の薬を見る。／P9 又兵衛は三十日質、利息付きで預ける。／P10 米購入、薬、家賃、旧臣への分配、質札保管、素手稽古、夜の空いた槍架。／P11 又兵衛は「槍より先に帰す者がいる」と言う。／P12 質屋の暗い戸棚に黒槍が横たわる。

### 終了台帳
黒槍は質屋預かり。現金で家族と同行者39人の30日分を確保。又兵衛は武器なし。

## 第200話「雇えない男」

### 話機能
大名たちが又兵衛を評価しつつ誰も雇えない状況を決着させ、第26巻の生活編へ渡す。

### 12頁設計
P1 三家から届く非公式な誘いと、すべてに付く「黒田同意が条件」。／P2 又兵衛は一日で三つの門を回る。／P3 待合、紹介状、肩書、扶持、監視、断り、帰路。／P4 ある家老は軍学だけなら匿名で雇うと提案。／P5 又兵衛は家族と旧臣を隠す条件を拒む。／P6 カヤは京都なら大名の国境から距離を置けると示す。／P7 39人の選択：同行17、別職8、帰農6、寺入り2、保留6。／P8 又兵衛は全員へ旅費を分け、忠誠を求めない。／P9 質屋へ戻り黒槍を受け出す金が足りない。／P10 利息交渉、質期限延長、借家探し、軍学道具、雨具、家族名簿、出発。／P11 又兵衛は黒槍を置いたまま京都へ向かう。／P12 雨漏りする京都の借家で、軍学図を守るため畳を剥がす。

### 巻末台帳
- 又兵衛一家＋同行17人が京都へ。その他は本人の選択で別れる。
- 黒槍：質屋に残る。質札は小夜が保管。第26巻第207話まで画面へ戻さない。
- 右肩古傷は寒雨で悪化。軍学と素手・木棒指導へ移る。
- 長政：公式抗議を維持。私的憎悪の言葉は送らない。
- 第26巻開始条件：京都の雨漏り家、仕官なし、軍学道具、欠けた椀、質札、旧臣の分散。
