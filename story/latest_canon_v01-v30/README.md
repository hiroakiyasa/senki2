# 『戦帰 SENKI』最新正典 第1巻〜第30巻

- 集約日：2026年7月26日
- 収録内容：各巻の最新完成稿または最新統合完成稿のみ
- 巻数：30巻
- 話数：240話（各巻8話）
- 元の完成稿は内容を書き換えず、Git blobをそのまま移設した
- 旧完成稿、競合稿、古い統合入口は削除した
- 今後、物語本文を改訂する場合は、このフォルダー内の該当巻だけを更新する
