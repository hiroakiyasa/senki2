- 後藤又兵衛は、黒髪の無造作な結び髪、大きく鋭い目、髭なし、黒い袖なし装束、引き締まった武者体型とする。
- 主武器は全長約5.5〜6.5mの黒槍。
- 正面・左右側面・背面・戦闘姿勢・槍の詳細・甲冑・表情集を共通フォーマットとする。
- 明るく読みやすい白背景の漫画設定資料とし、人物ごとに一枚へ分離する。
