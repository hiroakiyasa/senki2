## 年代・史実ロック

- 本編は1611〜1614年。京都・大和の浪人生活から大坂入城までを描く。
- 1614年の大坂入城と、黒田家を出奔後に奉公構で仕官を妨げられた骨格を守る `[A/B]`。
- 京都の借家、軍学塾、青木弥市、又吉の畑、酒場事件、七枚の帰参条件、三十二行の豊臣名簿、二十六人の入城隊は創作 `[C]`。
- 長政は又兵衛を飢えさせる悪役にしない。家族扶持、屋敷、療治を用意する一方、国を守るため旧臣名簿・書状・武具を管理する。
- 豊臣方も単純な善意へしない。浪人軍を早く組織する必要から、本人確認前の名簿と前金を持ち込む。
- 第206話までは大坂入りを確定させない。第207話で家族三人が選び、第208話で実際に門を越える。
- 「播磨一国」の伝承は第29巻第226話。第26巻へ前倒ししない。

## 共通人物シート

### `matabei@v26`

- 後藤又兵衛、五十代前半。長身、骨太だが浪人生活で頬が削げる。白髪が混じる。戦場の威圧と、家賃を数える生活者の手を同居させる。
- 灰藍の木綿小袖、継ぎ当てした袴、脚絆、草鞋。必要時だけ古い腹巻。豪華な大坂五人衆装束はまだ着せない。
- 右肩は長岩城以来の恒久傷。耳より高く上げる動作、大きな打ち下ろし、長時間の担ぎを避ける。冷雨で首から指先まで痺れる。
- 第201〜206話は黒槍を所持しない。第207話で受け戻した後も、左手で低く持つか若い者へ交代させる。
- 欠けた椀の片割れを持つ。長政を憎んでいない。戻りたい気持ちと、管理される旧臣を守りたい気持ちが衝突する。

### `kaya@v26`

- 百地カヤ、又兵衛と同世代の対等な伴侶。年齢を若返らせない。目尻、手の古傷、静かな速さで経験を出す。
- 墨茶の質素な小袖、短い脚絆。薬包、細縄、油紙、小さな鳴らない鈴。黒装束、網タイツ、魔法的な忍術は禁止。
- 情報仕事、薬仕事、偽名の見分けを担う。又兵衛の許可を待つ従者にしない。
- 第207話で自分の稼ぎを黒槍へ出し、大坂行きを自分の借りとして選ぶ。

### `sayo@v26`

- 小夜、又兵衛とカヤの娘。若い成人女性。父を英雄でなく、雨漏りの家へ帰る人として見る。
- 薄鼠の木綿小袖、前掛け、縫い針と糸巻き。戦場用の鎧、短刀、くノ一装束は禁止。
- 家計、写本、縫い仕事、荷造り、人数確認へ参加する。守られるだけの子にしない。
- 第208話で「二十六。父上も入る」と人数を訂正する。

### `genta@v26`

- 速水弦太、五十代。丸い体形を残しつつ、長年の兵站で肩と手が厚い。腰痛と膝の鈍さを隠さない。
- 算木、秤縄、米袋、受領札、古い台帳。大坂方へ先に所属していたのではなく、又兵衛の相談を受けて移動準備を手伝う。
- 前金と私金、戦闘員と扶養者、運んだ量と着いた量を分ける。

### `seijuro@v26`

- 公式名簿、借財帳、宿帳、本人の意思を別欄へ分ける。可読文字は生成画像に描かせない。

## 舞台・小道具の固定

### 京都の借家

- 低い軒、板と土壁、薄い畳二枚、土間、竈、雨漏り三か所。立派な町家、武家屋敷、白壁、庭園は禁止。
- 桶三つ、油紙、軍学図、糸巻き、欠けた椀、薄い麦粥、家賃包みを反復する。
- 光は曇天と小さな行灯。暗黒にせず顔と手が読める明るさを保つ。

### 鴨川河原の軍学塾

- 竹札、縄、荷俵、舟、川石、濡れた火縄。実戦を再現する粗末な教材。
- 立派な道場、甲冑の行列、砂盤模型の豪華演出は禁止。

### 大和の畑

- 借畑二反、崩れた水口、泥の畦、麦、粗末な小屋。又吉の暮らしが成立していることを先に見せる。
- 鍬は槍に似せすぎず、刃のある農具として正しく描く。戦闘ポーズを取らせない。

### 伏見の寺・関

- 寺は小堂、畳、火鉢、低い机。帰参条件七枚は写植前提で無地に見せる。
- 関は木柵、番小屋、荷改め台。大城門や石垣の威容へしない。

### 黒槍

- 鎌・鍵を持たない素槍。複数の補修輪、焦げ跡、刃こぼれ、短く重い柄、不均一な重心。
- 第201〜206話の画面へ出さない。質札、空いた壁、槍のない歩き方だけで不在を示す。
- 第207話の質屋で再登場。新品、黒光りする完璧な武器、豪華な鞘、金具は禁止。

### 名簿・札・文字

- 三十二行の名簿、二十四通の知らせ、二十六枚の登録札は、生成画像では可読文字を出さない。行数、印、紙の種類、折り方だけで区別する。
- 台詞、題字、看板、札文字はすべてローカル写植。

## 全話共通の生成禁止

- 又兵衛を若武者の顔や二十代の体へ戻さない。
- 甚六、官兵衛、三成、忠勝など死亡済み人物を現存場面へ出さない。回想も必要最小限。
- 長政を悪役顔で直接登場させない。第205話は書状、筆圧、条件、実務者の態度で存在を示す。
- 黒槍を第207話前へ出さない。別の槍を代用させない。
- 近世後期の整った町並み、現在の大坂城天守、徳川再建後の巨大石垣を豊臣大坂の現在景として描かない。
- 西洋式の椅子、机、馬具、銃、街灯、ガラス窓、印刷物を出さない。
- 豪華な甲冑、金の陣羽織、大のぼりの乱立、英雄的な騎馬入城は禁止。
- 生成画像へ台詞、題字、可読な偽文字を描かせない。
