# 第202話終了時の台帳

- 弥市と宗太は仕官。受領確認、分散指揮、負傷者後送、荷の損切りを自分で選んだ。
- 又兵衛は弟子が自分なしで進む成功を得る。月謝収入二人分を失う。
- 最後の米袋を受け取る。家賃期限は残り七日、黒槍期限は九日。
- 弥市から、大和で帰農した旧臣・又吉の所在札を得る。
- 軍学原図は又兵衛が保持。黒槍は質屋のまま。
