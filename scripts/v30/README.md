## 固定ページ構成

各話12頁・43コマ。ページ別コマ数は以下を標準とする。

```text
P1  1コマ（扉・断ち切り）
P2  3コマ
P3  7コマ（速射）
P4  3コマ
P5  3コマ
P6  3コマ
P7  7コマ（速射）
P8  3コマ
P9  2コマ
P10 7コマ（速射）
P11 3コマ
P12 1コマ（引き・断ち切り）
合計43コマ
```

完成稿の各話「12頁・43コマ脚本」は、この固定配分に対応する。個別ファイルへ分離する場合も、台詞、負傷、時刻、人数、道具、視点、引きを変更してはならない。

## 最終巻の生成ロック

- 小松山は低い山と畑・土手・用水であり、天守、石垣、巨大な岩山は出さない。
- 徳川方を同じ顔・同じ旗の群衆壁にしない。奥田、水野、本多、松平の異なる進路と命令音で示す。
- 又兵衛は超人的な単騎無双をしない。槍は殺傷より、押し返し、救助、間合い、列整理に使う。
- 負傷順序は右肩浅傷→腿銃創→脇腹槍傷。連続性を逆行させない。
- 第236話で又兵衛を帰還人数へ一人加える。第237話で指揮と黒旗を渡す。第238話の救援は七人・半刻・法螺一回に限定する。
- 第239話は戦死の神格化ではなく、清十郎が失敗・救援・生還者数を同じ頁へ書く。
- 第240話の最終画面は巨大な又兵衛像ではなく、最後尾の交代と半椀の粥。
- 生成画像には台詞、題字、時刻札、帰名帳の可読文字を描かせない。分割後にローカル写植する。

## 生成例

個別話へ分離後は既存巻と同じ pipeline を使う。

```bash
node pipeline/generate_spread.mjs scripts/v30/ep01_午前四時.md \
  --outdir production/v30/ep01spread --spreads 1 --prepare

node pipeline/generate_spread.mjs scripts/v30/ep01_午前四時.md \
  --outdir production/v30/ep01spread --spreads 1-6

node pipeline/finalize_spread.mjs scripts/v30/ep01_午前四時.md \
  --image production/v30/ep01spread/spreads/s01.png --spread 1 --open
```
