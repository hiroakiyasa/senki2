# 『戦帰 SENKI』v03ep23「黒田への手紙」

## 話情報

| 項目 | 内容 |
|---|---|
| 巻／話 | 第3巻『人質の城』第7話（通算23／240） |
| 頁数 | 12頁（6見開き・41コマ） |
| 年代 | 天正6年初夏（1578年）・長浜から播磨への定期便前日［C］ |
| 視点 | 松寿丸（終盤のみ又兵衛） |
| 現在の権限 | 自筆書状一通を許された。ただし坂井が検分し、情報・符丁・疑念を招く表現へ訂正貼紙を置ける |
| 即時質問 | 変えられると分かっている手紙へ、何を書けば自分の意思が残るのか |
| この話の主機能 | 最終選択／検閲／言葉の二重化 |
| 引きの型 | 「十二」が「十一」に変えられた手紙を、又兵衛が読む |

## 話別設計カード

- **前話から受け取るもの**：半兵衛の働きで松寿丸は自筆を許された。坂井の検分・訂正権は残る。便は翌日酉の刻に出る。
- **表面目標**：酉の刻までに、父と黒田家を不用意な救出へ走らせず、監視下にある事実と自分の意思を又兵衛へ伝える一通を出す。
- **失敗した場合**：沈黙すれば黒田側は生存と待遇を判断できない。露骨な救援要請なら松寿丸の接触・書状が止まり、父の立場も疑われる。
- **内面の問い**：変えられた言葉も、自分の言葉として引き受けられるか。
- **松寿丸の最初の答え**：変更されない無難な文だけを書けばよい。
- **坂井の答え**：人質の書状は本人だけの物ではなく、織田と黒田の疑念を増やさぬ証文でもある。
- **最大の選択**：坂井が「十二」を公式人数の「十一」へ直すと予測して書き、変更そのものを又兵衛への合図として、訂正貼紙の付いた手紙を破らず出す。
- **不可逆な変化**：松寿丸は、言葉を隠すのでなく、相手の変更まで含めて意思を送る。坂井は原文を保存し、変更者として印を残す。
- **次話への代価**：又兵衛は変更箇所から、松寿丸が自分を人数に入れたこと、監視役がそこを消したことを読む。門を破るか、外から守る仕組みを作るかを選ぶ。

## この話の生成規約

- 書状の可読文字は画像生成させない。脚本に記す原文・訂正文は、写植工程で紙面へ入れる。
- 書状は横書きでなく、縦の筆書き。和紙、墨、硯、文鎮、折紙、細い訂正貼紙。
- 坂井の訂正は、原文を完全に消す秘密工作でなく、薄紙を三か所へ貼り、異なる筆跡と自分の印を残す公的検閲。
- 松寿丸は現代の暗号専門家にしない。「自分を含めて十二人と数える」という既出の習慣を使う。
- 手紙の旅は馬、徒歩、荷舟、宿、関所。瞬間移動させない。
- 禁：封筒、切手、近代郵便印、タイプ文字、読める偽文字、過度な涙、魔法的な墨。

# 第23話終了時の台帳

## 人物

- **松寿丸**：自筆で十二人、宗太、安土の弥市、命令の途中で見えた一人を書く。坂井が変更すると読んだ上で、手紙を破らず出す。
- **坂井与次**：三か所を訂正貼紙で変更する。変更者として印を残し、写し替えで痕跡を消さない。人質の安全と政治的疑念の抑制を優先する。
- **宗太**：自分の一行が消されたと知る。「書いた事実は残る」と松寿丸を支える。
- **又兵衛**：届いた「十一」の下に「十二」があると知り、松寿丸が自分を人数へ入れ、監視役がそこを消したと読む。
- **清十郎**：筆圧、貼紙、訂正印から、松寿丸と坂井の二つの手を識別する。

## 道具と象徴

- **松寿丸の原文草案**：「帰りたい」を含む。椀片の下で松寿丸が保管し、送らない。
- **送付書状**：松寿丸自筆。三枚の訂正貼紙と坂井の印。黒田方へ到着。
- **十二粒の豆**：松寿丸が人数確認に使う。手紙が十一へ変わっても動かさない。
- **椀片**：折り目の重しに使うが同封しない。長浜に残る。

## 情報

- 黒田側は、松寿丸が自筆できたこと、坂井が三か所を変えたことを知る。
- 又兵衛は、公式人数が松寿丸を人員から外している可能性を知る。
- 松寿丸は、又兵衛が訂正の意味を読めたかまだ知らない。
- 坂井は、「十二」が意図的な合図である疑いを持つが、変更痕を隠していない。

## 生活・時間

- 手紙は長浜から播磨へ数日の継走で到着。
- 松寿丸は火事後も屋敷十二人で朝餉を取る。
- お鶴の火傷は改善。宗太の母も日常へ戻る。

- 門を破れば通信そのものが止まる。合法な受領・荷・宿・写しを組み合わせる必要がある。
