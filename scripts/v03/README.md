## 第2巻から受け取る固定条件

- 松寿丸は欠けた椀の大きい片方を持って、織田方の門内へ入った。
- 又兵衛は門外へ残り、焼け槍、若党試しを経た低い権限、弦太・清十郎・甚六との役割分担を持つ。
- 清十郎は帰名帳を始めている。
- 又兵衛は仲間へ「自分が倒れても帰れ」と命じたが、自分自身を帰る人数へまだ入れていない。
- 松寿丸は又兵衛を「帰る一人」に数えようとする。

## 舞台・美術の固定

### 長浜

- 琵琶湖岸。低い湖霧、湿った板、冬の横風、舟の鐘。
- 人質屋敷は長浜城内または隣接する、土塀と木戸で囲った質素な武家屋敷。豪壮な御殿ではない。
- 畳は限られ、板間、藁むしろ、火鉢、共同炊事、物置、馬小屋、井戸、裏の水門がある。
- 現在の模擬天守、近世完成形、白亜の大天守を描かない。

### 安土

- 天正5〜6年。築城途中。巨大石垣、広い石段、足場、木組み、滑車、石曳き、人夫、職人、荷舟、仮設小屋を中心にする。
- 天主完成は天正7年なので、完成済みの豪華な天主を描かない。
- 華やかさは輸入布、金具、職人、商人、荷の量で見せ、完成した金箔御殿へ逃げない。

## 小道具の固定

- **松寿丸の椀片**：粗い灰褐色の陶椀の大きい片方。割れ目は不規則。布袋に包む。
- **又兵衛の椀片**：同じ椀の小さい片方。第20話で長浜へ送り、坂井が親指大の縁片だけ通す。残部は検問箱へ封じる。
- **朝の十二本**：松寿丸が屋敷の十一人と自分を合わせて刻む数え跡。公式台帳の「奉公人十一・御預かり一」と対立する。
- **焼け槍**：播磨側。柄が焦げ、穂先に刃こぼれ。第3巻中は新しい補修輪を加えない。
- **帰名帳**：清十郎が携行。第24話で長浜の受領写しと避難宿を別紙へつなぐ。
- **原文と清書**：第23話。松寿丸の自筆原文は坂井が保管。黒田へ届く清書は一部改変される。

## 全話共通の生成規約

- 生成画像に台詞、題字、札、書状の可読文字を描かせない。文字は分割後にローカル写植する。
- 16世紀後半の日本。現代建築、電線、ガラス窓、洋家具、制服、ファスナー、近代印刷物を出さない。
- 人質屋敷を牢獄の鉄格子にしない。木戸、土塀、見張り、行動範囲、帳面、閉門時刻で拘束を見せる。
- 松寿丸を幼児化しない。十歳の体格、礼法、疲労、眠気、食欲を両立させる。
- 坂井を悪人顔へ固定しない。管理の合理と、子どもの言葉を消す加害が同じ人物に共存する。
- 半兵衛を超能力的な軍師にしない。目、匂い、足跡、人数、道具の位置から判断する。
- 安土の人夫を同一顔の群衆にしない。年齢、村、仕事、履物、道具をばらす。
- 甲冑は警備・移動時にのみ質素なものを限定使用。日常の屋敷で全員を武装させない。
- 断ち切りは扉・転換・巻末の頂点だけ。毎頁を派手な斜め構図にしない。
- 感情は、椀の冷たさ、凍る墨、濡れた足袋、炭の残量、門の音、筆圧、荷の重さで示す。

## 紙面共通ルール

- 各話12頁、右綴じ、6見開き。
- 全面1コマ頁は原則P1・P12。必要時のみもう1頁。
- 7コマ以上の速射頁は2〜3頁。
- 2〜3コマ頁を4頁以上置く。
- 4〜5コマ頁を3頁連続させない。
- 擬音は全コマの20%以上。静かな話では火、湖、筆、足、戸、息を使う。
- 叫びは場面の必要から置く。静かな政治劇へ無理に決め台詞を増やさない。
- 各話の最後は、台詞、無言、手順、物、移動など型を変える。

## 史実監査メモ

- 福岡市博物館「没後400年 黒田長政」：天正5年10月、十歳の松寿が織田信長へ人質として送られ、秀吉の長浜城で養育されたことを採用。
- 長浜市「長浜城跡」：琵琶湖岸の城と、秀吉による城下町経営を舞台設計へ反映。

- 竹中半兵衛が松寿丸を匿う史実・伝承上の役割は第4〜5巻で本格回収し、第3巻では「一人の子として見る人物」という前段だけを置く。
