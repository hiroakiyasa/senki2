- **年代**：1600年12月〜1604年初春
- **主舞台**：名島城の仮政庁、筑前嘉麻郡・大隈城（益富城）と城下、福岡城築城地、太宰府の如水隠居所

- **表面目標**：官兵衛が病に伏すまでに、大隈城の門・米・役職・書状・合図・年貢を、又兵衛一人の人気だけに依存しない仕組みへ移す
- **内面の問い**：人を「連れて帰る」約束は、城主が誰かへ負担を命じる時にも守れるのか
- **巻頭で又兵衛が欲しいもの**：一万石、城、旗、家臣、昔の仲間と囲む食卓
- **巻末で得るもの**：機能する支城、領民の信頼、緊急救援の権限、長政との共同規則、官兵衛の最後の課題
- **巻末で失うもの**：友を無役の友として呼べる距離、私信の自由、黒旗を自分だけの印として扱う自由、善意だけで人を救えるという思い込み
- **次巻の開始条件**：官兵衛は生きているが、太宰府の病床で呼吸と食事が弱っている。又兵衛と長政の規則は成立したものの、二人の間を翻訳する人間は消えようとしている

## 史実ロックと創作区分

### `[A/B：骨格として守る]`

- 1600年、関ヶ原後に黒田長政が筑前へ入国し、領国支配と福岡城築城に着手する。
- 大隈城（益富城）は嘉麻郡中益の標高約190メートルの山城で、戦国期の曲輪・竪堀と、筑前六端城期の石垣・枡形虎口を持つ。
- 大隈城は筑前六端城の一つとなり、後藤又兵衛が入城したと伝わる。知行は一万〜一万六千石級として扱う。
- 福岡城は1601年から築城が始まる。第23巻では未完成であり、石運び、堀、足場、仮政庁を描く。完成した白壁の大城郭を先取りしない。
- 慶長期の筑前では検地と石高・物成の整理が進み、新領国の帳面と現実の収穫量に差が生じ得る。
- 黒田如水は晩年を太宰府で過ごし、1604年3月20日に死去する。本巻では死去させず、病と最後の軍略までに留める。

### `[C：本巻の物語実装]`

- 又兵衛が家臣百二十七人分の扶持割を日没までに作ること。
- 大隈城旧城兵、領民、米俵、検地差、二村の負担量などの具体人数・数量。
- 細川・池田家中の武将から又兵衛へ届く軍事相談の私信。
- 六端城合同の普請演習で黒旗へ兵が集まる事故。
- 二村の年貢を巡る朱印と、官兵衛が三つの案件を用いて二人へ「翻訳」を課す最後の軍議。
- 緊急救援旗、私信の写し、減免時の代替負担を一枚へまとめる共同規則。

### 史実人物の功績を奪わないための境界

- 筑前国の獲得、福岡築城、六端城配置、検地、家中統制は長政と黒田家の政策である。
- 又兵衛は大隈城という一支城で、命令を生活へ落とし、事故・飢え・門外の人を減らす現場責任を担う。
- 官兵衛を万能な予言者にしない。二人の対立を消す答えではなく、対立を扱い続ける仕事を遺す。
- 長政を嫉妬だけで動かさない。五十二万石、未完成の本城、東の国境、家臣給与、検地、私的軍事書状という現実の危険を背負わせる。
- 又兵衛を領民の願いを全て叶える善政家にしない。救済の原資、誰が待つか、誰の給与が減るかを朱印へ残す。

# 舞台・建築・生活の固定

## 大隈城／益富城

- 嘉麻郡中益の標高約190メートルの山城。麓から急な坂と曲がる登城路が続く。
- 戦国期の曲輪、土塁、木柵、竪堀、堀切を基礎とし、主郭に粗い石垣、枡形虎口、木造門、櫓、倉、井戸を置く。
- 白亜の天守、整然とした巨大石垣、広大な御殿、金箔、豪華な障壁画は禁止。
- 城下は田、畑、炭焼き、木地、馬、長崎街道へつながる道、市、寺、粗末な家。山城と暮らしの高低差を毎話どこかで見せる。
- 門は守る装置であると同時に、米・訴え・人を止める装置として描く。

## 名島城・福岡築城地

- 第177話の黒田政庁は、筑前入国直後の名島城または仮の政務所。海に近い戦国城郭と狭い城下。
- 1601年以降の福岡は築城中。土、足場、石曳き、堀、仮小屋、荷車、測量縄を描く。
- 完成後の47櫓、整った白壁、完成した天守台を第23巻へ先取りしない。

## 太宰府の如水隠居所

- 静かな板敷きと畳、低い障子、庭の梅、薬を煎じる土瓶、炭火、脇息。
- 病床を豪華な御殿や現代病室にしない。医師の道具は薬研、竹筒、木椀、布、湯、香・時刻の目安。
- 太宰府の晩年と、第24巻冒頭の死去へ接続する。第184話終了時点では官兵衛を生存させる。

# 黒槍・黒旗・印・椀の固定

- **黒槍**：素槍。黒漆の下へ焼け跡、補修輪、傷が残る。城主の飾り物でなく、右肩へ重い実用品。
- **黒旗**：帰路・救援地点を示す小〜中型の黒布。巨大なのぼり、王旗、魔法の旗は禁止。
- **黒田家の旗**：家中の命令系統を示す。黒旗と同じ画面へ置く時は、どちらが見え、どちらが聞こえないかを地形・風・人数で決める。
- **朱印**：又兵衛の命令を暮らしへ届かせる道具。押した後に消せない赤を、救済と加害の両方へ使う。
- **欠けた椀**：又兵衛と長政が片割れずつ持つ。第184話で一度並べるが、接着・修復・交換はしない。
- **六つの椀**：又兵衛、長政、弦太、清十郎、甚六、カヤを想定した昔の食卓。小夜の小椀は別。空席を死亡と配置転換の両方で見せる。

# 巻頭の連続性台帳

## 人物

- **又兵衛**：関ヶ原で大橋掃部を討ち、追撃より味方の整列を選んだ。天下に「槍の又兵衛」として知られ、功績帳では仲間の働きまで又兵衛一人の名へ集約された。
- **長政**：関ヶ原前の調略と戦後処理によって筑前を得た。五十二万石の領国、未完成の本城、六端城、検地、旧領主の家臣を一つの命令系統へ入れる必要がある。
- **弦太**：中央兵站へ昇進。又兵衛の城だけでなく筑前全体の米を数える。
- **清十郎**：中央の地図・検地へ昇進。正確な記録が課税と封鎖へ使われる危うさを知る。
- **カヤ**：黒田家へ正式所属せず、又兵衛の隣へ自分の意思で戻る。城主の妻・情報役という一つの名へ閉じ込められない。
- **甚六**：既に死亡。盾の鉄縁、退路規則、補修輪に残る。
- **官兵衛**：生存。長政と又兵衛の違いを翻訳できる最後の人物。晩年の身体は衰えている。

## 道具

- **黒槍**：黒漆、焼け跡、複数の補修輪。右肩の傷と重さを伴う。
- **黒旗**：帰路の印。関ヶ原後、黒槍組以外の兵にも意味が知られ始めた。
- **欠けた椀**：又兵衛と長政が一片ずつ所持。二つを合わせていない。
- **帰名帳・台帳**：救援の記録と領国統治の記録が同じ技術から分かれた。
- **朱印**：又兵衛は城主として初めて、自分の名で他者の暮らしを拘束する権限を得る。

## 負傷

- 又兵衛の右肩は高い打ち下ろしと長時間保持に制限がある。
- 古傷と疲労は政務でも消えず、筆、荷、寝具を持つ動作に出す。
- 官兵衛の脚の後遺症と1604年の病を段階的に悪化させる。第183話以前に急死の兆候を乱発しない。

## 情報

- 又兵衛は、自分の名声が仲間の功績を吸収したことを完全には認めていない。
- 長政は、又兵衛の独断が救援に必要であることを知る一方、国境・書状・兵の合図へ広がる危険を警戒する。
- 読者は、官兵衛の死が近い時代であると知り得るが、人物は具体的な死日を知らない。
