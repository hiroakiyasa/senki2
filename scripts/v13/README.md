## 年代・史実ロック

- 本巻の現在時制は1586年晩秋。戸次川出陣評定まで十二日から始まり、渡河準備の夜で終わる。
- 1578年耳川、1584年沖田畷、1585年竹迫城落城と肥後侵攻は、住民の記憶、伝聞、現地の傷として使う。
- 島津家久・義弘・豊久の史実上の軍事的功績を又兵衛へ移さない。
- 又兵衛は、証言収集、避難誘導、退路確認、伝令、負傷者後送、兵站報告を担う `[C]`。
- 第104話終了時、味方六千余は戸次川近岸へ集まるが、まだ誰も渡河していない。合戦本体、長宗我部信親・十河存保らの死、仙石秀久の退却は第14巻へ送る。
- 兵数は史料・伝承差があるため、作中人物が受け取った概数として扱い、語り手の絶対値にしない。

## 舞台・建築・地形の固定

- **耳川下流**：葦原、低い土手、増水した濁流、外せる木橋、渡し舟、土壁と藁屋根。近代堤防、鉄橋、舗装路は禁止。
- **肥後〜豊後の峠**：竹谷、切通し、水抜き溝、焼けた陶工小屋、銀すすき、石峠。山道を広い平原にしない。
- **渡河点**：木橋、綱渡し、浅瀬、水車溝。橋板、舟栓、舵櫂、水中杭の違いを描く。
- **府内**：朝市、外門、寺蔵、土壁の陣屋、共同炊事場。江戸期の完成城下や近世大天守を先取りしない。
- **戸次川近岸**：広い河原、複数の浅瀬、対岸の高み、濡れた葦、夜半の見張り火。第104話では渡河シーンを描かない。

## 軍装・馬・武器

- 天正期の実用的で汚れた胴丸、腹巻、陣笠、小袖、脚絆、草鞋。兵ごとに補修、布色、年齢、疲労を変える。
- 島津兵を黒一色の怪物、忍者、野蛮人の群れへしない。大友・仙石・長宗我部兵も同様に人間の顔と装備差を出す。
- 火縄銃は火縄、火皿、乾いた火薬筒、煙、再装填の手を具体化する。連射銃、無煙、現代的照準器は禁止。
- 馬は小柄で骨太な日本在来馬。質素な大和鞍、反り上がる木製前輪・後輪、幅広い和鐙。英国式・カウボーイ式鞍は禁止。
- 技名を叫ばせない。槍勝負は足場、間合い、周囲の人数、退路、守る対象で決める。

## 全コマ共通の生成禁止

- 可読文字、偽文字、台詞、題字、札・地図の文章。
- 現代物、コンクリート、電線、プラスチック、腕時計、近代軍装。
- 西洋甲冑、西洋鞍、欧州大型馬、ファンタジー武器、発光する槍、魔法、巨大爆発。
- 同一顔の群衆クローン、同じ盾・槍・馬・荷車の機械的反復。
- 島津を主人公の正しさを証明するだけの残虐集団にすること。
- 仙石秀久を指示待ちの無能者へ落とすこと。
- 又兵衛が歴史上の総大将へ当然のように命令する構図。
- 第13巻で甚六を死亡させること、又兵衛の右肩を砕くこと、黒槍を完成させること。
- 第104話で渡河、中央崩壊、信親・十河の死、仙石の逃走を描くこと。
