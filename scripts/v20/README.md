## 正典ロック

- 年代：1597〜1598年、慶長の役から豊臣秀吉死去後の撤兵まで。
- 巻の勝利条件：黒槍組の生存者、寝たきり負傷兵123人、歩ける負傷兵38人を日本へ帰し、民間捕虜27人を朝鮮側へ返す。
- 内面の問い：「帰す」とは、自分の側へ連れてくることか、その者が選ぶ家へ戻すことか。
- 又兵衛の虎退治は事実化しない。虎は共同作業で退き、噂だけが又兵衛一人の武名へ膨張する。
- 黒槍は敵を倒すだけでなく、手すり、橋、退路の印として使う。
- 蔚山の戦い、秀吉の死、撤兵は史実の骨格を守る。民間人避難、捕虜返還、帰名帳の運用は創作として明示する。
- 第160話終了時、黒槍組は解散ではなく分散する。各人の技術を黒田家五千人へ広げ、第21巻『関ヶ原前夜』の政治的分岐へ接続する。
