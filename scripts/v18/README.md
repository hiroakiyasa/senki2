## 年代・史実ロック

- 文禄元年（1592）の朝鮮侵略開始から、同年末の晋州城外先遣まで `[A/C]`。第19巻の1593年へ越境しない。
- 黒田長政が黒田勢五千を率いて渡海した史実を守る `[A]`。
- 長政が水牛兜を用い、河中戦で角先が目印になったという伝承は `[B/D]`。河川名、相手、勝敗の細部を史実と断定しない。
- 1592年秋の第一次晋州城攻防で日本軍が退けられた後を第144話の背景とし、1593年の第二次攻防・亀甲車製作は第19巻へ送る `[A/C]`。
- 晋州城の勝敗、朝鮮側諸将・義兵・民の抵抗、明軍・朝鮮水軍の功績を又兵衛へ移さない。
- 上陸整理、村の交換、宿営、補助渡河、冬営、音の地名帳、庄兵衛・藤助の死、121人の渡河、固定遮蔽による23人救出、動く屋根の着想は `[C]`。
- 日本軍の軍糧不足と現地調達圧力を背景に置くが、略奪を必要悪の一言で処理しない。

## 舞台・季節の固定

### 釜山沿岸

- 1592年春。灰緑の海、低い木造軍船、櫂、艪、一本帆、濡れた荷板、砂浜。
- 焼けた家並み、落ちた屋根、井戸、木匙、灰を置く。現代港、石造埠頭、帆船の舵輪は禁止。

### 慶尚道の村・街道

- 土壁、藁葺きまたは瓦の低い家、板戸、床下、畑、種籾、鶏、井戸。
- 日本の農村と同じ背景へせず、朝鮮の家屋配置、床下暖房の構造、白〜淡色の綿衣を区別する。

### 渡河点

- 春〜初夏の増水。濁流、柳、葦、中州、流木、杭、腰縄。川面を平らな青い帯へしない。
- 第143話は厳冬の冷水と浮氷。水牛兜の角を遠くから識別できる。

### 冬営

- 黄海道方面の雪、凍土、低い朝鮮家屋、煙道・温突、凍った飯、濡れた薪。
- 画面を夜の黒一色にせず、雪明かり、火、薄明で顔を読めるようにする。

### 晋州城外

- 南江沿いの土石城壁、門、曲がる城壁線、乾いた濠と雨泥、弓、石、火矢。
- 日本式天守、総石垣、白い近世城郭へ変えない。
- 城内に兵と民の両方がいる。民を背景の点だけにしない。

## 馬・船・軍装

- 日本馬・朝鮮馬とも小柄な東アジア在来馬。サラブレッド体形、カウボーイ鞍、西洋鐙は禁止。
- 和鞍は木製前輪・後輪、幅広い和鐙。長政の馬具も金ぴかにしない。
- 日本軍船は16世紀東アジアの木造沿岸船。三本マスト、西洋帆船、蒸気船、鉄船体は禁止。
- 火縄銃は火縄、火皿、木床を持つ。近代銃、ボルトアクション、金属薬莢は禁止。
