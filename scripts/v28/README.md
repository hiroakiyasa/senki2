## 年代・史実ロック

- 1614年11月26日の鴫野・今福の戦いから、和議、堀・曲輪の破却、1615年初春の城外決戦案までを描く。
- 今福・鴫野は旧大和川筋の湿地、水田、細い堤を基礎にし、大軍が自由に横展開できない。
- 佐竹義宣勢の今福攻撃、木村重成・後藤基次の来援、上杉勢による圧力、大坂方の退却という大枠を変えない。
- 渋江政光の戦死を後藤又兵衛または木村重成の一騎討ちの手柄へ移さない。死因・討ち手には史料・伝承差を残す。
- 大砲による城内への物理的・心理的圧力を描くが、一発だけで和議が決まったとはしない。
- 和議の交渉者として阿茶局、本多正純、常高院を描き、浪人衆へ公式決定権を与えない。
- 和議後の三ノ丸側防備・堀の破却と、作業が内側へ広がる過程を描く。合意範囲・作業主体の解釈差を単純な一人の悪意へ集約しない。
- 濃霧、作戦漏洩の発覚、国分先取失敗、小松山転進、又兵衛の戦死は第29巻以降。第28巻へ前倒ししない。
- 木村隊813人・帰還796人・死者17人、避難者94人、荷車42台、三経路、全図五枚、三日分の兵糧などの具体数は本作上の創作 `[C]` であり、史実総兵力・損害を置き換えない。

## 巻全体の連続性ロック

- 巻頭の又兵衛は豊臣方六千遊軍の将。ただし大坂城中の最終決定権、講和権、出門裁可は持たない。
- 又兵衛の右肩は高く上がらない。冷え、黒槍の抜き差し、梁救出で痛みが増す。高い打ち下ろしや長時間の単独無双を禁止する。
- 黒槍は短く重い素槍。複数の鉄の補修輪があり、一つは浮き気味。柵の横木、追撃限界、梁の梃子、避難境界、測り棒、地図押さえとして使う。
- 甚六は既に死亡している。本巻で本人を生還・再登場させず、退路の原則、盾縁、補修輪へ残す。
- 又兵衛は木村重成へ退却時刻を渡し、弦太の兵站配分を追認し、カヤへ情報分散を任せる。一方で、作戦全体を一人で背負おうとする欠点は残す。
- 大坂城は希望を集める城から、夢と浪人を逃がさない牢へ変化する。堀が埋まっても「安全な道」が増えるわけではない。
- 巻末では道明寺・国分方面の城外決戦案、攻撃線と同じ濃さの帰還線、各隊の退却条件、帰還用兵糧一日分が成立する。

## 舞台・建築・軍装の固定

### 今福・鴫野

- 旧大和川筋の灰色の冬空、細い土堤、深田、水田、葦、木柵、低い火縄煙。
- 乾いた大平原や、六千人が横一列で突撃できる地形にしない。
- 堤の曲がりで旗が消え、田へ落ちた兵は腿まで沈む。負傷者と前進兵が同じ細道ですれ違う。

### 豊臣期大坂城

- 黒い木部、土壁、板廊下、長屋、竈、土蔵、曲輪、堀、番所。生活域の貧しさと混雑を描く。
- 現存の徳川期石垣・白い復興天守を、そのまま1614年の城として使わない。
- 金の装飾は遠景・上層の一部に限定し、女房長屋や台所を豪華な御殿へしない。

### 大筒・火縄銃

- 当時の火縄銃、木製砲架に据えた大筒。発射閃光、遅れて来る低い砲声、固体弾の木・土への打撃を描く。
- 近代榴弾砲、爆発する高性能砲弾、フリントロック、連発銃を禁止。
- 火薬、火縄、湿気、装填時間、煙、残弾を勝敗条件へ入れる。

### 堀埋立

- 鍬、畚、土俵、丸太、土留め、排水、人夫列、篝火で工程を描く。
- 数時間で全堀が消える演出や近代重機を禁止。
- 作業人夫には徴発された百姓・町人・足軽崩れを含め、冷たい麦飯、凍る指、作業期限を持たせる。

## 全コマ共通の生成禁止

- 可読な文字、台詞、題字、条文、地図名、旗文字、偽文字。
- 現代道路、鉄道、コンクリート、電線、プラスチック、近代軍服、近代医療器具。
- 西洋騎士甲冑、巨大ファンタジー槍、発光武器、超常的な砲弾・爆発。
- 同じ顔・同じ具足・同じ馬・同じ人夫の機械的反復。
- 又兵衛が黒槍一振りで大軍を退ける、砲弾を弾く、梁を一人で持ち上げる演出。
- 渋江政光の明確な討ち取り、首級の誇示、敵兵の一律な悪人顔。
- 浪人衆が公式講和席へ乱入し、史実の交渉者から決定権を奪う展開。
- 又兵衛が人夫を斬って堀埋立を止め、史実を覆す展開。
- 淀殿、女房衆、大野治長を愚かさ・臆病さ・悪意だけで動かすこと。
- 第29巻の濃霧、国分、小松山、致命傷を前倒しすること。
