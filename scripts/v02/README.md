## 第2巻の連続性ロック

- 第1巻終了から二十七日後に開始する。
- 又兵衛は16〜17歳。仮札と父の焼けた無銘素槍を持つ。
- 松寿丸は10歳。1577年10月に織田方へ人質として送られる史実を固定する。
- 五人は又兵衛、弦太、清十郎、甚六、松寿丸。若党試しの正式候補は前四人で、松寿丸は守る対象兼伝令役。
- 又兵衛と松寿丸は、同じ木椀の欠けた一片を一つずつ持つ。
- 焼け槍は第13話で松脂・生皮・麻縄による第一補修。焦げを消さず、手元が重くなる。
- 「返し」は第12話で百回中一回の失敗起点、第15話でも七回で握力が落ちる。完成技にしない。
- 帰名帳は第11話で成立。第一頁は架空人物・樋口久作。分からない死因を空白にする。
- 弥九郎は個人槍術で又兵衛を上回り、黒田家の札を拒んで離脱する。
- 第16話終了時は、松寿丸が門内一人、又兵衛たちが帰陣四人。又兵衛はまだ自分を帰る人数へ入れない。

## 共通生成ロック

- 1577年の播磨を、土塁、丸太柵、板小屋、田畑、井戸、雑木林、質素な門で描く。
- 後世の白い姫路城大天守、連立天守、高い総石垣、近世の整然とした城下町を出さない。
- 村人、候補者、敗残兵は粗末な麻・木綿の小袖、脚絆、草鞋。豪華な甲冑や統一軍装を避ける。
- 焼け槍と弥九郎の槍は鎌・鍵のない素槍。超常的な残像、衝撃波、技名を叫ぶ演出を使わない。
- 生成画像へ台詞、N、音、帳面本文、札、護送書、題字などの可読文字を描かせず、分割後にローカル写植する。
- P1・P12のみ断ち切り。各頁1488×2105（B5比率）。右綴じで右頁が先読み、左頁が次頁。
