# 『戦帰 SENKI』v12ep91「渇く井戸」

## 話情報

| 項目 | 内容 |
|---|---|
| 巻/話 | 第12巻『四国の海』第3話（通算91/240） |
| 頁数 | 12頁（6見開き・43コマ） |
| 年代 | 1585年初夏・包囲三日目、夜明け〜翌朝 `[A/C]` |
| 視点 | 後藤又兵衛 |
| 現在の権限 | 五十人預かりだが戦力は負傷で四十三人。水源工作の決定権はない |
| 表面目標 | 日暮れまでに毒を使わず城への水を絞り、村と攻城陣へ清水を残す |
| 即時質問 | 早く城を降らせるため、降伏後の水を壊してよいか |
| 主機能 | 仲間の別回答／「崩し」を地形へ広げる |
| 引き | 白布が揺れるが、降伏か負傷者の印か分からない |

## 前話から受け取るもの

- 正面突入は失敗し、七人負傷。仙石隊の水は一日分。
- 城、攻城陣、城下三村は同じ山の水筋を使う。
- 検使側は毒草と腐肉を水口へ入れる案を準備している。
- 又兵衛は秀久から再突入を禁じられ、普請の中で代案を示す必要がある。

## 生成規約

- 毒袋は現実的な革袋。毒煙・緑の液体・魔法表現は禁止。
- 水路は山の湧水、石組み、木樋、泥、苔。近代的な配管・水門は禁止。
- 日中は湿熱。兵の割れた唇、汗が出なくなる皮膚、重い呼吸を描く。
- 水を守る選択にも代価を置く。三人が倒れ、作業が遅れ、功は普請帳へ吸収される。
- 「崩し」は落石の線、水の圧、敵の列、足場を少しずらす動きとして描く。

# 第91話終了時の台帳

## 人物

- 又兵衛：権限がないまま毒の実行を日暮れまで止め、カヤ・弦太・宗十郎・甚六の技能をつないで代案を成立させる。「崩し」を敵個人から水流・落石線・隊列へ拡張。
- カヤ：苔と虫から二本の水筋を発見。
- 弦太：城七・村三の流量を測り、城二・村三・陣二へ配分。捕虜六人を歩かせる方が担架より人手を使わないと示す。
- 宗十郎：石三段、木栓、短い樋で水を分け直す。普請の公式功績は宗十郎と工兵方へ入る。
- 甚六：盾を斜面へ寝かせ、矢と石の線を変える。捕虜六人を殺さず囲う。
- 藤乃：熱疲労三人を救護し、又兵衛へ自分の水を飲むよう命じる。

## 人数・負傷

- 稼働可能四十三人のうち三人が熱疲労で倒れる。翌話の即応戦力は四十人。
- 長宗我部兵六人を生け捕り。負傷は軽く、歩行可能。
- 前話の重傷者一人は意識を回復するが行軍不可。

## 道具・水

- 毒袋：未使用で検使が回収。
- 水路：城側七→二、村側三を維持、陣側へ二。残りは地中へ逃がす。
- 樋・木栓：矢傷一、予備栓を使用。次話で城方の奪還目標になる。
- 又兵衛の論功札：個人の記載なし。

## 第92話への不可逆条件

- 城方は水路を取り戻さなければ井戸がもたない。
- 長宗我部兵は夜襲で六人を捕られたが、目的を失えば整然と退く兆候を見せた。
- 城柵の白布の意味は未確定。
- 又兵衛隊は首を取らず水場を守ったため、味方兵の一部に不満がある。
