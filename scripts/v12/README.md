## 年代・史実ロック

- 1585年 `[A]`。羽柴秀長を総大将とする四国攻めを守る。
- 一宮城は長宗我部元親が豊臣軍への防衛拠点とした山城 `[A]`。城方の中心は谷忠澄・江村親俊 `[A/B]`。
- 城の開城、長宗我部元親の降伏、四国全体の和平を又兵衛一人の功績にしない。
- 仙石秀久が宇喜多・黒田勢などと四国へ入り、1585年に讃岐を得る史実を守る `[A/B]`。
- 海上輸送、水路の細部、毒を用いる提案、又兵衛隊五十人、弥平、降伏兵六十二人、城下民二十一人は `[C]`。
- 九州への命令は出陣準備の開始として描き、戸次川合戦本体は第14巻まで起こさない。

## 共通人物シート

### `matabei@v12`

- 又兵衛、作中33歳前後。痩身だが肩・腰・前腕が鍛えられている。日に焼け、目尻に疲労線。
- 継ぎ当ての濃い藍小袖、質素な腹巻または胴丸、籠手は左右不揃い、脚絆、草鞋。立派過ぎる大鎧・金具は禁止。
- 武器は焼け跡と補修跡が残る無銘の素槍。十文字槍、鎌槍、管槍、黒く完成した黒槍は禁止。
- 小さな黒い旗または黒布を帰路の印に使う。大きなのぼり旗ではない。
- 表情は、救援時の集中と、名を欲しがる視線の両方を描く。聖人の顔へ固定しない。

### `sengoku@1585`

- 仙石秀久、33歳前後。小柄〜中背、動きが速く、笑う時も相手の働きを測る目。
- 実用的だが他兵より一段良い胴丸、陣羽織、兜。金ぴか・過剰な装飾・巨大な角は禁止。
- 低い身分から上がった自負と、人を前へ出させる魅力を持つ。後の失敗を知る悪役顔にしない。

### `genta@v12`

- 兵站を担う。戦場で食べ物だけを見ている滑稽役にしない。

### `seijuro@v12`

- 狭間清十郎。細身、濡れた紙を守る油紙、矢立、地図箱、帰名帳。

### `jinroku@v12`

## 舞台・建築・舟の固定

### 海・舟

- 鳴門周辺の灰緑の海、速い潮、岩礁、白い潮筋。穏やかな湖のように描かない。
- 16世紀日本の木造沿岸舟。櫂、艪、一本帆、低い舷。西洋帆船、三本マスト、舵輪、鉄製船体、蒸気船は禁止。
- 舟ごとに大きさと積荷を変える。十二艘を同一コピーにしない。
- 兵、馬、水樽、火薬箱、盾、縄の重量差を見せる。

### 一宮城

- 山の尾根を削った中世山城。土塁、木柵、堀切、曲輪、細い坂、湿った岩、井戸、水の手。
- 天守、総石垣、白壁の近世城郭、巨大な瓦門は禁止。1585年の攻略前に蜂須賀期の整備を先取りしない。
- 城下は田、畑、用水、粗末な家。水源は城兵だけでなく三村の生活へつながる。

### 軍装

- 足軽は陣笠、胴丸・腹巻、粗末な小袖、脚絆、草鞋。装備は統一し過ぎない。
- 長宗我部兵も仙石兵も人間の顔、年齢、装備差を出す。敵だけ黒く禍々しくしない。
- 鉄砲、弓、槍、盾、鍬、木槌を状況に応じて使う。抜き身の刀を全員に持たせない。

## 全コマ共通の生成禁止

- 可読な文字、台詞、題字、札の文章、偽文字。
- 現代の港、コンクリート、電線、機械、プラスチック、現代医療器具。
- 西洋式の甲冑・鞍・船・帆・城。
- ファンタジー魔法、発光する槍、超常的な水流、巨大爆発。
- 同じ顔の群衆クローン、同じ舟・盾・槍の機械的反復。
- 歴史上の総大将を又兵衛の後ろで指示待ちする構図。
- 技名を叫ぶ演出。「崩し」は人物と地形の動きで見せる。
- 敵兵の一律な悪人顔、降伏兵を無力な群衆としてだけ描くこと。

- 各話12頁、6見開き、43コマ。

- P12は次話の質問を残すが、当話の小さな問いには答える。
