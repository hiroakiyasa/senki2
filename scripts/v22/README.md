## 巻の固定線

- 第22巻の外的勝利は、関ヶ原東軍勝利への寄与、大橋掃部討ち取り、筑前移封への前進。
- 内的敗北は、協働の功が又兵衛一人の名へ集約され、六人が評価によって別役へ分かれること。
- 又兵衛の強さは単独無双ではなく、弦太・清十郎・又吉・小平・藤乃・宗十郎と無名兵の接続で成立する。
- 右肩の古傷、左掌の裂傷、短く重い黒槍、二つの補修輪、五本の黒旗、白布の帰路を連続させる。
- 小早川秀秋は自分の命令で決める。山への威嚇射撃だけを原因にしない。
- 島津の退き口は島津側の判断と犠牲で成立する。又兵衛が救ったことにしない。
- 大橋掃部討ち取りは後世伝承を採用したC/D再構成であり、二人だけの一騎討ちにはしない。
- 大隈城と正式な知行高は第177話で確定。本巻最終話は内示箱まで。

## 生成例

```bash
# 参照ボードと指示文の準備
node pipeline/generate_spread.mjs scripts/v22/ep01_黒田の前進.md \
  --outdir production/v22/ep01spread --spreads 1 --prepare

# 全6見開き生成
node pipeline/generate_spread.mjs scripts/v22/ep01_黒田の前進.md \
  --outdir production/v22/ep01spread --spreads 1-6

# 分割・写植・検品
node pipeline/finalize_spread.mjs scripts/v22/ep01_黒田の前進.md \
  --image production/v22/ep01spread/spreads/s01.png --spread 1 --open
```

各話は `ep01` を該当番号へ置換する。生成画像には文字を描かせず、台詞・N・音・題字は分割後に正典全文を写植する。
