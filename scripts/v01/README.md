## 巻の固定値

- 時間：豪雨の午後から翌朝まで、ほぼ一夜。
- 帰す対象：松寿丸、避難民43人、主要五人、兵糧車9台。
- 初期荷：兵糧車12台。油細工3台のうち、浅い1台から乾いた6俵を救い、深い2台の14俵を失う。
- 敵：源六を含む11人。騎馬3、徒歩8。
- 父：第5話で死亡。遺体の行方は不明。
- 源六：生存。父の札を持つ。
- 又兵衛：第4話で左肩、第5話で両掌を負傷。第8話まで継続。
- 焼け槍：第4話P12で初出、第5話で継承。完成した黒槍ではない。

## manga-spread 実行例

```bash
# 参照ボードと指示文のみ準備
node pipeline/generate_spread.mjs scripts/v01/ep01_父のいない馬.md \
  --outdir production/v01/ep01spread --spreads 1 --prepare

# 全6見開き生成
node pipeline/generate_spread.mjs scripts/v01/ep01_父のいない馬.md \
  --outdir production/v01/ep01spread --spreads 1-6

# 見開き分割、正典全文写植、検品、エディター起動
node pipeline/finalize_spread.mjs scripts/v01/ep01_父のいない馬.md \
  --image production/v01/ep01spread/spreads/s01.png --spread 1 --open
```

各話は `ep01` と出力先を対象話へ置き換える。画像生成時は台詞、ナレーション、擬音、題字、掲示、可読な偽文字を描かせず、分割後にローカル写植する。
