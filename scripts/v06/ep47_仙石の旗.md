# 『戦帰 SENKI』v06ep47「仙石の旗」

## 話情報

| 項目 | 内容 |
|---|---|
| 巻/話 | 第6巻『音のない鈴』第7話（通算47/240） |
| 頁数 | 12頁（6見開き・43コマ） |
| 年代 | 1581年頃・二日後の朝〜夜、明石沿岸の見張り砦 `[C]` |
| 視点 | 後藤又兵衛 |
| 現在の権限 | 仙石家の仮雇い。先陣札あり、正式な小頭ではない |
| 表面目標 | 満ち潮まで二刻以内に火台へ仙石の小旗を立て、門を内側から開く |
| 即時質問 | 五郎作を全員で戻すか、役割を分けて旗を取り、その功を誰の名で残すか |
| 主機能 | 武名の快感／仲間の働きを一人の名が吸収する最初の失敗 |
| 引き | 又兵衛は三人の名を軍帳へ足す機会を、自分で黙って失う |

## 戦闘条件

- 仙石方72人。細道へ一度に8人。砦側26人、弓6、長槍8。
- 干潮路は荷車一台幅。左右は膝まで沈む塩泥。満ち潮まで二刻、実測一刻半。
- 第一・第二組が盾で射線を受け、第三組が梯子を掛ける。退く合図は銅鑼二つ。

## 生成規約

- 細道、塩泥、潮、盾、梯子が勝敗を決める。又兵衛単独の超人的突撃へしない。
- 甚六は左腕を吊ったまま右腕で盾と救助を行う。
- 小旗は人の胴より小さい。大のぼり、勝利の巨大旗は禁止。
- 砦は土塁・木柵・火台・木門。天守・総石垣・瓦門は禁止。
- 敵兵は舟へ退く。全員を討ち取る爽快演出にしない。

# 第47話終了時の台帳

- 見張り砦は仙石方が確保。砦兵は舟で退き、追撃しない。
- 又兵衛は火台へ小旗を立て、門を開け、仮小頭札と板敷き一間を得る。
- 清十郎の風、弦太の梯子、甚六の盾と救助が成功条件だが、公式軍帳は又兵衛一人の一番槍として記す。
- 又兵衛は三人の名を足そうと言いかけ、称賛を受けて黙る。
- 五郎作は左脚を梯子に挟む。生存し、甚六が添え木を当てる。
- 又兵衛の左前腕傷が開く。焼け槍は焦げと仮巻きのまま。
