## 自動検証

実行コマンド：

```bash
python scripts/v06/validate_v06.py
```

検証スクリプトは、次を失敗条件として扱う。

1. 第41〜48話の8ファイルが揃っていない。
2. P1〜P12が連番でない。
3. 一話43コマ、全巻344コマになっていない。
4. 頁別コマ数が固定配列と違う。
5. コマ番号が各頁でc01から連番になっていない。
6. 各コマの `画:` または `生成:` が欠ける。
7. 終了台帳がない。
8. 仮置きコメント、未完成マーカーが残る。
9. 擬音欄が一話9コマ未満になる。
10. 負傷、所属、道具、人物関係の継続語が欠ける。

GitHub Actionsの `.github/workflows/validate-v06.yml` は、`scripts/v06/**` の更新ごとに同じ検証を実行し、`senki/v06-structure` のコミットステータスを登録する。

## 連続性ロック

### 第5巻から受け取る

- 又兵衛は黒田家を追放済み。黒田の組紐を焼け槍から外している。
- 焼け槍は焦げ、刃こぼれ、麻縄の仮巻きを維持し、まだ黒漆を施さない。
- 又兵衛の左脇腹傷と発熱後の消耗を残す。
- 甚六は左前腕を負傷し、布で吊ったまま第6巻へ入る。
- 弦太、清十郎、甚六は黒田方に所属したまま。仙石家臣として一括転籍させない。

### 第6巻内で増えるもの

- 第42話：又兵衛の左足首に縄ずれ。
- 第44話：又兵衛の左前腕に浅い切創。カヤはスズの東行きを知る。
- 第45話：八人の帰路を作り、カヤを従わせずに別れる。
- 第46話：又兵衛だけが仙石家の新しい名札を受ける。
- 第47話：三人の働きが又兵衛一人の軍功へ吸収され、又兵衛は訂正しない。
- 第48話：カヤが自分の判断で鈴を鳴らし、三人は救援、又兵衛は先陣を選ぶ。

### 第7巻へ送る

- 又兵衛は仙石家の正式小頭札と十人、板敷き二間を得る。
- 弦太、清十郎、甚六は黒田方へ戻る。
- カヤは又兵衛の配下にならず、スズと鴉丸を追う。
- 官兵衛の密使が備中へ通じる三本の街道図を持って仙石陣へ来る。
- 右肩の恒久傷、黒漆の黒槍、金属補修輪はまだ登場させない。

## 史実境界

- 三木合戦後の播磨の荒廃、伊賀侵攻による離散、仙石秀久が羽柴方で働く大枠を背景史実として扱う。
- 嘉助一家、灰谷十蔵、鴉丸、炭場救出、明石沿岸の二砦、札制度、小頭札取得の具体的経緯は創作区間とする。
- 砦戦を特定の史実合戦へ置き換えず、羽柴軍・仙石秀久の判断と功績を又兵衛一人へ奪わせない。
