# 第41話終了時の台帳

- 又兵衛は黒田の名を使わず、嘉助の荷札を焼いた。嘉助、おりく、お春、辰、六助の名を焼け槍の仮巻き内へ残す。
- 嘉助一家は屋根修理を条件に納屋へ残れる。公的な荷札は消失。
- 焼け槍は黒田組紐なし、麻縄仮巻きあり。黒漆・正式補修なし。
- 欠けた椀と清十郎の紙片は又兵衛が保持。
- 鳴らない鈴の女は又兵衛を縄罠で捕らえ、黒田の道を求める。名はまだ出ない。
