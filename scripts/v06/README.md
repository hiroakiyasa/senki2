- 本編の現在時点は1581年頃。三木合戦後の播磨の荒廃と、伊賀侵攻による離散を背景に置く `[A/B]`。

## 共通人物シート

### `matabei@v06`

- 後藤又兵衛、29歳前後。痩身から実戦的な筋肉がつき、手足が長い。顔には発熱後のやつれと、名を呼ばれたい若さが同居する。

- 第5巻の左脇腹切創が治り切っていない。第42話で左足首を縄ずれ、第44話で左前腕を浅く切られ、第47話で傷が開く。右肩の恒久傷はまだない。
- 武器は黒田の組紐を外した焼けた無銘の素槍。焦げた柄、刃こぼれ、麻縄の仮巻きを維持。黒漆、正式な黒槍、金属の補修輪は禁止。
- 欠けた椀の片割れと、清十郎の紙片を懐へ持つ。紙片の文字は生成画像で読ませない。

- 鈴は小さな鉄または銅の素朴な鈴。舌を布で包み、普段は鳴らない。第48話で布を外すまで音を出さない。

## 舞台・小道具の固定

### 焼け村・藍染め場

- 三木合戦後の貧しい播磨。焼けた梁、半分落ちた藁屋根、泥、灰、畑、竹藪、雨漏りする納屋。
- 近世の白壁町家、瓦屋根の整った宿場、石垣、天守、豪華な武家屋敷は禁止。
- 食事は粟、焼け米、干し大根、味噌玉、薄い粥。豪華な膳、白米の山、陶磁器の揃い物は禁止。

### 灰谷の炭場

- 谷底に土と石の炭窯三つ、腰高の粗い木柵、南門、東の排水溝、西の馬二頭、北の簡素な見張り台。
- 城郭化しない。天守、石垣、櫓門、整った兵舎は禁止。
- 縄、木札、藁床、水桶、干し縄、炭粉を反復小道具にする。

### 明石の浜・二つの砦

- 灰緑の海、潮の速い砂州・干潟、塩泥、松林、粗い木舟、低い土塁と木柵の見張り砦。
- 砦は火台、逆茂木、木門、土塁、見張り足場で構成。総石垣、白壁、瓦門、天守は禁止。
- 舟は16世紀日本の低い木造沿岸舟。西洋帆船、舵輪、鉄製船体、近代港は禁止。
- 荷車、塩俵、矢竹、水樽、短梯子、木盾、仙石の小旗を使う。旗は手旗〜小旗で、大のぼりを画面へ乱立させない。

### 札・帳面・鈴

- 木札は薄い無地または読めない角度。生成画像に可読文字を出さない。写植でのみ「後藤又兵衛」等を入れる。
- 欠けた椀は粗い木椀の半欠け。話ごとに欠け方を変えない。
- 鈴は掌に収まる一つだけ。神楽鈴、房飾り、巨大な鐘、魔法の発光は禁止。

## 全コマ共通の生成禁止

- 可読な台詞、題字、札、帳面、道標、偽文字。文字は分割後に写植する。
- 現代物、電線、コンクリート、機械、プラスチック、現代医療器具。
- 西洋甲冑、西洋鞍、西洋帆船、近世完成城郭、豪華な大名行列。
- ファンタジー忍術、分身、超常的な跳躍、発光する槍・鈴、巨大爆発。
- 全員が抜き身の刀を持つ構図。戦闘は槍、短槍、弓、火縄銃一挺、盾、縄、地形を中心にする。
- 技名を叫ぶ演出。又兵衛の「返し」は接触、短い引き、足場で見せる。
- 仙石秀久を後世の敗北だけで歪めた悪人顔にすること。
- カヤを性的な忍者衣装へすること、又兵衛の所有物・従者として常に一段後ろへ置くこと。
- 同じ顔の子供・兵・舟・荷車をコピー反復すること。

## 紙面共通規定

- 各話12頁、6見開き、43コマ。
- 基本配列は `1 / 3 / 7 / 3 / 3 / 3 / 7 / 3 / 2 / 7 / 3 / 1`。
- 全面1コマ頁はP1・P12。断ち切りは頂点だけ。
- 7コマ以上の速射頁をP3・P7・P10の3頁に置く。
- 2〜3コマ頁を7頁置く。4〜5コマ頁を3頁連続させない。
- 擬音を全コマの20%以上、叫びを3回以上置く。
- P1に場所、時刻、物資または残り時間を置く。
- P12は当話の小さな問いへ答え、次話で払う代価を一枚の絵にする。
- 戦闘話は人数、武器、足場、時間、疲労、情報差、守る対象、退路を話情報か本文で明示する。
