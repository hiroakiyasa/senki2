## 史実と創作

- `[A]`：1587年の黒田氏豊前入封、豊前国人衆の蜂起、長政の城井谷攻めと敗退、その後の再攻勢。
- `[D]`：正確な出陣日、二千余という兵数、個々の討死、剃髪の細部など、軍記・伝承に依存する事項。

- 城井鎮房の中津での死は本巻では起こさない。又兵衛を直接殺害者にしない。

## キャラクター年代・状態

- **又兵衛**：黒田へ百石与力として帰参した実戦指揮官。焼けた無銘槍を使用。右肩骨折前。黒槍・補修輪はまだ存在しない。
- **黒田長政**：父・官兵衛の留守に豊前を預かる若い主君。新領国の連鎖蜂起を恐れる。水牛兜は朝鮮編以降なので本巻では使わない。
- **速水弦太**：兵站・水・馬・荷車・歩調を担当。粗末だが実用的な胴丸。
- **狭間清十郎**：地図・時刻・帰名帳。戦闘より観察と記録を優先しがち。
- **槙島甚六**：盾・後陣・退路。戸次川以来の脚傷があり、走ると右脚を引きずる。
- **吉田長利**：黒田方の実務将。測量、先陣、主君護衛を担う。
- **城井方**：粗野な山賊ではなく、代々の谷、墓、田、家族を守る在地武士・農兵。女性、子ども、老人も籠城準備をする。
- **作兵衛**：創作の炭焼き・案内人。黒田方に拘束され、城井方には家族を押さえられ、白砂の沢を伏せる。

## 全話共通の画面規約

- 時代：1587年、豊前。初秋から晩秋。
- 馬ヶ岳城：入封直後の木・土・竹で普請中の山城。後世の立派な天守、白壁の近世城郭、完成した石垣は出さない。
- 城井谷：深い杉・樫林、巨岩、細い沢、泥、苔、岩丸谷の狭道。山道は二列が限界。霧と湿気で遠景が切れる。
- 武具：実戦用の胴丸・腹巻・陣笠・籠手・脛当。色は黒、鉄錆、藍、茶。金箔、過剰な角、ファンタジー装甲、江戸後期の儀礼鎧は禁止。
- 又兵衛の槍：素槍。柄の一部が火を受けて黒く、古い継ぎと傷がある。十文字槍、鉤、管槍、黒槍の補修輪は禁止。
- 長政：黒漆系の実用具足。大きな水牛角兜は禁止。馬印・小旗は必要時のみ。
- 城井方：家伝の古い胴、革、蓑、農具を改めた武器、弓、石、丸太。全員を同じ顔・同じ衣装にしない。
- 文字：生成画像へ台詞、題字、札、地図文字、可読な偽文字を描かせない。文字は分割後にローカル写植。
- 光：谷は灰緑と湿った低い光。火、松明、普請場の夕日だけを暖色源とする。
- 禁：現代物、洋式馬具、銃剣、幕末装備、巨大天守、コンクリート、電線、可読なAI文字、過剰な血飛沫、英雄だけを照らす神聖光。

1. 12頁・40コマである。
2. P1・P12が断ち切り。
3. P3・P7・P10が6コマ速射。
4. 戦闘話は地形、人数、武器、時刻、疲労、情報差、退路が絵から読める。
5. 旗・地図・台帳・門が「救う道具」と「支配の道具」の両方に見える。
6. 又兵衛の正論だけで場面を解決しない。
7. 長政の進軍を虚栄だけで説明しない。
8. 城井方の生活、家族、食料、墓、田を少なくとも一場面置く。
9. 右肩骨折、第一補修輪、黒槍組成立を先取りしない。
