## 年代・史実ロック

- 天正十二年（1584年） `[A]`。小牧・長久手の戦いを扱う。
- 家康・信雄方が小牧山を短期間で改修し、東方へ連砦を築いた骨格を守る `[A/B]`。
- 三河中入り、篠木周辺から家康方へ届く通報、4月9日の白山林・桧ケ根・長久手の順を崩さない `[A/B]`。
- 三好信吉を逃がした功は木下勘解由・木下助左衛門兄弟へ残す `[A/B]`。
- 桧ケ根で徳川方先遣隊を破る功は堀秀政へ残す `[A/B]`。
- 池田恒興・池田元助・森長可の戦死を又兵衛が防がず、討ち手の功績も奪わない `[A]`。
- 長久手後、家康が小牧山へ戻り、11月に秀吉と織田信雄が和議へ至る流れを守る `[A/B]`。
- 又兵衛の五十二人隊、道調べ、負傷者収容、黒旗、追撃命令違反、忠勝との接触は `[C]`。
- 家康・秀吉・池田・森・堀・木下兄弟を又兵衛の指示待ちにしない。又兵衛は歴史上の決断を奪わず、退路、人数、命令時刻、負傷者を扱う。

## 共通人物シート

### `matabei@v11`

- 又兵衛、作中32〜33歳前後 `[C]`。長身で痩せて見えるが、肩、腰、前腕は鍛えられている。日に焼け、目の下に行軍疲れ。
- 継ぎ当ての濃い藍小袖、質素な腹巻または胴丸、左右不揃いの籠手、脚絆、草鞋。大鎧、金蒔絵、巨大な前立は禁止。
- 武器は父から受け継いだ焼け跡と複数の補修跡を持つ無銘の素槍。黒く完成した黒槍、十文字槍、管槍、発光する必殺武器は禁止。
- 使える原理は「返し」「空」「伸び」まで。技名を叫ばず、接触、足場、間合いで見せる。
- 腰に仙石家の小頭札。黒田の正式家臣へ戻ってはいない。
- 救援時の集中と、旗・首・先陣へ目が向く武名欲を同じ顔に残す。完成した人格者にしない。

### `genta@v11`

- 速水弦太。丸顔、大柄。荷役で肩と腕が太い。算木、木札、縄、干飯袋、柄杓。
- 米、水、馬草、草鞋、荷車、人数を数える。食いしん坊だけの滑稽役にしない。
- 又兵衛が自分を人数から抜くたび、数字で押し戻す。

### `seijuro@v11`

- 狭間清十郎。細身。油紙に包んだ地図、矢立、白土袋、帰名帳。
- 道だけでなく、足跡、泥、命令書の折り目、伝令の草鞋から時刻と経路を読む。
- 確認できない死因を美談へ補わず、「不明」を残す。

### `jinroku@v11`

- 槙島甚六。大柄、幅広い木盾、質素な胴丸。盾縁には古い傷。
- 又兵衛の横または後ろに立ち、列の幅、畦、荷車、退路を見る。
- 右脇を打つが歩行可能。脚の恒久傷、後世の五原則はまだない。

### `sengoku@1584`

- 仙石秀久、30代前半。小柄〜中背、動きが速い。実用的だが一段良い胴丸と兜。
- 低い身分から上がった自負、人へ機会を与える魅力、先駆けを価値とする危うさを併せる。
- 戸次川の失敗を知る悪役顔、無能な道化として描かない。

### `kanbei@1584`

- 黒田官兵衛。痩身、牢で傷めた脚を引き、杖を使う。簡素な具足、地図、書付。
- 戦略上の決定を担い、又兵衛へ現場の問いを渡す。万能予言者にしない。

### `nagamasa@1584`

- 黒田長政。若い武将。幼い松寿丸の面差しを残すが、背が伸び、実用的な胴丸を着る。
- 又兵衛を兄のように見る近さと、記録・所属を制度へ変えようとする視線を持つ。
- 豪華な若君、子どもの姿、冷酷な監視者へ固定しない。

### `hideyoshi@1584`

- 羽柴秀吉。小柄、目と手が速い。楽田本陣では簡素な陣羽織と実戦具足。
- 怒りを大声だけで表さず、伝令時刻、泥、草鞋、死者家族、政治判断へ変える。
- 一騎討ちの英雄ではなく、軍と政略を動かす総大将として描く。

### `ieyasu@1584`

- 徳川家康、40代前半。低い重心、厚い胴、落ち着いた目。実用的な具足。
- 土塁、井戸、交代、草鞋、誤報への反応を管理する。臆病な狸、肥満した老人、派手な豪傑にしない。
- 長久手の勝利後も追撃欲へ流されず、守る位置と政治目的を選ぶ。

### `tadakatsu@1584`

- 本多忠勝、30代半ば。鹿角脇立の兜、実戦的な黒系具足、長い素槍。巨大な超常槍にしない。
- 槍技を誇示せず、半歩の位置、低い穂先、追わない判断で又兵衛を止める。
- 一合も交えない初遭遇を守る。無表情な怪物ではなく、荷駄の若兵へ縄を締め直せと声を掛ける。

### `nobuyoshi@1584`

- 三好信吉、17歳前後。若い総大将。白山林で兜を失い、泥にまみれる。
- 木下兄弟に逃がされる。又兵衛が救出の功を奪わない。

### `hori@1584`・`ikeda@1584`・`mori@1584`

- 堀秀政：20代後半。桧ケ根で鉄砲と地形を使い、勝っている間に退く判断をする。
- 池田恒興：50代。老練だが武功への熱を失わない。家紋旗の中心にいるだけの置物にしない。
- 森長可：20代後半。速度と攻勢の将。赤い悪鬼のように誇張せず、兵を率いる若い大将として描く。

## 舞台・建築・軍装

### 小牧山・連砦

- 低い独立丘陵。新しく切った土、二重土塁、堀、折れた虎口、木柵、東方へ続く小砦。
- 近世の石垣、復興天守、博物館、舗装階段、現代の街並みは禁止。
- 「低いから容易」という第一印象と、地面へ入ると射線が交差する実態を両立する。

### 楽田本陣・街道

- 土塁、木柵、粗末な陣小屋、炊事鍋、荷車、馬繋ぎ。豪華な御殿にしない。
- 大草、関田、上条、篠木周辺は田畑、低い丘、庄内川支流、竹藪、粗末な家、共同井戸。
- 村人の生活物を背景小道具にせず、味噌、藁、椀、井戸蓋、畦、受取札の所有者を見せる。

### 白山林・桧ケ根・長久手

- 白山林は林根、斜面、朝靄、炊事煙、狭い出口。整然とした平原会戦にしない。
- 桧ケ根は低い丘と香流川周辺。鉄砲線、畦、屋敷林、退路を見せる。
- 長久手は低丘、田畑、林、村道。巨大な一枚平原や近代公園として描かない。

### 軍装・馬具・旗

- 足軽は陣笠、胴丸・腹巻、粗末な小袖、脚絆、草鞋。装備と年齢を揃え過ぎない。
- 馬は16世紀日本の質素な和鞍、和鐙。西洋鞍、細い輪鐙、巨大な軍馬は禁止。
- 旗は家紋が識別できる形でも、生成画像へ文字を描かせない。巨大過ぎるのぼり、現代国旗は禁止。
- 又兵衛の黒旗は手のひら数枚分の無紋黒布。高く掲げる英雄旗ではなく、低い退路標識として使う。

## 全コマ共通の生成禁止

- 可読な台詞、題字、札、地図文字、家名、偽文字。
- 近代の道路、電柱、コンクリート、ビニール、銃器、車両。
- 天守、総石垣、白壁の近世城郭を小牧山・楽田へ置くこと。
- 西洋式甲冑、馬具、城、ファンタジー武器、発光する槍、超人的な衝撃波。
- 全員が抜き身の刀を持つ構図。同じ顔・具足・旗・馬の機械的反復。
- 家康、秀吉、池田、森、堀、木下兄弟を又兵衛の後ろで指示待ちさせること。
- 又兵衛が池田・森を救う、家康を追い詰める、忠勝へ一騎討ちで勝つ構図。
- 技名を叫ぶ演出、黒槍完成、恒久的な右肩後遺症、亀甲車、後世の五原則。
- 徳川方だけを黒い悪人顔、秀吉方だけを明るい正義側にする色分け。
