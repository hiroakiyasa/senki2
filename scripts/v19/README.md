## 生成上の固定

- 生成画像に台詞・題字・効果音・可読文字を描かせない。
- 晋州城を日本式天守、欧州城塞、中国幻想宮殿にしない。
- 日本側・朝鮮側の衣装と武器を区別するが、どちらも幻想甲冑へしない。
- 城内に家、井戸、穀倉、炊事、椀、家族を置く。
- 陥落後の暴力は日本軍側の加害として残す。残虐さを娯楽的な血量で誇張しない。
- 群衆は同一顔を複製しない。
- 亀甲車を近代戦車、金属装甲車、攻城塔にしない。
- 黒槍の右肩制約と重心を全話で継続する。

## pipelineについて

本ファイル作成時点のリポジトリには、ユーザー指定の

- `pipeline/generate_spread.mjs`
- `pipeline/finalize_spread.mjs`

が存在しないため、画像生成・分割・写植・検品は実行していない。脚本は同じ入力形式へ整えてあり、pipeline追加後に各話を順に処理できる。

想定実行例：

```bash
node pipeline/generate_spread.mjs scripts/v19/ep145_矢の雨.md \
  --outdir production/v19/ep145spread --spreads 1 --prepare

node pipeline/generate_spread.mjs scripts/v19/ep145_矢の雨.md \
  --outdir production/v19/ep145spread --spreads 1-6

node pipeline/finalize_spread.mjs scripts/v19/ep145_矢の雨.md \
  --image production/v19/ep145spread/spreads/s01.png --spread 1 --open
```

同じ規則で `ep146` 〜 `ep152` を処理する。
