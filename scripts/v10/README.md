## 巻の固定値

- 年代：1582年の山崎直後から1583年の賤ヶ岳後まで。
- 第10巻の外的勝利：記録外二十三人を補遺へ入れ、冬米百六十二俵を有効配分し、賤ヶ岳で73人と火薬箱8棹を帰し、旧住民と帰還兵の継ぎ宿を一軒成立させる。
- 第10巻の内的敗北：又兵衛は褒美、恒久所属、自分だけの家を得られない。五人は別々の命令系統へ分かれる。
- 又兵衛の右肩の大傷はまだない。甚六の脚の大傷・死もまだ起こらない。
- 「賤ヶ岳七本槍」は後世の呼称として扱い、1583年当日の七人が固定称号を自称する描写を禁じる。
- 清洲会議の室内会話を確定再現せず、又兵衛を織田家継承・領地配分の決定者にしない。
- 又兵衛の褒美目録と栗毛は預かりのまま。父の栗毛とは別個体。
- 両家請状・継ぎ宿は創作［C］。正式帰参状、所領安堵、恒久屋敷ではない。

## 八話を貫く感情線

1. **名を一緒に載せたい**――五人で勝ったのに、帳面は五人を分ける。
2. **自分たちを先にしたい**――又兵衛は二十三人の死者を先へ通し、自分なら次を奪えると考える。
3. **仲間へ任せるしかない**――弦太が米を決め、甚六が最後尾を決め、清十郎が不都合な記録を残す。
4. **名を取りたい**――賤ヶ岳で又兵衛は持場を離れ、父と同じ「先へ出れば名が残る」誤りへ近づく。
5. **守られることを嫌う**――長政の印も官兵衛の条件も、又兵衛には囲いと縄に見える。
6. **それでも帰る場所が欲しい**――最後は所有権ではなく、自分の椀を置き、戻らなければ叱る人を得る。

## 共通生成規約

- 16世紀後半の日本。現代の復元天守、コンクリート、洋式軍装、細い西洋鐙、近代印刷物を出さない。
- 画像生成時に可読文字を描かせない。帳面、札、目録、請状は欄・朱線・印・紐・紙の重なりだけを生成し、本文は分割後に写植する。
- 又兵衛の槍は、焼け跡と継ぎ補修が残る無銘の素槍（焼け槍／継ぎ槍）。完成した黒槍、十文字槍、鍵槍、管槍ではない。技名を叫ばない。
- 戦闘は湿地幅、橋板、継ぎ縄、火薬箱、人数、残り時間、疲労、誤情報で動かす。
- 勝家方・書役・門役・村書役を主人公の正しさを証明する悪役にしない。各人に守る帳、村、扶持、家族、任務がある。
- 群衆は同一顔を反復しない。負傷、荷、年齢、歩き方、持ち物を分ける。
- 戦の直前と直後に、飯、椀、薪、屋根、種籾、子どもの玩具を置く。
