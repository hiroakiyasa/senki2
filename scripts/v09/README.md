## 正典上の固定

- 秀吉が総大将、官兵衛が戦略中枢。又兵衛は現場で渡河・射線分断・旗の命令網・退路遮断を成立させる。
- 光秀本人を又兵衛が討たない。最期は複数証言のまま確定しない。
- 天王山頂の争奪だけで山崎の勝敗を説明しない。円明寺川、湿地、西国街道、坂本への道、時刻を併記する。
- 素槍七手「伸び」は叫ばない。初回は戻せず市松を死なせ、二回目は甚六・七郎・弦太・清十郎の補助で成立する。
- 又兵衛の武名欲を消さない。全員の名を書かせる場面も無欲の聖人化ではなく、褒美を人数分取る要求として描く。
- 長政は冷たい敵ではない。又兵衛を守るため制度へ入れようとし、同時に別の忠誠中心を管理しようとする。

## 共通紙面規格

- 各話12頁・6見開き・43コマ。
- 頁別コマ数は `1 / 3 / 7 / 3 / 3 / 3 / 7 / 3 / 2 / 7 / 3 / 1`。
- P1・P12は全面断ち切り。P3・P7・P10は7コマ速射。2〜3コマ頁は7頁。
- 4〜5コマ頁の3連続なし。
- 右綴じ。P1-P2をS1、P3-P4をS2、P5-P6をS3、P7-P8をS4、P9-P10をS5、P11-P12をS6とする。
- 生成画像へ台詞・N・音・題字・可読文字を描かせない。分割後に正典全文を写植する。

## 共通美術規約

- 時代：天正十年（一五八二）。大山崎の西国街道、円明寺川、湿地、油座、低い土手、炭焼き道。
- 羽柴・黒田方も明智方も移動直後で質素。過剰な金甲冑、巨大なのぼり、天守を戦場近景へ置かない。
- 雨上がりの泥、湿った火縄、油紙、葦、柳、菜種粕、土嚢、荷縄を反復物として固定。
- 又兵衛は煤けた鎌なしの素槍。完成した黒漆の名槍や超常的な軌跡は禁止。
- 血は負傷の位置と結果を読める量に抑え、飛沫を見世物にしない。
- 明智方は負傷者と退路を守る合理的な兵として描く。異形・悪鬼・一様な悪人顔は禁止。

## 巻末不可逆条件

1. 秀吉は「後藤又兵衛」の名を正しく覚えた。
2. 兵は旗より先に又兵衛の名を集合標識として使い始めた。
3. 長政は又兵衛を守るためにも管理するためにも、黒田の制度へ戻す必要を感じた。
4. 又兵衛は市松の木櫛を持つ。
5. カヤは又兵衛の命令違反を見届け、無条件の信頼を引いた。
6. 清十郎の帳面には又兵衛の成功と過失が同じ濃さで残る。
7. 褒美帳に又兵衛の名はあるが、所属欄は空白。第10巻『勝者の空席』の開始条件とする。
