# 第66話終了時台帳

- 黒槍組48→生存47。市松戦死。市松の木櫛は又兵衛が保持。
- 又兵衛は「伸び」を偶発的に使うが、槍を戻せず盾列を開けた。成功技として完成扱いしない。
- 柳の浅瀬へ水中板、柳根、石入り油桶、腰縄を設置。60人が渡河。
- 甚六の制止を又兵衛が退けた事実を消さない。
- 上流・畦道の二射線と、油紙で乾いた火薬が残る。
