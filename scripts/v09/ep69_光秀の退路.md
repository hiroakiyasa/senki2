# 『戦帰 SENKI』v09ep69「光秀の退路」

## 話情報

| 項目 | 内容 |
|---|---|
| 巻/話 | 第9巻第5話（通算69/240） |
| 頁数 | 12頁（6見開き・43コマ） |
| 時刻 | 天正10年6月13日・夕刻〜日没 |
| 視点 | 又兵衛 |
| 即時質問 | 敗走兵、武器を持つ民、負傷者が混ざる一本道で、誰を止めるか |
| 表面目標 | 坂本へ続く軍の道だけを塞ぎ、明智軍の再編を防ぐ |
| 最初の誤り | 手の煤だけで鉄砲兵を識別し、油職人を拘束する |
| 修正 | 出身と行先、荷、足跡、命令印を複数で照合し三つの通路を作る |
| 結果 | 民186人、武器を置いた負傷兵31人を通し、組織兵47人を捕縛 |
| 代価 | 炭焼き道から伝令十数人が抜け、山中継所へ向かう |
| 引き | 白頭巾の騎馬を見て、又兵衛の武名欲が再び槍へ動く |

## 本話の倫理固定

- 退路遮断を無差別殺戮にしない。
- 百姓にも護身用の火縄銃があり、兵も鎧を捨てられるため、衣装だけで判定しない。
- 桑原与市は弟を背負いながら軍の列を選び、民を盾にする小頭を止める。
- 又兵衛の温情を完全正解にせず、伝令が抜ける実務的代価を残す。

# 第69話終了時台帳

- 民186、武器を置いた負傷兵31を通す。組織兵47、弾薬車2を止める。
- 又兵衛は「煤の手」一条件で誤判定し、千吉の叔父を拘束。公に修正した。
- 三通路は鍋・白布・折槍を目印にし、可読文字を使わない。
- 桑原与市は捕縛側へ残り、敵方証言者として継続。
- 明智伝令十数人が炭焼き道へ抜ける。山中継所と白頭巾の一騎が第70話へ直結。
