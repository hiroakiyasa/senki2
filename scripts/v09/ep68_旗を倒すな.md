| 視点 | 又兵衛（副視点・長政） |
| 即時質問 | 煙で本旗が倒れた時、兵は誰の命令へ集まるか |
| 表面目標 | 長政隊の命令系統を切らず、側面前進を継続する |

| 引き | 黒田の旗は立つが、兵の目は先に又兵衛を探す |

## 美術・戦術固定

- 黒田の小旗は家紋が判別できる形だが、可読文字はない。巨大なのぼりではない。
- 太鼓は湿り、煙で法螺の方向が分かりにくい。旗の上下を受領確認へ使う。
- 明智方騎馬8騎。豪華な騎馬武者ではなく、退路確保を狙う軽装の伝令・小頭。
- 又兵衛は馬を派手に斬らず、土嚢と槍で進路を絞る。

# 第68話終了時台帳

- 長政隊は本旗1・予備旗2・受領確認で命令系統を保持。
- 又兵衛の名が臨時の右旗として使われる。兵が「又兵衛」を方向語・集合標識として呼び始める。
- 長政は又兵衛を称賛しつつ、制度の外に別の忠誠中心が生まれた危険を理解。
- 又兵衛は名が人を動かす高揚を実際に感じる。無欲化しない。
- 次話、明智方の敗走と民の避難が混ざり、命令系統の次は識別の問題になる。
