## 巻全体カード

- **年代**：慶長3〜5年（1598〜1600）。
- **主な場所**：伏見、大坂道、佐和山、東海道・中山道周辺、美濃赤坂、杭瀬川周辺、関ヶ原・岡山東肩。
- **巻の表面目標**：開戦の第一発までに黒田家の返答を東軍の実働へ変え、又兵衛隊三百二十人と火薬八櫃を、友軍誤射なく固い二列目へ配置する。
- **内面の問い**：槍で届かない相手を、誰が、何で動かすのか。書状と数字は人を救うのか、それとも人を縛るのか。
- **巻頭で又兵衛が欲しいもの**：朝鮮で得た武名に見合う前線、長政からの全面的な信頼、黒槍組が再び一つに戻ること。
- **巻末で得るもの**：三百二十人の指揮、十二家の友軍識別、受領確認、分散小旗、停止縄、霧中の再点呼、他者へ槍を預ける経験。
- **巻末で失うもの**：黒槍組の一枚名簿、政治書状の全情報、一番手、替え馬一頭、荷車一台、仲間の働きを個別に残す余白。
- **巻の外的勝利**：射手不明の第一発が鳴っても先走らず、長政の手旗を確認して三百二十人が半歩をそろえる。
- **次巻条件**：第169話は二列目から前進路へ入る瞬間から始める。大橋掃部は生存。小早川・毛利・島津の実際の行動は未決着。

## 年代・史実ロック

- 秀吉は慶長3年（1598）8月18日に伏見で死去し、幼い秀頼の政務は五大老・五奉行へ委ねられた `[A]`。
- 前田利家死去後に豊臣政権内の均衡が崩れ、家康を中心とする勢力と反家康側が分かれていく `[A]`。
- 黒田長政が吉川広家へ通じ、小早川秀秋へ東軍加担を働きかけた調略は長政の功績として残す `[A/B]`。又兵衛へ移さない。
- 吉川史料館に伝わる慶長5年8月8日付黒田長政書状には横裂きの痕跡があり、密書は帯や笠の緒へ隠して運ばれたという館蔵説明を第162話へ使う `[A]`。
- 小早川秀秋が東軍側へ決めた時期は研究上の論点である。本巻では確定返答を出さず、白紙、沈黙、圧力、待機として扱う `[A/B/C]`。
- 石田三成の掟書に見える役負担軽減、不法行為防止、年貢、逃亡百姓、京枡の規定と、検地奉行としての史料を第163話の制度描写へ使う `[A]`。
- 関ヶ原本戦は慶長5年（1600）9月15日 `[A]`。第一射、開戦時刻、霧、厳密な布陣位置は複数説を分け、断定しない `[B]`。
- 杭瀬川前哨戦の働きを島左近らから奪わない。又兵衛と大橋掃部の事前遭遇は創作 `[C/D]`。
- 大橋掃部を本巻で討死させない。小早川勢の山下り、島津の退き口、三成・吉継の最期、戦後論功は第22巻へ送る。
- 六十四人、千四百四十人、三百二十人、火薬八櫃、停止縄、小黒旗、具体的会話は創作 `[C]`。

- 黒槍組は朝鮮から日本へ戻ったが、民間人避難、負傷兵、捕虜、船席の仕事は戦果帳からこぼれている。

- 又兵衛と長政は互いの力量を知る。長政は又兵衛を必要とするほど管理し、又兵衛は必要とされるほど全情報を求める。

## 全話共通の画像生成規約

- 1598〜1600年の安土桃山末期。江戸中後期の町並み、幕末装備、現代物を入れない。
- 書状、台帳、割符、署判、枡、札は形と手順だけ描く。可読文字、題字、偽文字を生成しない。
- 当世具足、陣笠、長槍、火縄銃、荷駄、筵、縄、木桶、松明を使う。巨大な軍旗の林で識別難を消さない。
- 黒槍は鎌・鉤・十文字のない素槍。低い水平構えと小刻みな足運びを基本にする。
- 関ヶ原盆地の湿田、排水溝、畦、低い土手、川、霧、朝露を勝敗条件として描く。地面を平らな舞台にしない。
- 馬具は16世紀日本の和鞍・和鐙。英国式鞍、カウボーイ鞍、細い西洋鐙を禁止する。
- 伏見・佐和山は灯明と障子の低い光。美濃以降は曇天、雨上がり、夜明け前の青灰色。火縄・烽火だけを橙にする。
- 群衆の同一顔・同一姿勢を避ける。欠損、凍傷、年齢、身分、荷の違いを出す。
- 台詞、N、音、題字は画像生成後にローカル写植する。生成欄の「空き」を吹き出し・ナレーション位置として使う。
