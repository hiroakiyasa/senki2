| 項目 | 内容 |

| この話の勝利条件 | 種籾を村へ戻しつつ十日分の配給を成立させ、帳外の帰還兵を本人確認して米へ接続する |
| 即時質問 | 帳面へ名を入れることは、その人を救うのか、それとも再び命令へ縛るのか |
| この話の主機能 | 敵側の別回答／三成の制度を人間化／帰名帳と動員台帳の二重性 |
| 引きの型 | 一筆の二重効果（配給と動員） |
| 勝利の代価 | 救済の記録が同時に役負担の記録となり、兵の一日分は薄くなる |

## 骨子

- 三成は兵千二百、荷運び二百四十の十日分を米俵三百六十で組む。
- 不足補填のため村の種籾十八俵が軍用へ移され、三成は戦う者の一日分を薄くして種を戻す。
- 帳面で死者扱いされた朝鮮帰還兵を、清十郎の帰名帳と傷の記録で生存確認する。
- 名を入れると米が出る一方、蔵役・動員の対象にもなる。本人が村へ戻るか役を受けるか選ぶ。
- 雨漏りで俵山が崩れかけ、名を得た帰還兵の警告と又兵衛・弦太・三成の工程で損失を抑える。

## 登場

- **石田三成**：数、検地、配給、役負担で万人を支えようとする。正しさを受け取れる形で伝えるのが不得手。
- **又兵衛**：名を入れることを救済と考えていたが、名が命令の入口にもなると知る。
- **速水弦太**：床の傾き、俵の湿気、十日後の不足を読む。
- **狭間清十郎**：帰名帳で同名死者の取り違えを正す。記録が支配にも救済にもなる場面。
- **朝鮮帰還兵［C］**：死者扱いから生存確認され、本人の選択で蔵の照合役になる。
- **村の老女と孫［C］**：十八俵の種籾を守る。戦後の春を具体化する。
- **軍奉行・書記・荷運び**：制度の現場を担い、三成の命令へ合理的に反発する。

## この話の生成規約

- 三成を冷たい数字の人に固定しない。自ら枡を取り、薄い粥を食べ、種籾と運搬人を数える。
- 京枡・算木・色紐・印・俵・検地尺を使うが、特定の現存台帳を再現したと断定しない。
- 又兵衛は黒槍で俵山を超人的に持ち上げず、柱と石突へ荷重を逃がし数秒稼ぐ。
- 帳面の可読本文は画像生成しない。二つの印、行の追加、頁の照合を視覚で示す。
- 種籾を軍用へ回す問題は、戦争が来年の生活を食う具体的代価として扱う。

## 第163話終了時の台帳

- **三成**：千四百四十人の配給を組み、戦闘員の一日分を薄くして種籾十八俵を村へ戻す［人数・俵数はC］。
- **帰還兵**：死者扱いを訂正され、十日分の米と蔵照合役を得る。本人が役を選んだ。
- **又兵衛**：記録へ入ることが救済と拘束を同時に生むと知る。右手指を板戸で軽く負傷。
- **弦太**：雨漏り俵十八を粥用へ転用し、乾燥・積み直しを指揮。
- **清十郎**：帰名帳が三成の公的台帳を訂正した一方、その訂正が新しい役負担を生んだ。
- **生活**：種籾は村へ戻るが、兵・荷運びは十日間一日一口ずつ少ない配給となる。

## 次話への不可逆な条件

- 又兵衛は三成を単純な敵として見られなくなるが、制度が人を再動員する怖さも覚える。
- 東西どちらの陣営も、米・荷運び・返書・名簿なしでは動けないと読者へ固定される。
- 家康の書状網は、三成の台帳と対になる『返答を数える制度』として第164話へ続く。
- 又兵衛の右手指の傷は軽傷で次話までに塞がる。右肩の古傷は継続。
